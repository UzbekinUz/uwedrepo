- Lokal ekstremumlar: 1- va 2-hosila alomatlari
- Kesmadagi eng katta va eng kichik qiymat
- Qavariqlik, botiqlik va egilish nuqtalari

:::

::: hayot Hayotda qayerda kerak?
Karton qutilar ishlab chiqaruvchi firma 12 × 12 sm list burchaklaridan kvadratlar qirqib, ustsiz quti yasaydi. Qirqim juda kichik bo'lsa — quti past, juda katta bo'lsa — tubi kichik. Qaysi o'lchamda qutiga **eng ko'p** narsa sig'adi? Narxni qancha qo'ysak foyda **eng katta** bo'ladi? Yo'lni qanday tanlasak benzin **eng kam** ketadi? Bularning barchasi bitta usul bilan yechiladi: **hosilani nolga tenglash**.
:::

## O'sish va kamayish

::: teorema Monotonlik alomati
(a; b) da **f′(x) > 0** ⇒ f o'sadi; **f′(x) < 0** ⇒ f kamayadi.
:::

## Ekstremumlar

- **Kritik nuqtalar:** f′(c) = 0 yoki f′(c) mavjud emas. Ekstremum faqat shu nuqtalarda bo'lishi mumkin.
- **1-hosila alomati:** c dan o'tishda f′ ishorasi «+» → «−» bo'lsa **maksimum**, «−» → «+» bo'lsa **minimum**, o'zgarmasa — ekstremum yo'q.
- **2-hosila alomati:** f′(c) = 0 va f″(c) < 0 ⇒ maksimum; f″(c) > 0 ⇒ minimum.

::: grafik x: -3..5, y: -26..16 | f(x) = x³ − 3x² − 9x + 5: x = −1 da maksimum, x = 3 da minimum
y = x^3 - 3x^2 - 9x + 5 | teal | f(x)
y = 10 | amber | maksimum = 10 | -2..0
y = -22 | violet | minimum = −22 | 2..4
nuqta -1, 10 | max (−1; 10)
nuqta 3, -22 | min (3; −22)
:::

::: oddiy
Maksimumda funksiya «tepaga chiqib, pastga tushadi» — hosila musbatdan manfiyga o'tadi; tepada urinma gorizontal (f′ = 0). Minimumda — teskarisi.
:::

## Kesmadagi eng katta va eng kichik qiymat

::: formula 3 qadamli algoritm
1. (a; b) ichidagi kritik nuqtalarni toping.
2. f ning **kritik nuqtalardagi** va **kesma uchlaridagi** (a va b) qiymatlarini hisoblang.
3. Eng kattasi — absolyut maksimum, eng kichigi — absolyut minimum.
:::

## Qavariqlik va egilish

| f″ ishorasi | Grafik shakli |
|---|---|
| f″ > 0 | botiq (∪, «chashka») — urinma grafikdan pastda |
| f″ < 0 | qavariq (∩, «gumbaz») — urinma grafikdan yuqorida |
| f″ ishorasini o'zgartiradi | **egilish nuqtasi** |

::: grafik x: -0.5..4.5, y: -4..7 | f(x) = x³ − 6x² + 9x + 1: egilish nuqtasi (2; 3)
y = x^3 - 6x^2 + 9x + 1 | teal | f(x)
nuqta 2, 3 | egilish (2; 3)
nuqta 1, 5 | max
nuqta 3, 1 | min
:::

## Ishlangan misollar

::: misol Monotonlik va ekstremumlar
f(x) = x^3 − 3x^2 − 9x + 5.
---
f′(x) = 3x^2 − 6x − 9 = 3(x + 1)(x − 3) ⇒ kritik nuqtalar x = −1, x = 3.

| Oraliq | (−∞; −1) | (−1; 3) | (3; ∞) |
|---|---|---|---|
| f′ | + | − | + |
| f | ↗ | ↘ | ↗ |

**Maksimum** f(−1) = −1 − 3 + 9 + 5 = 10; **minimum** f(3) = 27 − 27 − 27 + 5 = −22.
:::

::: misol Kesmadagi eng katta va kichik qiymat
f(x) = x^3 − 3x ning [0; 2] dagi eng katta va eng kichik qiymatlari.
---
f′ = 3x^2 − 3 = 0 ⇒ x = ±1; kesmada faqat x = 1. Qiymatlar: f(0) = 0, f(1) = −2, f(2) = 2.

**Eng katta: 2 (x = 2 da — kesma uchida!), eng kichik: −2 (x = 1 da).**
:::

::: misol 2-hosila alomati
f(x) = x^4 − 2x^2.
---
f′ = 4x(x − 1)(x + 1) ⇒ x = 0, ±1. f″ = 12x^2 − 4: f″(0) = −4 < 0 — **maksimum f(0) = 0**; f″(±1) = 8 > 0 — **minimum f(±1) = −1**.
:::

::: misol Egilish nuqtasi
f(x) = x^3 − 6x^2 + 9x + 1.
---
f″ = 6x − 12 = 0 ⇒ x = 2. x < 2 da f″ < 0 (∩), x > 2 da f″ > 0 (∪). f(2) = 8 − 24 + 18 + 1 = 3 ⇒ **egilish nuqtasi (2; 3)**.
:::

## Optimallashtirish masalalari

::: formula Ish tartibi
1. Nima eng katta/kichik bo'lishi kerak — **maqsad funksiyasi**ni yozing.
2. Shartdan foydalanib uni **bitta o'zgaruvchi** orqali ifodalang.
3. O'zgaruvchining **mantiqiy oralig'ini** aniqlang (uzunlik > 0 va h.k.).
4. Hosilani nolga tenglang, ekstremumni tekshiring, javobni so'ralgan ko'rinishda yozing.
:::

::: misol Perimetri berilgan to'rtburchak
Perimetri 40 m bo'lgan to'g'ri to'rtburchaklardan eng katta yuzalisini toping.
---
Tomonlar x va 20 − x, yuza S(x) = x(20 − x), 0 < x < 20. S′ = 20 − 2x = 0 ⇒ x = 10; S″ = −2 < 0 — maksimum.

**Javob: 10 × 10 kvadrat, S = 100 m².**
:::

::: misol Ustsiz quti
12 × 12 sm list burchaklaridan x sm li kvadratlar qirqiladi. Hajm eng katta bo'lishi uchun x = ?
---
V(x) = x(12 − 2x)^2, 0 < x < 6.

V′ = (12 − 2x)^2 − 4x(12 − 2x) = (12 − 2x)(12 − 6x) = 0 ⇒ x = 2 (x = 6 mos emas).

**x = 2 sm, V = 2·8^2 = 128 sm³.**
:::

::: grafik x: 0..6, y: 0..140 | Quti hajmi V(x) = x(12 − 2x)²: eng katta qiymat x = 2 da
y = x(12-2x)^2 | amber | V(x)
nuqta 2, 128 | V(2) = 128
:::

::: misol Daryo bo'yidagi uchastka
Daryo bo'yida to'g'ri to'rtburchak yer 600 m to'r bilan **uch tomondan** o'raladi. Eng katta yuza?
---
Daryoga perpendikulyar tomonlar x, parallel tomon 600 − 2x. S(x) = x(600 − 2x), S′ = 600 − 4x = 0 ⇒ x = 150.

**S = 150·300 = 45 000 m².**
:::

::: xato
- **Kesma uchlarini unutish.** 2-misolda eng katta qiymat aynan uchida (x = 2) — kritik nuqtada emas.
- **f′ = 0 bo'lgan har bir nuqtani ekstremum deb hisoblash.** f = x^3 uchun f′(0) = 0, lekin ishora o'zgarmaydi — ekstremum yo'q.
- **Optimallashtirishda mantiqiy oraliqni tekshirmaslik.** Qutida x = 6 hajmni nolga aylantiradi.
:::

::: xulosa
