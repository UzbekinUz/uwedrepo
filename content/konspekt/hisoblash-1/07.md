## Monotonlik

(a; b) oraliqda:

- f′(x) > 0 ⇒ f **o'suvchi**;
- f′(x) < 0 ⇒ f **kamayuvchi**.

Monotonlik oraliqlarini topish: f′(x) ni nolga tenglab va aniqlanmagan nuqtalarni topib, son o'qini oraliqlarga ajratamiz va har birida f′ ning ishorasini aniqlaymiz.

## Ekstremumlar

- f′(c) = 0 yoki f′(c) mavjud bo'lmagan ichki nuqtalar — **kritik nuqtalar**. Ekstremum faqat shu nuqtalarda bo'lishi mumkin (Ferma).
- **Birinchi hosila alomati:** c dan o'tishda f′ ishorasi «+» dan «−» ga o'zgarsa — **lokal maksimum**, «−» dan «+» ga — **lokal minimum**, o'zgarmasa — ekstremum yo'q.
- **Ikkinchi hosila alomati:** f′(c) = 0 va f″(c) < 0 bo'lsa — maksimum, f″(c) > 0 bo'lsa — minimum (f″(c) = 0 bo'lsa — alomat javob bermaydi).

## Kesmadagi eng katta va eng kichik qiymat

[a; b] kesmada uzluksiz funksiya uchun:

1. (a; b) dagi kritik nuqtalarni toping.
2. Funksiyaning shu nuqtalardagi va **kesma uchlaridagi** (a va b) qiymatlarini hisoblang.
3. Ulardan eng kattasi — absolyut maksimum, eng kichigi — absolyut minimum.

## Qavariqlik va egilish nuqtalari

- f″(x) > 0 ⇒ grafik **botiq** (pastga qavariq, «chashka» ∪);
- f″(x) < 0 ⇒ grafik **qavariq** (yuqoriga qavariq, «gumbaz» ∩);
- f″ ishorasi o'zgaradigan nuqta — **egilish (burilish) nuqtasi**.

## Ishlangan misollar

> **1-misol.** f(x) = x^3 − 3x^2 − 9x + 5 ning monotonlik oraliqlari va ekstremumlari.
>
> **Yechim.** f′(x) = 3x^2 − 6x − 9 = 3(x + 1)(x − 3). Kritik nuqtalar: x = −1, x = 3.
>
> | Oraliq | (−∞; −1) | (−1; 3) | (3; ∞) |
> |---|---|---|---|
> | f′ ishorasi | + | − | + |
> | f | o'sadi | kamayadi | o'sadi |
>
> x = −1 da **maksimum** f(−1) = −1 − 3 + 9 + 5 = **10**; x = 3 da **minimum** f(3) = 27 − 27 − 27 + 5 = **−22**.

> **2-misol** (kesmada). f(x) = x^3 − 3x ning [0; 2] dagi eng katta va eng kichik qiymatlari.
>
> **Yechim.** f′(x) = 3x^2 − 3 = 0 ⇒ x = ±1; kesmaga faqat x = 1 tushadi. Qiymatlar: f(0) = 0, f(1) = −2, f(2) = 2. **Eng katta: 2 (x = 2 da), eng kichik: −2 (x = 1 da).**

> **3-misol** (ikkinchi hosila alomati). f(x) = x^4 − 2x^2.
>
> **Yechim.** f′(x) = 4x^3 − 4x = 4x(x − 1)(x + 1) ⇒ x = 0, ±1. f″(x) = 12x^2 − 4. f″(0) = −4 < 0 — **maksimum** f(0) = 0; f″(±1) = 8 > 0 — **minimum** f(±1) = −1.

> **4-misol** (egilish nuqtasi). f(x) = x^3 − 6x^2 + 9x + 1.
>
> **Yechim.** f″(x) = 6x − 12 = 0 ⇒ x = 2. x < 2 da f″ < 0 (qavariq ∩), x > 2 da f″ > 0 (botiq ∪). Egilish nuqtasi: **(2; 3)**, chunki f(2) = 8 − 24 + 18 + 1 = 3.

## Optimallashtirish masalalari

Ish tartibi: 1) nimani maksimallashtirish/minimallashtirish kerakligini aniqlang; 2) uni bitta o'zgaruvchi funksiyasi ko'rinishida yozing; 3) aniqlanish sohasini toping; 4) hosila yordamida ekstremumni toping va tekshiring.

> **5-misol.** Perimetri 40 m bo'lgan to'g'ri to'rtburchaklardan eng katta yuzalisini toping.
>
> **Yechim.** Tomonlar x va 20 − x, yuza S(x) = x(20 − x) = 20x − x^2, 0 < x < 20. S′(x) = 20 − 2x = 0 ⇒ x = 10, S″ = −2 < 0 — maksimum. Javob: **10 × 10 kvadrat, S = 100 m^2**.

> **6-misol.** 12 × 12 sm tunuka burchaklaridan x tomonli kvadratlar qirqib, ustsiz quti yasaladi. Hajm eng katta bo'lishi uchun x qancha bo'lishi kerak?
>
> **Yechim.** V(x) = x(12 − 2x)^2, 0 < x < 6. V′(x) = (12 − 2x)^2 − 4x(12 − 2x) = (12 − 2x)(12 − 6x) = 0 ⇒ x = 2 (x = 6 mos emas). **x = 2 sm, V = 2·8^2 = 128 sm^3**.

> **7-misol.** Daryo bo'yida to'g'ri to'rtburchak yer uchastkasi 600 m sim to'r bilan uch tomondan o'raladi (daryo tomoni o'ralmaydi). Eng katta yuza qancha?
>
> **Yechim.** Daryoga perpendikulyar tomonlar x, parallel tomon 600 − 2x. S(x) = x(600 − 2x), S′ = 600 − 4x = 0 ⇒ x = 150. **S = 150·300 = 45 000 m^2**.
