- Differensiallash qoidalari va hosilalar jadvali

::: hayot Hayotda qayerda kerak?
Onlayn do'kon sotuvlari S(t) haftalar bo'yicha o'sib bormoqda. Rahbarga «jami qancha sotdik» emas, «sotuvlar **hozir** qanchalik tez o'sayapti» muhim — reklama ishlayaptimi yoki yo'q? Bu savolga **hosila** S′(t) javob beradi. Iqtisodda hosila — «marjinal» so'zining sinonimi: marjinal xarajat, marjinal daromad, marjinal foyda — hammasi hosilalar.
:::

## Hosila ta'rifi

::: formula Ta'rif
$$
f′(x) = lim_{h→0} {f(x + h) − f(x)|h} = lim_{Δx→0} {Δy|Δx}
$$
:::

| Ma'nosi | f′(x) nimani ko'rsatadi |
|---|---|
| Geometrik | grafikka x nuqtada o'tkazilgan **urinma qiyaligi** |
| Fizik | **oniy tezlik** (yo'l hosilasi — tezlik, tezlik hosilasi — tezlanish) |
| Iqtisodiy | **marjinal** ko'rsatkich: x bir birlikka oshganda f taxminan qanchaga o'zgaradi |

::: grafik x: -2..2.5, y: -3..5 | y = x³ − 2x va unga urinmalar: qiyalik har nuqtada har xil
y = x^3 - 2x | teal | y = x³ − 2x
y = x - 2 | amber | x = 1 da urinma (qiyalik 1)
y = -2x | violet | x = 0 da urinma (qiyalik −2)
nuqta 1, -1 | (1; −1)
nuqta 0, 0 |
:::

::: formula Urinma tenglamasi
$$
y − f(x_{0}) = f′(x_{0})·(x − x_{0})
$$
:::

::: eslatma
Differensiallanuvchi funksiya albatta uzluksiz. Teskarisi doim to'g'ri emas: y = ∣x∣ funksiya x = 0 da uzluksiz, lekin u yerda «burchak» bor — hosilasi yo'q.
:::

## Differensiallash qoidalari

::: formula
$$
(u ± v)′ = u′ ± v′,   (c·u)′ = c·u′
(u·v)′ = u′v + uv′,   ({u|v})′ = {u′v − uv′|v^2}
(f(g(x)))′ = f′(g(x))·g′(x)   — zanjir qoidasi
$$
:::

::: oddiy Zanjir qoidasi
«Tashqi funksiyaning hosilasi (ichki joyida qoladi) **ko'paytirilgan** ichki funksiya hosilasiga». Masalan, (sin 3x)′ = cos 3x · 3.
:::

## Hosilalar jadvali

| f(x) | f′(x) | f(x) | f′(x) |
|---|---|---|---|
| c | 0 | sin x | cos x |
| x^n | n·x^{n−1} | cos x | −sin x |
| √x | {1|2√x} | tg x | {1|cos^2 x} |
| {1|x} | −{1|x^2} | ctg x | −{1|sin^2 x} |
| e^x | e^x | arcsin x | {1|√(1 − x^2)} |
| a^x | a^x ln a | arccos x | −{1|√(1 − x^2)} |
| ln x | {1|x} | arctg x | {1|1 + x^2} |
| log_{a} x | {1|x ln a} | arcctg x | −{1|1 + x^2} |

## Maxsus hollar

| Holat | Formula |
|---|---|
| Parametrik: x = x(t), y = y(t) | y′_{x} = {y′_{t}|x′_{t}} |
| Oshkormas: F(x, y) = 0 | ikki tomonni x bo'yicha differensiallab, y′ ni ifodalash |
| Teskari funksiya | x′_{y} = {1|y′_{x}} |
| Logarifmik (y = u^v) | ln y ni differensiallash: y′ = y·(ln y)′ |
| Yuqori tartib | y″ = (y′)′, y^{(n)} = (y^{(n−1)})′ |

## Ishlangan misollar

::: misol Ta'rif bo'yicha
f(x) = x^2 + 3x ning hosilasini ta'rif bo'yicha toping.
---
$$
{f(x + h) − f(x)|h} = {(x + h)^2 + 3(x + h) − x^2 − 3x|h} = {2xh + h^2 + 3h|h} = 2x + h + 3
$$
h → 0 da **f′(x) = 2x + 3**.
:::

::: misol Ta'rif bo'yicha, ildiz
f(x) = √x.
---
Qo'shma ifodaga ko'paytiramiz: {√(x + h) − √x|h} = {1|√(x + h) + √x} → **{1|2√x}**.
:::

::: misol Jadval va qoidalar
y = 3x^4 − {2|x} + 5√x.
---
y′ = 12x^3 + {2|x^2} + {5|2√x}.
:::

::: misol Ko'paytma va bo'linma
a) y = x^2 e^x; b) y = {x^2 + 1|x − 1}.
---
a) y′ = 2x·e^x + x^2·e^x = **(x^2 + 2x)e^x**.

b) y′ = {2x(x − 1) − (x^2 + 1)|(x − 1)^2} = **{x^2 − 2x − 1|(x − 1)^2}**.
:::

::: misol Zanjir qoidasi
a) sin(3x^2 + 1); b) ln(x^2 + 4); c) (2x − 5)^{10}; d) e^{−x^2}.
---
a) cos(3x^2 + 1)·6x. b) {2x|x^2 + 4}. c) 10(2x − 5)^9·2 = 20(2x − 5)^9. d) −2x·e^{−x^2}.
:::

::: misol Urinma
y = x^3 − 2x ga x_{0} = 1 nuqtada urinma tenglamasini tuzing.
---
y(1) = −1; y′ = 3x^2 − 2, y′(1) = 1. Urinma: y + 1 = 1·(x − 1) ⇒ **y = x − 2** (grafikdagi sariq chiziq).
:::

::: misol Parametrik funksiya
x = t^2, y = t^3 − t. y′_{x} ni va t = 1 dagi qiymatini toping.
---
y′_{x} = {3t^2 − 1|2t}. t = 1 da {2|2} = **1**.
:::

::: misol Oshkormas funksiya
x^2 + y^2 = 25 aylanaga (3; 4) nuqtada urinma.
---
2x + 2y·y′ = 0 ⇒ y′ = −{x|y} = −{3|4}. Urinma: y − 4 = −{3|4}(x − 3) ⇒ **3x + 4y = 25**.
:::

::: misol Logarifmik differensiallash
y = x^x (x > 0).
---
ln y = x ln x ⇒ {y′|y} = ln x + 1 ⇒ **y′ = x^x(ln x + 1)**.
:::

::: misol Teskari funksiya
y = x^3 + x. y = 2 nuqtada x′_{y} ni toping.
---
y = 2 da x = 1. y′_{x} = 3x^2 + 1 = 4 ⇒ x′_{y} = **{1|4}**.
:::

::: misol Yuqori tartib
a) y = x^4 − 3x^2 ning y″ si; b) y = e^{2x} ning n-tartibli hosilasi.
---
a) y′ = 4x^3 − 6x, **y″ = 12x^2 − 6**. b) har differensiallashda 2 ko'paytuvchi chiqadi: **y^{(n)} = 2^n e^{2x}**.
:::

::: xato
- **(u·v)′ = u′·v′.** Noto'g'ri! To'g'risi: u′v + uv′.
- **Zanjir qoidasini unutish:** (sin 3x)′ ≠ cos 3x, to'g'risi 3cos 3x.
- **x^x ni x^n kabi differensiallash:** (x^x)′ ≠ x·x^{x−1}. Asos ham, daraja ham o'zgaruvchi — logarifmik usul kerak.
:::

## O'zingizni tekshiring

::: test
? (x^5)′ = ?
- x^4
+ 5x^4
- 5x^5
- {x^6|6}
> (x^n)′ = n·x^{n−1}.
? (e^{3x})′ = ?
- e^{3x}
+ 3e^{3x}
- 3xe^{3x−1}
- {e^{3x}|3}
> Zanjir qoidasi: e^{3x}·(3x)′.
? y = x^2 ning x = 3 dagi urinmasining qiyaligi:
- 3
- 9
+ 6
- 2
> y′ = 2x, y′(3) = 6.
? (x·ln x)′ = ?
- {1|x}
+ ln x + 1
- ln x
- x + ln x
> Ko'paytma: 1·ln x + x·{1|x}.
:::
