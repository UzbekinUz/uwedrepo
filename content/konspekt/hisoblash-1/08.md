## Tekshirish sxemasi

::: formula 7 bosqich
1. **Aniqlanish sohasi**, uzilish nuqtalari.
2. **Juft-toqlik**, davriylik (simmetriya).
3. **O'qlar bilan kesishish:** x = 0 da y; y = 0 da x.
4. **Asimptotalar.**
5. **1-hosila:** kritik nuqtalar, o'sish/kamayish, ekstremumlar.
6. **2-hosila:** qavariqlik, egilish nuqtalari.
7. Jadval tuzish va **grafikni chizish**.
:::

## Asimptotalar

| Tur | Qanday topiladi |
|---|---|
| Vertikal x = a | x → a da f(x) → ±∞; ratsional funksiyada maxraj nollari (surat ≠ 0) |
| Gorizontal y = b | b = lim_{x→±∞} f(x), chekli bo'lsa |
| Og'ma y = kx + b | k = lim_{x→∞} {f(x)|x}, b = lim_{x→∞} (f(x) − kx) |

::: eslatma Tez yo'l
Ratsional funksiyada surat darajasi maxrajnikidan **aynan 1 ga** katta bo'lsa, og'ma asimptota — bo'lishning butun qismi: {x^2|x − 1} = x + 1 + {1|x − 1} ⇒ y = x + 1.
:::

## Ishlangan misollar

::: misol Ko'phad
y = x^3 − 3x ni to'liq tekshiring.
---
- **Soha:** (−∞; ∞). **Toq:** grafik koordinata boshiga simmetrik.
- **Kesishish:** x(x^2 − 3) = 0 ⇒ x = 0, ±√3 ≈ ±1,73.
- **Asimptota** yo'q (ko'phad).
- y′ = 3x^2 − 3 = 0 ⇒ x = ±1: **max (−1; 2)**, **min (1; −2)**.
- y″ = 6x: x < 0 da ∩, x > 0 da ∪, **egilish (0; 0)**.

| x | (−∞; −1) | −1 | (−1; 0) | 0 | (0; 1) | 1 | (1; ∞) |
|---|---|---|---|---|---|---|---|
| y′ | + | 0 | − | − | − | 0 | + |
| y″ | − | − | − | 0 | + | + | + |
| y | ↗ ∩ | max 2 | ↘ ∩ | egilish | ↘ ∪ | min −2 | ↗ ∪ |
:::

::: grafik x: -2.5..2.5, y: -4..4 | y = x³ − 3x
y = x^3 - 3x | teal | y = x³ − 3x
nuqta -1, 2 | max
nuqta 1, -2 | min
nuqta 0, 0 | egilish
nuqta 1.732, 0 | √3
nuqta -1.732, 0 | −√3
:::

::: misol Kasr-ratsional funksiya
y = {x^2|x − 1} ni tekshiring.
---
- **Soha:** x ≠ 1. Kesishish: (0; 0).
- **Vertikal asimptota x = 1:** x → 1^{+} da y → +∞, x → 1^{−} da y → −∞.
- **Og'ma asimptota:** {x^2|x − 1} = x + 1 + {1|x − 1} ⇒ **y = x + 1**.
- y′ = {x(x − 2)|(x − 1)^2} = 0 ⇒ x = 0 (**max y = 0**), x = 2 (**min y = 4**).
- y″ = {2|(x − 1)^3}: x > 1 da ∪, x < 1 da ∩; egilish nuqtasi yo'q.
:::

::: grafik x: -4..6, y: -10..12 | y = x²/(x − 1): vertikal asimptota x = 1, og'ma asimptota y = x + 1
y = x^2/(x-1) | teal | y = x²/(x − 1)
y = x + 1 | slate | og'ma asimptota y = x + 1
vertikal 1 | x = 1
nuqta 0, 0 | max
nuqta 2, 4 | min
:::

::: misol Ko'rsatkichli funksiya
y = xe^{−x} ni tekshiring.
---
- **Soha:** (−∞; ∞); kesishish (0; 0).
- x → +∞ da xe^{−x} → 0 ⇒ **gorizontal asimptota y = 0** (o'ngda). x → −∞ da y → −∞.
- y′ = (1 − x)e^{−x} = 0 ⇒ x = 1: **max y = {1|e} ≈ 0,37**.
- y″ = (x − 2)e^{−x} = 0 ⇒ x = 2: **egilish (2; {2|e^2}) ≈ (2; 0,27)**.
:::

::: grafik x: -1..7, y: -1.5..0.6 | y = x·e⁻ˣ: max x = 1 da, egilish x = 2 da
y = x*e^(-x) | teal | y = x·e⁻ˣ
nuqta 1, 0.3679 | max
nuqta 2, 0.2707 | egilish
:::

::: misol Asimptotalar
y = {2x^2 + 1|x^2 − 4}.
---
Vertikal: **x = ±2**. Gorizontal: lim {2x^2 + 1|x^2 − 4} = 2 ⇒ **y = 2**. Gorizontal bo'lgani uchun og'ma yo'q.
:::

::: misol Og'ma asimptota formula bilan
y = {x^3|x^2 + 1}.
---
k = lim {x^3|x(x^2 + 1)} = 1; b = lim ({x^3|x^2 + 1} − x) = lim {−x|x^2 + 1} = 0 ⇒ **y = x**.
:::

::: xato
- **Asimptotani grafik kesib o'tmaydi deb o'ylash.** Gorizontal va og'ma asimptotani grafik kesishi mumkin; muhimi — cheksizlikdagi xatti-harakat.
- **Ekstremum jadvalida aniqlanmagan nuqtani unutish.** x = 1 da ishora o'zgarsa ham, u ekstremum emas — funksiya u yerda yo'q.
- **Faqat bir tomondan tekshirish.** x → +∞ va x → −∞ da asimptotalar har xil bo'lishi mumkin (3-misol).
:::

## O'zingizni tekshiring

::: test
? y = {x + 3|x − 2} ning vertikal asimptotasi:
- x = −3
+ x = 2
- y = 1
- yo'q
> Maxraj x = 2 da nol, surat 5 ≠ 0.
? y = {x^2 + 1|x} ning og'ma asimptotasi:
- y = x + 1
+ y = x
- y = 1
- yo'q
> {x^2 + 1|x} = x + {1|x}, demak y = x.
? y″ ishorasi «−» dan «+» ga o'zgaradigan nuqta:
- maksimum
- minimum
+ egilish nuqtasi
- asimptota
> Qavariqlik yo'nalishi almashadi.
? y = x^4 − 2x^2 qanday simmetriyaga ega?
+ juft — Oy ga nisbatan
- toq — koordinata boshiga nisbatan
- simmetriya yo'q
- y = x ga nisbatan
> Faqat juft darajalar: f(−x) = f(x).
:::

## Mustaqil mashqlar
