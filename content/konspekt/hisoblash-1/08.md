## Funksiyani to'liq tekshirish sxemasi

Grafik qurishdan oldin quyidagilar ketma-ket bajariladi:

1. **Aniqlanish sohasi**; uzilish nuqtalari.
2. **Juft-toqlik**, davriylik (grafik simmetriyasi).
3. **Koordinata o'qlari bilan kesishish** nuqtalari: x = 0 da y ni, y = 0 da x ni topish.
4. **Asimptotalar** (vertikal, gorizontal, og'ma).
5. **Birinchi hosila:** kritik nuqtalar, monotonlik oraliqlari, ekstremumlar.
6. **Ikkinchi hosila:** qavariqlik/botiqlik oraliqlari, egilish nuqtalari.
7. Natijalarni jadvalga yozish va **grafikni chizish**.

## Asimptotalar

- **Vertikal** x = a: lim_{x→a} f(x) = ±∞ (chap yoki o'ngdan). Ratsional funksiyada — maxrajning surat nolga aylantirmaydigan ildizlari.
- **Gorizontal** y = b: b = lim_{x→±∞} f(x) (chekli bo'lsa).
- **Og'ma** y = kx + b:

$$
k = lim_{x→∞} {f(x)|x},   b = lim_{x→∞} (f(x) − kx)
$$

Ratsional funksiyada surat darajasi maxrajnikidan aynan 1 ga katta bo'lsa, og'ma asimptota bo'linmaning butun qismi.

## Ishlangan misollar

> **1-misol.** y = x^3 − 3x funksiyani tekshiring va grafigini quring.
>
> **Yechim.**
> - Aniqlanish sohasi: (−∞; ∞). Toq funksiya: y(−x) = −y(x) — grafik koordinata boshiga simmetrik.
> - Kesishish: y = 0 ⇒ x(x^2 − 3) = 0 ⇒ x = 0, x = ±√3 ≈ ±1,73.
> - Asimptotalar yo'q (ko'phad).
> - y′ = 3x^2 − 3 = 0 ⇒ x = ±1. x = −1 da **max y = 2**, x = 1 da **min y = −2**.
> - y″ = 6x: x < 0 da qavariq (∩), x > 0 da botiq (∪), **egilish nuqtasi (0; 0)**.
>
> | x | (−∞; −1) | −1 | (−1; 0) | 0 | (0; 1) | 1 | (1; ∞) |
> |---|---|---|---|---|---|---|---|
> | y′ | + | 0 | − | − | − | 0 | + |
> | y″ | − | − | − | 0 | + | + | + |
> | y | ↗ ∩ | max 2 | ↘ ∩ | egilish 0 | ↘ ∪ | min −2 | ↗ ∪ |

> **2-misol.** y = {x^2|x − 1}.
>
> **Yechim.**
> - Aniqlanish sohasi: x ≠ 1. Juft ham, toq ham emas. Kesishish: (0; 0).
> - **Vertikal asimptota x = 1:** x → 1^{+} da y → +∞, x → 1^{−} da y → −∞.
> - **Og'ma asimptota:** {x^2|x − 1} = x + 1 + {1|x − 1}, demak **y = x + 1** (k = 1, b = 1).
> - y′ = {2x(x − 1) − x^2|(x − 1)^2} = {x(x − 2)|(x − 1)^2} = 0 ⇒ x = 0, x = 2. x = 0 da **max y = 0**, x = 2 da **min y = 4**.
> - y″ = {2|(x − 1)^3}: x > 1 da botiq (∪), x < 1 da qavariq (∩). Egilish nuqtasi yo'q (x = 1 — aniqlanish sohasiga kirmaydi).

> **3-misol.** y = x e^{−x}.
>
> **Yechim.**
> - Aniqlanish sohasi: (−∞; ∞); kesishish (0; 0).
> - lim_{x→+∞} x e^{−x} = 0 — **gorizontal asimptota y = 0** (x → +∞ da). x → −∞ da y → −∞.
> - y′ = (1 − x)e^{−x} = 0 ⇒ x = 1: **max y = {1|e} ≈ 0,37**.
> - y″ = (x − 2)e^{−x} = 0 ⇒ x = 2: **egilish nuqtasi (2; {2|e^2}) ≈ (2; 0,27)**. x < 2 da qavariq, x > 2 da botiq.

> **4-misol.** y = {2x^2 + 1|x^2 − 4} ning asimptotalari.
>
> **Yechim.** Vertikal: **x = ±2**. Gorizontal: lim_{x→∞} {2x^2 + 1|x^2 − 4} = **2**, ya'ni y = 2. Og'ma asimptota yo'q (gorizontal bor).

> **5-misol.** y = {x^3|x^2 + 1} ning og'ma asimptotasi.
>
> **Yechim.** k = lim {x^3|x(x^2 + 1)} = 1; b = lim ({x^3|x^2 + 1} − x) = lim {−x|x^2 + 1} = 0. **y = x**.

## Mustaqil ishlash uchun

1. y = x^4 − 2x^2 ni to'liq tekshiring. **Javob:** juft; max (0; 0), min (±1; −1); egilish nuqtalari x = ±{1|√3}.
2. y = {x|x^2 + 1}. **Javob:** toq; max: x = 1 da y = {1|2}; min: x = −1 da y = −{1|2}; gorizontal asimptota y = 0.
3. y = {x^2 + 1|x} ning asimptotalari. **Javob:** x = 0 va y = x.
4. y = {x − 1|x + 1} ning asimptotalari. **Javob:** x = −1, y = 1.
5. y = x ln x ning ekstremumi. **Javob:** min x = {1|e} da, y = −{1|e}.
