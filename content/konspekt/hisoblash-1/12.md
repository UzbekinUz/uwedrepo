## Ratsional kasrlar

{P(x)|Q(x)} da surat darajasi maxrajnikidan kichik bo'lsa — **to'g'ri**, aks holda **noto'g'ri** kasr. Noto'g'ri kasr ko'phadni ko'phadga bo'lish orqali yoyiladi:

$$
{P(x)|Q(x)} = S(x) + {R(x)|Q(x)}   (butun qism + to'g'ri kasr)
$$

### To'rt turdagi sodda kasrlar

::: formula
| Tur | Kasr | Integrali |
|---|---|---|
| I | {A|x − a} | A ln∣x − a∣ |
| II | {A|(x − a)^k}, k ≥ 2 | −{A|(k − 1)(x − a)^{k−1}} |
| III | {Mx + N|x^2 + px + q} (p^2 − 4q < 0) | ln va arctg |
| IV | {Mx + N|(x^2 + px + q)^k} | rekurrent formula |
:::

::: formula Algoritm
1. Kasr noto'g'ri bo'lsa — butun qismni ajratish.
2. Maxrajni ko'paytuvchilarga ajratish.
3. Noma'lum koeffitsiyentli sodda kasrlarga yoyish: (x − a) → {A|x − a}; (x − a)^2 → {A|x − a} + {B|(x − a)^2}; x^2 + px + q → {Mx + N|x^2 + px + q}.
4. Koeffitsiyentlarni topish: **xususiy qiymatlar** (x ga maxraj ildizlarini berish) yoki **koeffitsiyentlarni tenglashtirish**.
5. Har bir kasrni integrallash.
:::

::: eslatma Eng tez usul — ildizlarni qo'yish
3x + 5 = A(x + 3) + B(x − 1) tenglikka x = 1 ni qo'ysangiz B yo'qoladi va A darhol topiladi; x = −3 ni qo'ysangiz — B.
:::

## Ishlangan misollar: ratsional kasrlar

::: misol Ikki xil chiziqli ko'paytuvchi
∫ {3x + 5|x^2 + 2x − 3}dx
---
x^2 + 2x − 3 = (x − 1)(x + 3). {3x + 5|(x − 1)(x + 3)} = {A|x − 1} + {B|x + 3} ⇒ 3x + 5 = A(x + 3) + B(x − 1).

x = 1: 8 = 4A ⇒ A = 2. x = −3: −4 = −4B ⇒ B = 1.

**2 ln∣x − 1∣ + ln∣x + 3∣ + C**.
:::

::: misol Noto'g'ri kasr
∫ {x^2|x + 1}dx
---
Bo'lamiz: {x^2|x + 1} = x − 1 + {1|x + 1}. Javob: **{x^2|2} − x + ln∣x + 1∣ + C**.
:::

::: misol Karrali ildiz
∫ {x + 2|x(x − 1)^2}dx
---
{x + 2|x(x − 1)^2} = {A|x} + {B|x − 1} + {D|(x − 1)^2} ⇒ x + 2 = A(x − 1)^2 + Bx(x − 1) + Dx.

x = 0: A = 2. x = 1: D = 3. x^2 oldidagi koeffitsiyent: 0 = A + B ⇒ B = −2.

**2 ln∣x∣ − 2 ln∣x − 1∣ − {3|x − 1} + C**.
:::

::: misol Logistik o'sish integrali
∫ {dN|N(100 − N)}
---
{1|N(100 − N)} = {A|N} + {B|100 − N} ⇒ 1 = A(100 − N) + BN. N = 0: A = {1|100}; N = 100: B = {1|100}.

**{1|100}ln∣{N|100 − N}∣ + C** — shu integraldan logistik egri chiziq N(t) = {100|1 + Ke^{−t}} kelib chiqadi.
:::

::: misol To'liq kvadrat ajratish (III tur)
∫ {dx|x^2 + 4x + 13}
---
x^2 + 4x + 13 = (x + 2)^2 + 9 ⇒ **{1|3}arctg {x + 2|3} + C**.
:::

::: misol Suratda x bor (III tur)
∫ {2x + 3|x^2 + 2x + 5}dx
---
Maxraj hosilasi 2x + 2, shuning uchun 2x + 3 = (2x + 2) + 1:

$$
∫ {2x + 2|x^2 + 2x + 5}dx + ∫ {dx|(x + 1)^2 + 4} = ln(x^2 + 2x + 5) + {1|2}arctg {x + 1|2} + C
$$
:::

## Trigonometrik ifodalar

| Holat | Usul |
|---|---|
| sin^2 x, cos^2 x | darajani pasaytirish: sin^2 x = {1 − cos 2x|2}, cos^2 x = {1 + cos 2x|2} |
| sin yoki cos toq darajada | bitta ko'paytuvchini ajratib, u = cos x (yoki sin x) |
| sin ax·cos bx | ko'paytmani yig'indiga: {1|2}[sin(a + b)x + sin(a − b)x] |
| har qanday R(sin x, cos x) | universal almashtirish t = tg {x|2} |

::: formula Universal almashtirish t = tg (x/2)
$$
sin x = {2t|1 + t^2},   cos x = {1 − t^2|1 + t^2},   dx = {2dt|1 + t^2}
$$
:::

::: misol Darajani pasaytirish
∫ sin^2 x dx
---
∫ {1 − cos 2x|2}dx = **{x|2} − {sin 2x|4} + C**.
:::

::: misol Toq daraja
∫ sin^3 x dx
---
sin^3 x = (1 − cos^2 x)sin x; u = cos x, du = −sin x dx: −∫ (1 − u^2)du = **−cos x + {cos^3 x|3} + C**.
:::

::: misol Ko'paytmani yig'indiga
∫ sin 3x cos x dx
---
sin 3x cos x = {1|2}(sin 4x + sin 2x) ⇒ **−{cos 4x|8} − {cos 2x|4} + C**.
:::

::: misol Universal almashtirish
∫ {dx|1 + cos x}
---
1 + cos x = {2|1 + t^2}, dx = {2dt|1 + t^2} ⇒ ∫ dt = t + C = **tg {x|2} + C**.
:::

## Irratsional ifodalar

| Ifoda | Almashtirish |
|---|---|
| R(x, ⁿ√x, ᵐ√x) | x = t^k, k = EKUK(n, m) |
| R(x, √(ax + b)) | t = √(ax + b) |
| √(a^2 − x^2) | x = a sin t |
| √(x^2 + a^2) | x = a tg t |

::: misol Seminardagi n = 6 misol
∫ {dx|√x + ∛x}
---
x = t^6 (EKUK(2; 3) = 6): dx = 6t^5dt, √x = t^3, ∛x = t^2.

$$
∫ {6t^5|t^3 + t^2}dt = 6∫ {t^3|t + 1}dt = 6∫ (t^2 − t + 1 − {1|t + 1})dt
= 2t^3 − 3t^2 + 6t − 6 ln∣t + 1∣ + C,   t = ⁶√x
$$
:::

::: misol Chiziqli ildiz
∫ x√(x − 1)dx
---
t = √(x − 1), x = t^2 + 1, dx = 2t dt: 2∫ (t^4 + t^2)dt = **{2t^5|5} + {2t^3|3} + C**, t = √(x − 1).
:::

::: xato
- **Noto'g'ri kasrni darhol yoyish.** Avval butun qismni ajrating — aks holda koeffitsiyentlar topilmaydi.
- **Karrali ildizda bitta kasr yozish.** (x − 1)^2 uchun **ikkita** kasr kerak: {B|x − 1} + {D|(x − 1)^2}.
- **Javobda t ni qoldirib ketish.** Oxirida eski o'zgaruvchiga qayting.
:::

## O'zingizni tekshiring

::: test
? {5|(x − 2)(x + 3)} = {A|x − 2} + {B|x + 3} da A = ?
+ 1
- 5
- −1
- {1|5}
> x = 2: 5 = A·5 ⇒ A = 1 (va B = −1).
? ∫ {dx|x^2 + 1} = ?
- ln(x^2 + 1) + C
+ arctg x + C
- {1|2x} + C
- arcsin x + C
> Jadval integrali, a = 1.
? ∫ cos^2 x dx = ?
- {cos^3 x|3} + C
+ {x|2} + {sin 2x|4} + C
- sin^2 x + C
- {x|2} − {sin 2x|4} + C
> cos^2 x = {1 + cos 2x|2}.
? ∫ {dx|√x + 1} uchun qulay almashtirish:
- x = sin t
+ t = √x
- t = x + 1
- x = tg t
> t = √x, dx = 2t dt — ildiz yo'qoladi.
:::

## Mustaqil mashqlar

::: mashq
∫ {dx|x^2 − 1} || {1|2}ln∣{x − 1|x + 1}∣ + C
∫ {x + 4|x^2 + x − 2}dx || {5|3}ln∣x − 1∣ − {2|3}ln∣x + 2∣ + C
∫ {dx|x^2 + 6x + 10} || arctg(x + 3) + C
∫ cos^3 x dx || sin x − {sin^3 x|3} + C
∫ {dx|1 + √x} || 2√x − 2 ln(1 + √x) + C
:::


::: xulosa
- Ratsional kasr: butun qism → maxrajni ajratish → sodda kasrlar → ln va arctg.
- Trigonometrik: darajani pasaytirish, toq darajada u = cos x, universal t = tg {x|2}.
- Irratsional: ildizni yo'qotadigan almashtirish (x = t^k, t = √(ax + b)).
:::
