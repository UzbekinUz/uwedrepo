## Kasr-ratsional funksiyalar

{P_{m}(x)|Q_{n}(x)} ko'rinishidagi kasr (P, Q — ko'phadlar) **ratsional kasr** deyiladi. m < n bo'lsa — **to'g'ri**, aks holda **noto'g'ri** kasr.

**Noto'g'ri kasr** avval ko'phadni ko'phadga bo'lish orqali butun qism va to'g'ri kasrga ajratiladi:

$$
{P(x)|Q(x)} = S(x) + {R(x)|Q(x)}
$$

### Eng sodda kasrlar (4 tur)

$$
I. {A|x − a}   II. {A|(x − a)^{k}}   III. {Mx + N|x^2 + px + q}   IV. {Mx + N|(x^2 + px + q)^{k}}
$$

(III, IV da x^2 + px + q ning haqiqiy ildizi yo'q: p^2 − 4q < 0.)

$$
∫ {A|x − a} dx = A ln∣x − a∣ + C,   ∫ {A|(x − a)^{k}} dx = −{A|(k − 1)(x − a)^{k−1}} + C
$$

III tur: maxrajdan to'liq kvadrat ajratiladi, surat esa «maxraj hosilasi + son» ko'rinishiga keltiriladi — natijada ln va arctg chiqadi.

### Ratsional kasrni integrallash algoritmi

1. Kasr noto'g'ri bo'lsa — butun qismini ajratish.
2. Maxrajni ko'paytuvchilarga ajratish.
3. Kasrni noma'lum koeffitsiyentli sodda kasrlar yig'indisiga yoyish: har bir (x − a) ga {A|x − a}, (x − a)^{2} ga {A|x − a} + {B|(x − a)^2}, x^2 + px + q ga {Mx + N|x^2 + px + q}.
4. Koeffitsiyentlarni topish: umumiy maxrajga keltirib, **koeffitsiyentlarni tenglashtirish** yoki x ga **xususiy qiymatlar** (maxraj ildizlari) berish usuli.
5. Har bir sodda kasrni integrallash.

## Ishlangan misollar: ratsional funksiyalar

> **1-misol.** ∫ {3x + 5|x^2 + 2x − 3} dx.
>
> **Yechim.** x^2 + 2x − 3 = (x − 1)(x + 3). {3x + 5|(x − 1)(x + 3)} = {A|x − 1} + {B|x + 3} ⇒ 3x + 5 = A(x + 3) + B(x − 1).
> x = 1 da 8 = 4A ⇒ A = 2; x = −3 da −4 = −4B ⇒ B = 1.
> Javob: **2 ln∣x − 1∣ + ln∣x + 3∣ + C**.

> **2-misol** (noto'g'ri kasr). ∫ {x^2|x + 1} dx.
>
> **Yechim.** Bo'lish: {x^2|x + 1} = x − 1 + {1|x + 1}. Javob: **{x^2|2} − x + ln∣x + 1∣ + C**.

> **3-misol** (karrali ildiz). ∫ {x + 2|x(x − 1)^2} dx.
>
> **Yechim.** {x + 2|x(x − 1)^2} = {A|x} + {B|x − 1} + {D|(x − 1)^2} ⇒ x + 2 = A(x − 1)^2 + Bx(x − 1) + Dx.
> x = 0: A = 2; x = 1: D = 3; x^2 oldidagi koeffitsiyentlar: 0 = A + B ⇒ B = −2.
> Javob: **2 ln∣x∣ − 2 ln∣x − 1∣ − {3|x − 1} + C**.

> **4-misol** (III tur). ∫ {dx|x^2 + 4x + 13}.
>
> **Yechim.** x^2 + 4x + 13 = (x + 2)^2 + 9. ∫ {dx|(x + 2)^2 + 3^2} = **{1|3} arctg {x + 2|3} + C**.

> **5-misol** (III tur, suratda x). ∫ {2x + 3|x^2 + 2x + 5} dx.
>
> **Yechim.** Maxraj hosilasi 2x + 2, shuning uchun 2x + 3 = (2x + 2) + 1:
> $$
> ∫ {2x + 2|x^2 + 2x + 5} dx + ∫ {dx|(x + 1)^2 + 4} = ln(x^2 + 2x + 5) + {1|2} arctg {x + 1|2} + C
> $$

## Trigonometrik ifodalarni integrallash

- **sin^{2}x, cos^{2}x** — darajani pasaytirish: sin^2 x = {1 − cos 2x|2}, cos^2 x = {1 + cos 2x|2}.
- **Toq daraja** (masalan sin^{3}x): bitta ko'paytuvchini ajratib, qolganini cos x orqali ifodalash, u = cos x.
- **Ko'paytmalar:** sin a cos b = {1|2}[sin(a + b) + sin(a − b)] kabi formulalar.
- **Universal almashtirish** t = tg {x|2}: sin x = {2t|1 + t^2}, cos x = {1 − t^2|1 + t^2}, dx = {2 dt|1 + t^2} — har qanday R(sin x, cos x) ni ratsional kasrga keltiradi.

> **6-misol.** ∫ sin^2 x dx.
>
> **Yechim.** ∫ {1 − cos 2x|2} dx = **{x|2} − {sin 2x|4} + C**.

> **7-misol.** ∫ sin^3 x dx.
>
> **Yechim.** sin^3 x = (1 − cos^2 x) sin x. u = cos x, du = −sin x dx: −∫ (1 − u^2) du = **−cos x + {cos^3 x|3} + C**.

> **8-misol.** ∫ sin 3x cos x dx.
>
> **Yechim.** sin 3x cos x = {1|2}(sin 4x + sin 2x). Javob: **−{cos 4x|8} − {cos 2x|4} + C**.

> **9-misol** (universal almashtirish). ∫ {dx|1 + cos x}.
>
> **Yechim.** 1 + cos x = 1 + {1 − t^2|1 + t^2} = {2|1 + t^2}, dx = {2 dt|1 + t^2}. Integral ∫ dt = t + C = **tg {x|2} + C**.

## Irratsional ifodalarni integrallash

Asosiy g'oya — ildizlardan qutuladigan almashtirish:

- ∫ R(x, ⁿ√x, ᵐ√x) dx: x = t^{k}, k — n va m ning EKUKi.
- ∫ R(x, √(ax + b)) dx: t = √(ax + b).
- √(a^2 − x^2) — x = a sin t; √(x^2 + a^2) — x = a tg t (trigonometrik almashtirishlar).

> **10-misol** (seminardagi n = 6 misol). ∫ {dx|√x + ∛x}.
>
> **Yechim.** x = t^6 (6 = EKUK(2; 3)), dx = 6t^5 dt, √x = t^3, ∛x = t^2:
> $$
> ∫ {6t^5|t^3 + t^2} dt = 6∫ {t^3|t + 1} dt = 6∫ (t^2 − t + 1 − {1|t + 1}) dt
> = 2t^3 − 3t^2 + 6t − 6 ln∣t + 1∣ + C,   t = ⁶√x
> $$

> **11-misol.** ∫ x√(x − 1) dx.
>
> **Yechim.** t = √(x − 1), x = t^2 + 1, dx = 2t dt: ∫ (t^2 + 1)·t·2t dt = 2∫ (t^4 + t^2) dt = **{2t^5|5} + {2t^3|3} + C**, t = √(x − 1).

## Seminar bilan bog'liqlik

«Семинар 12» (CALC_S10) faylida sodda kasrlarni integrallash (4 ta namunaviy misol), butun qismni ajratish, sodda kasrlarga yoyish va irratsional ifodalar (n = 6 almashtirish) bo'yicha misollar bor. Uy vazifasi — har bo'limdan 3 tadan misol.

## Mustaqil ishlash uchun

1. ∫ {dx|x^2 − 1}. **Javob:** {1|2} ln∣{x − 1|x + 1}∣ + C.
2. ∫ {x + 4|x^2 + x − 2} dx. **Javob:** {5|3} ln∣x − 1∣ − {2|3} ln∣x + 2∣ + C.
3. ∫ cos^2 x dx. **Javob:** {x|2} + {sin 2x|4} + C.
4. ∫ {dx|x^2 + 6x + 10}. **Javob:** arctg(x + 3) + C.
5. ∫ {dx|1 + √x}. **Javob:** 2√x − 2 ln(1 + √x) + C.
