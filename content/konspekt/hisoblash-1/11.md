## Boshlang'ich funksiya va aniqmas integral

Agar F′(x) = f(x) bo'lsa, F(x) funksiya f(x) ning **boshlang'ich funksiyasi** deyiladi. Bitta funksiyaning boshlang'ich funksiyalari bir-biridan o'zgarmas songa farq qiladi. Ularning umumiy ko'rinishi **aniqmas integral**:

$$
∫ f(x) dx = F(x) + C
$$

Integrallash — differensiallashga teskari amal. Natijani har doim **differensiallab tekshirish** mumkin: (F(x) + C)′ = f(x).

## Xossalari

$$
∫ (f ± g) dx = ∫ f dx ± ∫ g dx,   ∫ k·f dx = k ∫ f dx
(∫ f dx)′ = f,   ∫ dF = F + C
$$

## Asosiy integrallar jadvali

| Integral | Natija | Integral | Natija |
|---|---|---|---|
| ∫ x^{n} dx (n ≠ −1) | {x^{n+1}|n + 1} + C | ∫ sin x dx | −cos x + C |
| ∫ {dx|x} | ln∣x∣ + C | ∫ cos x dx | sin x + C |
| ∫ e^{x} dx | e^{x} + C | ∫ {dx|cos^2 x} | tg x + C |
| ∫ a^{x} dx | {a^{x}|ln a} + C | ∫ {dx|sin^2 x} | −ctg x + C |
| ∫ {dx|x^2 + a^2} | {1|a} arctg {x|a} + C | ∫ {dx|√(a^2 − x^2)} | arcsin {x|a} + C |
| ∫ {dx|x^2 − a^2} | {1|2a} ln∣{x − a|x + a}∣ + C | ∫ {dx|√(x^2 ± a^2)} | ln∣x + √(x^2 ± a^2)∣ + C |

Foydali qoida: ∫ f(kx + b) dx = {1|k} F(kx + b) + C.

## Integrallash usullari

- **Bevosita integrallash:** ifodani almashtirib (qavslarni ochib, bo'lib), jadval integrallariga keltirish.
- **O'zgaruvchini almashtirish (o'rniga qo'yish):** ∫ f(g(x))·g′(x) dx = ∫ f(u) du, bunda u = g(x). Integral ostida biror funksiya va uning hosilasi (ko'paytuvchi aniqligida) bo'lsa qo'llanadi.
- **Bo'laklab integrallash:**

$$
∫ u dv = uv − ∫ v du
$$

Odatda u sifatida differensiallaganda soddalashadigan funksiya (ko'phad, ln x, arctg x) olinadi: ∫ xe^{x} dx, ∫ x sin x dx, ∫ ln x dx, ∫ x^{n} ln x dx.

## Ishlangan misollar

> **1-misol.** ∫ (3x^2 − 4x + 5) dx.
>
> **Yechim.** 3·{x^3|3} − 4·{x^2|2} + 5x + C = **x^3 − 2x^2 + 5x + C**.

> **2-misol.** ∫ (√x + {1|x^2}) dx.
>
> **Yechim.** ∫ x^{1/2} dx + ∫ x^{−2} dx = **{2|3}x^{3/2} − {1|x} + C**.

> **3-misol.** ∫ {(x^2 + 1)^2|x} dx.
>
> **Yechim.** Qavsni ochib, bo'lamiz: {x^4 + 2x^2 + 1|x} = x^3 + 2x + {1|x}. Integral: **{x^4|4} + x^2 + ln∣x∣ + C**.

> **4-misol** (almashtirish). ∫ 2x(x^2 + 1)^5 dx.
>
> **Yechim.** u = x^2 + 1, du = 2x dx: ∫ u^5 du = {u^6|6} + C = **{(x^2 + 1)^6|6} + C**.

> **5-misol.** a) ∫ cos(3x + 1) dx; b) ∫ x e^{x^2} dx; c) ∫ {ln x|x} dx.
>
> **Yechim.**
> - a) **{1|3} sin(3x + 1) + C**.
> - b) u = x^2, du = 2x dx: {1|2}∫ e^{u} du = **{1|2} e^{x^2} + C**.
> - c) u = ln x, du = {dx|x}: ∫ u du = **{ln^2 x|2} + C**.

> **6-misol.** ∫ {dx|x^2 + 9} va ∫ tg x dx.
>
> **Yechim.** Jadvaldan a = 3: **{1|3} arctg {x|3} + C**. Ikkinchisi: tg x = {sin x|cos x}, u = cos x, du = −sin x dx: −∫ {du|u} = **−ln∣cos x∣ + C**.

> **7-misol** (bo'laklab). ∫ x e^{x} dx.
>
> **Yechim.** u = x, dv = e^{x} dx ⇒ du = dx, v = e^{x}. ∫ x e^{x} dx = x e^{x} − ∫ e^{x} dx = **(x − 1)e^{x} + C**.

> **8-misol** (bo'laklab). a) ∫ x cos x dx; b) ∫ ln x dx; c) ∫ x ln x dx.
>
> **Yechim.**
> - a) u = x, dv = cos x dx: x sin x − ∫ sin x dx = **x sin x + cos x + C**.
> - b) u = ln x, dv = dx: x ln x − ∫ x·{1|x} dx = **x ln x − x + C**.
> - c) u = ln x, dv = x dx, v = {x^2|2}: {x^2|2} ln x − ∫ {x|2} dx = **{x^2|2} ln x − {x^2|4} + C**.

> **Tekshirish namunasi** (7-misol): ((x − 1)e^{x})′ = e^{x} + (x − 1)e^{x} = x e^{x} ✓.
