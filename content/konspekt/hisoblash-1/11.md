::: hayot Hayotda qayerda kerak?
Hosila «umumiydan marjinalga» olib boradi: xarajatdan marjinal xarajatga. Ko'pincha esa teskari masala turadi: buxgalteriya **har bir qo'shimcha mahsulot** narxini (MC) biladi, umumiy xarajat C(x) ni esa tiklash kerak. Yoki tezlik ma'lum — bosib o'tilgan yo'lni topish kerak. Hosilaga **teskari** amal — **integrallash**.
:::

## Boshlang'ich funksiya

::: tushuncha Ta'rif
F′(x) = f(x) bo'lsa, F — f ning **boshlang'ich funksiyasi**. Barcha boshlang'ich funksiyalar to'plami — **aniqmas integral**:
$$
∫ f(x) dx = F(x) + C
$$
:::

::: oddiy
Nega «+ C»? Chunki o'zgarmasning hosilasi nol: x^2, x^2 + 5, x^2 − 3 — hammasining hosilasi 2x. Grafikda bular bir-biridan yuqoriga-pastga surilgan bir xil egri chiziqlar.
:::

::: grafik x: -2.5..2.5, y: -3..7 | ∫ 2x dx = x² + C: C har xil — bir oila egri chiziqlar
y = x^2 | teal | C = 0
y = x^2 + 2 | amber | C = 2
y = x^2 - 2 | violet | C = −2
:::

::: eslatma Oltin qoida
Integralning javobini **har doim differensiallab tekshiring**: (F + C)′ = f bo'lishi kerak. Bu imtihonda xatoni topishning eng tez yo'li.
:::

## Xossalar

::: formula
$$
∫ (f ± g)dx = ∫ f dx ± ∫ g dx,   ∫ k·f dx = k∫ f dx
(∫ f dx)′ = f,   ∫ dF = F + C
∫ f(kx + b)dx = {1|k}F(kx + b) + C
$$
:::

## Integrallar jadvali

| Integral | Natija | Integral | Natija |
|---|---|---|---|
| ∫ x^n dx (n ≠ −1) | {x^{n+1}|n + 1} + C | ∫ sin x dx | −cos x + C |
| ∫ {dx|x} | ln∣x∣ + C | ∫ cos x dx | sin x + C |
| ∫ e^x dx | e^x + C | ∫ {dx|cos^2 x} | tg x + C |
| ∫ a^x dx | {a^x|ln a} + C | ∫ {dx|sin^2 x} | −ctg x + C |
| ∫ {dx|x^2 + a^2} | {1|a} arctg {x|a} + C | ∫ {dx|√(a^2 − x^2)} | arcsin {x|a} + C |
| ∫ {dx|x^2 − a^2} | {1|2a} ln∣{x − a|x + a}∣ + C | ∫ {dx|√(x^2 ± a^2)} | ln∣x + √(x^2 ± a^2)∣ + C |

## Uch asosiy usul

::: formula 1. Bevosita integrallash
Ifodani almashtirib (qavslarni ochib, hadlab bo'lib) jadval integrallariga keltirish.
:::

::: formula 2. O'zgaruvchini almashtirish
$$
∫ f(g(x))·g′(x)dx = ∫ f(u)du,   u = g(x)
$$
**Belgisi:** integral ostida biror funksiya va uning hosilasi (ko'paytuvchi aniqligida) bor.
:::

::: formula 3. Bo'laklab integrallash
$$
∫ u dv = uv − ∫ v du
$$
**u** sifatida differensiallaganda soddalashadiganini oling: ko'phad, ln x, arctg x. **dv** — oson integrallanadigan qism: e^x dx, sin x dx, x^n dx.
:::

| Integral turi | u | dv |
|---|---|---|
| ∫ P(x)e^x dx, ∫ P(x)sin x dx | P(x) | e^x dx, sin x dx |
| ∫ P(x)ln x dx | ln x | P(x)dx |
| ∫ P(x)arctg x dx | arctg x | P(x)dx |

## Ishlangan misollar

::: misol Bevosita
∫ (3x^2 − 4x + 5)dx
---
3·{x^3|3} − 4·{x^2|2} + 5x + C = **x^3 − 2x^2 + 5x + C**.
:::

::: misol Darajaga keltirish
∫ (√x + {1|x^2})dx
---
∫ x^{1/2}dx + ∫ x^{−2}dx = **{2|3}x^{3/2} − {1|x} + C**.
:::

::: misol Qavsni ochish
∫ {(x^2 + 1)^2|x}dx
---
{x^4 + 2x^2 + 1|x} = x^3 + 2x + {1|x} ⇒ **{x^4|4} + x^2 + ln∣x∣ + C**.
:::

::: misol Almashtirish
∫ 2x(x^2 + 1)^5 dx
---
u = x^2 + 1, du = 2x dx: ∫ u^5 du = {u^6|6} + C = **{(x^2 + 1)^6|6} + C**.
:::

::: misol Almashtirish: uch xil holat
a) ∫ cos(3x + 1)dx; b) ∫ xe^{x^2}dx; c) ∫ {ln x|x}dx.
---
a) **{1|3}sin(3x + 1) + C**.

b) u = x^2, du = 2x dx: **{1|2}e^{x^2} + C**.

c) u = ln x, du = {dx|x}: **{ln^2 x|2} + C**.
:::

::: misol Jadval va tg x
a) ∫ {dx|x^2 + 9}; b) ∫ tg x dx.
---
a) a = 3: **{1|3}arctg {x|3} + C**.

b) tg x = {sin x|cos x}, u = cos x, du = −sin x dx: −∫ {du|u} = **−ln∣cos x∣ + C**.
:::

::: misol Bo'laklab
∫ xe^x dx
---
u = x, dv = e^x dx ⇒ du = dx, v = e^x.

∫ xe^x dx = xe^x − ∫ e^x dx = **(x − 1)e^x + C**.

Tekshirish: ((x − 1)e^x)′ = e^x + (x − 1)e^x = xe^x ✓.
:::

::: misol Bo'laklab: uch misol
a) ∫ x cos x dx; b) ∫ ln x dx; c) ∫ x ln x dx.
---
a) u = x, dv = cos x dx: **x sin x + cos x + C**.

b) u = ln x, dv = dx: x ln x − ∫ dx = **x ln x − x + C**.

c) u = ln x, dv = x dx: **{x^2|2}ln x − {x^2|4} + C**.
:::

::: misol Iqtisodiy: xarajatni tiklash
Marjinal xarajat MC(x) = 3x^2 − 4x + 10, doimiy xarajat 50. C(x) = ?
---
C(x) = ∫ (3x^2 − 4x + 10)dx = x^3 − 2x^2 + 10x + K. Doimiy xarajat C(0) = 50 ⇒ K = 50.

**C(x) = x^3 − 2x^2 + 10x + 50**.
:::

::: xato
- **«+ C» ni yozmaslik.** Aniqmas integral — funksiyalar oilasi.
- **∫ {dx|x} = {x^0|0}.** n = −1 da daraja formulasi ishlamaydi: javob ln∣x∣.
- **∫ f·g dx = ∫ f dx·∫ g dx.** Ko'paytmani bunday integrallab bo'lmaydi — almashtirish yoki bo'laklab usuli kerak.
:::

## O'zingizni tekshiring

::: test
? ∫ x^3 dx = ?
- 3x^2 + C
+ {x^4|4} + C
- x^4 + C
- {x^3|3} + C
> {x^{n+1}|n + 1}, n = 3.
? ∫ e^{2x}dx = ?
- 2e^{2x} + C
- e^{2x} + C
+ {1|2}e^{2x} + C
- {e^{2x + 1}|2x + 1} + C
> ∫ f(kx)dx = {1|k}F(kx).
? ∫ x sin x dx uchun bo'laklab integrallashda u = ?
+ x
- sin x
- x sin x
- cos x
> Ko'phadni u qilib olamiz — differensiallanganda 1 bo'ladi.
? ∫ {2x|x^2 + 1}dx = ?
- arctg x + C
+ ln(x^2 + 1) + C
- {1|x^2 + 1} + C
- 2 ln∣x∣ + C
> Surat — maxrajning hosilasi: ∫ {du|u} = ln∣u∣.
:::

## Mustaqil mashqlar

::: mashq
∫ (2e^x − {3|x})dx || 2e^x − 3 ln∣x∣ + C
∫ sin^4 x cos x dx || {sin^5 x|5} + C
∫ {x|x^2 + 4}dx || {1|2}ln(x^2 + 4) + C

::: xulosa
- ∫ f dx = F + C, bunda F′ = f. Javobni differensiallab tekshiring.
- Usul tanlash: jadvalga keltirsa bo'ladimi → funksiya va uning hosilasi bormi (almashtirish) → ko'phad × e^x/sin/ln (bo'laklab).
- Iqtisodda: C(x) = ∫ MC dx + doimiy xarajat.
:::
