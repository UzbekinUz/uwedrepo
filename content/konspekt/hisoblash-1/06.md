## Asosiy teoremalar

::: teorema Ferma teoremasi
f ichki c nuqtada lokal ekstremumga erishsa va u yerda differensiallanuvchi bo'lsa, **f′(c) = 0** — urinma gorizontal.
:::

::: teorema Roll teoremasi
f [a; b] da uzluksiz, (a; b) da differensiallanuvchi va **f(a) = f(b)** bo'lsa, kamida bitta c ∈ (a; b) da **f′(c) = 0**.
:::

::: teorema Lagranj teoremasi (o'rta qiymat haqida)
f [a; b] da uzluksiz va (a; b) da differensiallanuvchi bo'lsa, kamida bitta c ∈ (a; b) uchun:
$$
f′(c) = {f(b) − f(a)|b − a}
$$
:::

::: grafik x: -0.3..2.4, y: -1..9 | Lagranj: kesuvchiga parallel urinma bor (f = x³, [0; 2], c = 2/√3 ≈ 1,155)
y = x^3 | teal | y = x³
y = 4x | violet | kesuvchi, qiyalik 4
y = 4x - 3.0792 | amber | urinma x = c da, qiyalik 4
nuqta 0, 0 | A
nuqta 2, 8 | B
nuqta 1.1547, 1.5396 | c
:::

**Natija:** (a; b) da f′ > 0 bo'lsa f o'suvchi, f′ < 0 bo'lsa kamayuvchi, f′ ≡ 0 bo'lsa f o'zgarmas.

::: teorema Koshi teoremasi
f, g [a; b] da uzluksiz, (a; b) da differensiallanuvchi va g′ ≠ 0 bo'lsa:
$$
{f(b) − f(a)|g(b) − g(a)} = {f′(c)|g′(c)}
$$
:::

## Lopital qoidasi

::: formula
{0|0} yoki {∞|∞} aniqmaslikda:
$$
lim_{x→a} {f(x)|g(x)} = lim_{x→a} {f′(x)|g′(x)}
$$
:::

::: xato Diqqat
Surat va maxraj **alohida-alohida** differensiallanadi — bu bo'linmaning hosilasi emas! Va qoida faqat aniqmaslikda ishlaydi: {sin x|x + 1} ni x → 0 da Lopital bilan hisoblasangiz, noto'g'ri javob olasiz.
:::

| Aniqmaslik | Qanday {0|0} yoki {∞|∞} ga keltiriladi |
|---|---|
| 0·∞ | f·g = {f|1/g} |
| ∞ − ∞ | umumiy maxrajga keltirish |
| 0^0, 1^{∞}, ∞^{0} | y = f^g ⇒ ln y = g·ln f, avval ln y ning limiti |

::: grafik x: 0..12, y: 0..2 | O'sish tezligi: ln x ≪ x ≪ eˣ — shuning uchun ln x / x → 0, x²/eˣ → 0
y = ln(x)/x | violet | ln x / x
y = x^2/e^x | rose | x² / eˣ
:::

## Teylor formulasi

::: formula Makloren formulasi
$$
f(x) ≈ f(0) + f′(0)x + {f″(0)|2!}x^2 + … + {f^{(n)}(0)|n!}x^n
$$
| Funksiya | Yoyilma |
|---|---|
| e^x | 1 + x + {x^2|2} + {x^3|6} + … |
| sin x | x − {x^3|6} + {x^5|120} − … |
| cos x | 1 − {x^2|2} + {x^4|24} − … |
| ln(1 + x) | x − {x^2|2} + {x^3|3} − … |
:::

::: grafik x: -3..3, y: -1..10 | eˣ va uning Makloren ko'phadlari: hadlar ko'paygan sari yaqinlik oshadi
y = e^x | teal | eˣ
y = 1 + x | amber | 1 + x
y = 1 + x + x^2/2 + x^3/6 | violet | 3-darajali ko'phad
:::

## Ishlangan misollar

::: misol Roll teoremasi
f(x) = x^2 − 4x + 3 uchun [1; 3] da c ni toping.
---
f(1) = 0 = f(3) — shart bajariladi. f′(c) = 2c − 4 = 0 ⇒ **c = 2**.
:::

::: misol Lagranj teoremasi
f(x) = x^3, [0; 2].
---
{f(2) − f(0)|2 − 0} = {8|2} = 4. 3c^2 = 4 ⇒ c = {2|√3} ≈ **1,155** (grafikka qarang).
:::

::: misol Lagranj teoremasi, ildiz
f(x) = √x, [1; 4].
---
{2 − 1|4 − 1} = {1|3}; {1|2√c} = {1|3} ⇒ √c = {3|2} ⇒ **c = {9|4}**.
:::

::: misol Tengsizlikni isbotlash
∣sin a − sin b∣ ≤ ∣a − b∣ ekanini isbotlang.
---
Lagranj bo'yicha sin a − sin b = cos c·(a − b). ∣cos c∣ ≤ 1 bo'lgani uchun ∣sin a − sin b∣ ≤ ∣a − b∣. ∎
:::

::: misol Koshi teoremasi
f = x^2, g = x^3, [1; 2].
---
{4 − 1|8 − 1} = {3|7}; {2c|3c^2} = {2|3c}. {2|3c} = {3|7} ⇒ **c = {14|9}** ≈ 1,56.
:::

::: misol Lopital, {0|0}
lim_{x→0} {e^x − 1 − x|x^2}
---
Ikki marta qo'llaymiz: {e^x − 1|2x} → {e^x|2} → **{1|2}**.
:::

::: misol Lopital, {∞|∞}
a) lim_{x→∞} {ln x|x}; b) lim_{x→∞} {x^2|e^x}.
---
a) {1/x|1} → **0**. b) {2x|e^x} → {2|e^x} → **0**. Ko'rsatkichli funksiya har qanday darajadan tez o'sadi.
:::

::: misol 0·∞
lim_{x→0^{+}} x ln x
---
{ln x|1/x} — {∞|∞}. Lopital: {1/x|−1/x^2} = −x → **0**.
:::

::: misol ∞ − ∞
lim_{x→0} ({1|x} − {1|sin x})
---
Umumiy maxraj: {sin x − x|x sin x} — {0|0}. Lopital: {cos x − 1|sin x + x cos x} — yana {0|0}. Yana bir marta: {−sin x|2cos x − x sin x} → {0|2} = **0**.
:::

::: misol 0^0
lim_{x→0^{+}} x^x
---
ln y = x ln x → 0 (8-misol) ⇒ y → e^0 = **1**.
:::

::: misol Teylor bilan hisoblash
e^{0,1} ni taqriban hisoblang.
---
1 + 0,1 + {0,01|2} + {0,001|6} ≈ **1,10517** (aniq: 1,105171…).
:::

::: xato
- **Lopitalni aniqmaslik bo'lmaganda qo'llash.** Avval qiymatni qo'yib tekshiring.
- **({f|g})′ formulasini ishlatish.** Lopitalda f′ va g′ alohida olinadi.
- **Lagranjda c ni kesmadan tashqarida olish.** c ∈ (a; b) bo'lishi shart: ±{2|√3} dan faqat musbati mos.
:::

::: xulosa
- **Lagranj:** f′(c) = {f(b) − f(a)|b − a} — o'rtacha tezlik qaysidir lahzada oniy tezlikka teng.

- **Teylor:** murakkab funksiyani ko'phad bilan yaqinlashtirish.
