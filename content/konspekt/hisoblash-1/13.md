## Aniq integral ta'rifi

[a; b] kesmani x_{0} = a < x_{1} < … < x_{n} = b nuqtalar bilan n bo'lakka bo'lamiz, har bir bo'lakdan c_{i} nuqta tanlab, **integral yig'indi (Riman yig'indisi)** tuzamiz:

$$
S_{n} = f(c_{1})Δx_{1} + f(c_{2})Δx_{2} + … + f(c_{n})Δx_{n}
$$

Eng katta bo'lak uzunligi nolga intilganda S_{n} ning limiti **aniq integral** deyiladi:

$$
∫_{a}^{b} f(x) dx = lim_{max Δx_{i}→0} S_{n}
$$

**Geometrik ma'nosi:** f(x) ≥ 0 bo'lsa — y = f(x) grafigi, Ox o'qi va x = a, x = b chiziqlar bilan chegaralangan **egri chiziqli trapetsiya yuzasi**. Ox o'qidan pastdagi qismlar «−» ishora bilan hisoblanadi.

Aniqmas integraldan farqi: natija — **son** (funksiya emas).

## Xossalari

$$
∫_{a}^{a} f dx = 0,   ∫_{a}^{b} f dx = −∫_{b}^{a} f dx,   ∫_{a}^{b} f dx = ∫_{a}^{c} f dx + ∫_{c}^{b} f dx
∫_{a}^{b} (αf + βg) dx = α∫_{a}^{b} f dx + β∫_{a}^{b} g dx
$$

- f ≤ g bo'lsa ∫_{a}^{b} f ≤ ∫_{a}^{b} g.
- Toq funksiya uchun ∫_{−a}^{a} f dx = 0; juft funksiya uchun ∫_{−a}^{a} f dx = 2∫_{0}^{a} f dx.
- **O'rta qiymat teoremasi:** shunday c ∈ [a; b] borki, ∫_{a}^{b} f dx = f(c)(b − a). Funksiyaning o'rtacha qiymati: {1|b − a}∫_{a}^{b} f dx.

## Nyuton–Leybnits formulasi

F — f ning boshlang'ich funksiyasi bo'lsa:

$$
∫_{a}^{b} f(x) dx = F(b) − F(a) = F(x) |_{a}^{b}
$$

**Yuqori chegarasi o'zgaruvchi integral:** ({d|dx}) ∫_{a}^{x} f(t) dt = f(x). Umumiyroq: ({d|dx}) ∫_{a}^{g(x)} f(t) dt = f(g(x))·g′(x).

## Aniq integralda o'zgaruvchini almashtirish va bo'laklab integrallash

- Almashtirishda **chegaralar ham almashtiriladi**: x = a da u = g(a), x = b da u = g(b) — eski o'zgaruvchiga qaytish shart emas.
- Bo'laklab: ∫_{a}^{b} u dv = uv|_{a}^{b} − ∫_{a}^{b} v du.

## Ishlangan misollar

> **1-misol.** ∫_{0}^{2} (3x^2 + 1) dx.
>
> **Yechim.** (x^3 + x)|_{0}^{2} = (8 + 2) − 0 = **10**.

> **2-misol.** a) ∫_{1}^{e} {dx|x}; b) ∫_{0}^{π} sin x dx; c) ∫_{0}^{π/2} cos x dx.
>
> **Yechim.** a) ln x|_{1}^{e} = 1 − 0 = **1**. b) −cos x|_{0}^{π} = 1 + 1 = **2**. c) sin x|_{0}^{π/2} = **1**.

> **3-misol** (almashtirish). ∫_{0}^{1} x(x^2 + 1)^3 dx.
>
> **Yechim.** u = x^2 + 1, du = 2x dx; x = 0 ⇒ u = 1, x = 1 ⇒ u = 2:
> $$
> {1|2}∫_{1}^{2} u^3 du = {1|2}·{u^4|4}|_{1}^{2} = {16 − 1|8} = {15|8}
> $$

> **4-misol** (almashtirish). ∫_{0}^{4} {dx|1 + √x}.
>
> **Yechim.** t = √x, x = t^2, dx = 2t dt; t: 0 → 2:
> $$
> ∫_{0}^{2} {2t|1 + t} dt = 2∫_{0}^{2} (1 − {1|1 + t}) dt = 2(t − ln(1 + t))|_{0}^{2} = 4 − 2 ln 3 ≈ 1,80
> $$

> **5-misol** (bo'laklab). a) ∫_{0}^{1} x e^{x} dx; b) ∫_{1}^{e} ln x dx.
>
> **Yechim.** a) (x − 1)e^{x}|_{0}^{1} = 0 − (−1) = **1**. b) (x ln x − x)|_{1}^{e} = (e − e) − (0 − 1) = **1**.

> **6-misol** (Riman yig'indisi orqali). ∫_{0}^{1} x^2 dx ni ta'rif bo'yicha hisoblang.
>
> **Yechim.** [0; 1] ni n ta teng bo'lakka bo'lamiz, Δx = {1|n}, c_{i} = {i|n} (o'ng uchlar):
> $$
> S_{n} = ∑ ({i|n})^2·{1|n} = {1|n^3}·{n(n + 1)(2n + 1)|6} = {(n + 1)(2n + 1)|6n^2} → {2|6} = {1|3}
> $$
> Nyuton–Leybnits bilan tekshirish: {x^3|3}|_{0}^{1} = {1|3} ✓.

> **7-misol** (o'rtacha qiymat). f(x) = x^2 ning [0; 3] dagi o'rtacha qiymati va c nuqta.
>
> **Yechim.** {1|3}∫_{0}^{3} x^2 dx = {1|3}·9 = **3**. c^2 = 3 ⇒ **c = √3** ≈ 1,73.

> **8-misol** (toq funksiya). ∫_{−2}^{2} (x^3 + 4x) dx.
>
> **Yechim.** Integral ostidagi funksiya toq, chegaralar simmetrik — **0**.

> **9-misol** (o'zgaruvchi chegara). a) ({d|dx}) ∫_{0}^{x} √(1 + t^2) dt; b) ({d|dx}) ∫_{1}^{x^2} ln t dt.
>
> **Yechim.** a) **√(1 + x^2)**. b) ln(x^2)·2x = **4x ln x** (x > 0).
