## Ikki turdagi xosmas integral

::: tushuncha I tur — cheksiz chegara
$$
∫_{a}^{+∞} f(x)dx = lim_{A→+∞} ∫_{a}^{A} f(x)dx
$$
Limit chekli bo'lsa — **yaqinlashuvchi**, aks holda — **uzoqlashuvchi**. ∫_{−∞}^{+∞} ni ikkiga bo'lamiz: ikkala qism ham yaqinlashishi shart.
:::

::: tushuncha II tur — cheksiz uzilish
f b nuqtada cheksizga ketsa:
$$
∫_{a}^{b} f(x)dx = lim_{ε→0^{+}} ∫_{a}^{b−ε} f(x)dx
$$
Maxsus nuqta kesma ichida bo'lsa (c ∈ (a; b)), integral ∫_{a}^{c} + ∫_{c}^{b} ga bo'linadi.
:::

::: oddiy
Cheksiz uzun soha yuzasi chekli bo'lishi mumkinmi? Ha — agar funksiya **yetarlicha tez** nolga intilsa. {1|x^2} «tez» intiladi — yuza 1. {1|x} esa «sekin» — yuza cheksiz. Farq ko'zga deyarli tashlanmaydi, lekin natija butunlay boshqa!
:::

::: grafik x: 0.5..8, y: 0..2.2 | 1/x² ostidagi yuza (x ≥ 1) = 1, 1/x ostidagi yuza esa cheksiz
y = 1/x | rose | y = 1/x — uzoqlashadi
y = 1/x^2 | teal | y = 1/x² — yaqinlashadi
soha 1/x^2 | 1..8 | teal | ∫ 1/x² dx = 1
:::

## Etalon integrallar

::: formula Eng muhim ikki natija
| Integral | p > 1 | p = 1 | p < 1 |
|---|---|---|---|
| ∫_{1}^{+∞} {dx|x^p} | yaqinlashadi: {1|p − 1} | uzoqlashadi | uzoqlashadi |
| ∫_{0}^{1} {dx|x^p} | uzoqlashadi | uzoqlashadi | yaqinlashadi: {1|1 − p} |
:::

::: eslatma Eslab qolish usuli
Cheksizlikda — **tez** kamaysin (p > 1). Nol atrofida — **sekin** o'ssin (p < 1). p = 1 ({1|x}) — ikkala holda ham chegarada, uzoqlashadi.
:::

## Yaqinlashish alomatlari

::: teorema Taqqoslash alomati
0 ≤ f(x) ≤ g(x) bo'lsa: ∫ g yaqinlashsa ⇒ ∫ f ham yaqinlashadi; ∫ f uzoqlashsa ⇒ ∫ g ham uzoqlashadi.
:::

::: teorema Limit ko'rinishidagi taqqoslash
f, g > 0 va lim_{x→∞} {f(x)|g(x)} = λ, 0 < λ < ∞ bo'lsa, ikkala integral **bir vaqtda** yaqinlashadi yoki uzoqlashadi.
:::

- ∫ ∣f∣ yaqinlashsa, ∫ f — **absolyut yaqinlashuvchi**.
- ∫ f yaqinlashib, ∫ ∣f∣ uzoqlashsa — **shartli yaqinlashuvchi**.

::: oddiy Taqqoslash g'oyasi
Funksiyaning cheksizlikdagi «bosh qismi»ni ajrating: {x + 1|x^3 + 2} ≈ {1|x^2} (katta x da). Etalon bilan solishtiring — javob tayyor.
:::

## Ishlangan misollar

::: misol I tur, yaqinlashadi
∫_{1}^{+∞} {dx|x^2}
---
lim_{A→∞} (−{1|x})|_{1}^{A} = lim_{A→∞} (1 − {1|A}) = **1** — yaqinlashadi.
:::

::: misol I tur, uzoqlashadi
∫_{1}^{+∞} {dx|x}
---
lim_{A→∞} ln A = ∞ — **uzoqlashadi**, garchi {1|x} → 0 bo'lsa ham.
:::

::: misol Ko'rsatkichli funksiyalar
a) ∫_{0}^{+∞} e^{−2x}dx; b) ∫_{0}^{+∞} xe^{−x}dx.
---
a) lim_{A→∞} (−{1|2}e^{−2x})|_{0}^{A} = **{1|2}**.

b) Bo'laklab: ∫ xe^{−x}dx = −(x + 1)e^{−x}. lim_{A→∞} [1 − (A + 1)e^{−A}] = **1** (Lopital bo'yicha (A + 1)e^{−A} → 0).
:::

::: misol Ikki tomonlama cheksiz
∫_{−∞}^{+∞} {dx|1 + x^2}
---
arctg x|_{−∞}^{+∞} = {π|2} − (−{π|2}) = **π**.
:::

::: grafik x: -6..6, y: 0..1.2 | y = 1/(1 + x²) ostidagi butun yuza = π
y = 1/(1 + x^2) | teal | y = 1/(1 + x²)
soha 1/(1 + x^2) | -6..6 | teal | yuza → π
:::

::: misol II tur
a) ∫_{0}^{1} {dx|√x}; b) ∫_{0}^{1} {dx|x^2}.
---
a) lim_{ε→0^{+}} 2√x|_{ε}^{1} = **2** — yaqinlashadi (p = {1|2} < 1).

b) lim_{ε→0^{+}} (−{1|x})|_{ε}^{1} = lim (−1 + {1|ε}) = ∞ — **uzoqlashadi** (p = 2 ≥ 1).
:::

::: misol Maxsus nuqta ichkarida
∫_{0}^{3} {dx|∛(x − 1)}
---
x = 1 da cheksiz uzilish — ikkiga bo'lamiz. Boshlang'ich funksiya {3|2}(x − 1)^{2/3}:

∫_{0}^{1} = −{3|2}, ∫_{1}^{3} = {3|2}·∛4. Ikkalasi chekli ⇒ **{3|2}(∛4 − 1) ≈ 0,881**.
:::

::: misol Logarifm
∫_{0}^{1} ln x dx
---
(x ln x − x)|_{ε}^{1} = −1 − (ε ln ε − ε) → **−1** (ε ln ε → 0).
:::

::: misol Taqqoslash
∫_{1}^{+∞} {dx|x^3 + 1} va ∫_{1}^{+∞} {2 + sin x|x}dx ni tekshiring.
---
Birinchisi: {1|x^3 + 1} < {1|x^3}, ∫ {dx|x^3} yaqinlashadi ⇒ **yaqinlashadi**.

Ikkinchisi: 2 + sin x ≥ 1 ⇒ {2 + sin x|x} ≥ {1|x}, ∫ {dx|x} uzoqlashadi ⇒ **uzoqlashadi**.
:::

::: misol Limit alomati
∫_{1}^{+∞} {x + 1|x^3 + 2}dx
---
g = {1|x^2} bilan: lim {(x + 1)/(x^3 + 2)|1/x^2} = lim {x^3 + x^2|x^3 + 2} = 1 ⇒ **yaqinlashadi**.
:::

::: misol Abadiy renta
Yiliga 1 000 $ uzluksiz to'lov abadiy, r = 5%. Joriy qiymat?
---
PV = ∫_{0}^{+∞} 1000e^{−0,05t}dt = {1000|0,05} = **20 000 $**. Umumiy formula: **PV = {A|r}**.
:::

::: hayot Qiziq fakt: Gabriel shoxi
y = {1|x} (x ≥ 1) ni Ox atrofida aylantirsak, «shox» hosil bo'ladi. Uning hajmi π∫_{1}^{∞} {dx|x^2} = **π** — chekli. Sirt yuzasi esa cheksiz! Ya'ni shoxni bo'yoq bilan **to'ldirish** mumkin, lekin sirtini **bo'yab** bo'lmaydi. Matematiklar bu paradoksni 350 yildan beri yaxshi ko'radi.
:::

::: xato
- **«f(x) → 0 bo'lsa integral yaqinlashadi».** {1|x} → 0, lekin ∫_{1}^{∞} {dx|x} = ∞.
- **Ichki maxsus nuqtani ko'rmaslik.** ∫_{−1}^{1} {dx|x^2} ni «−{1|x}|_{−1}^{1} = −2» deb hisoblash — xato; integral uzoqlashadi.
- **∫_{−∞}^{∞} ni simmetrik limit bilan hisoblash.** Ikki qism alohida yaqinlashishi kerak.
:::
