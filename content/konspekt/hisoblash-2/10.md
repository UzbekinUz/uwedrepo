::: hayot Hayotda qayerda kerak?
Iqtisodiy ko'rsatkich muvozanatga qanday qaytadi: silliq so'nib boradimi yoki tebranib-tebranib? Javobni **xarakteristik tenglama ildizlari** beradi: haqiqiy manfiy ildizlar — silliq yaqinlashish, kompleks ildizlar — tebranish (biznes-sikllar). Bu mavzuda butun DT ni **algebraik tenglamaga** keltirishni o'rganamiz.

## Bir jinsli tenglama

$$
y'' + py' + qy = 0 (p, q — sonlar)
$$

y = e^{rx} ko'rinishda qidiramiz: y' = re^{rx}, y'' = r^2e^{rx}. Qo'yib e^{rx} ga qisqartirsak — **xarakteristik tenglama**:

$$
r^2 + pr + q = 0
$$

::: formula Umumiy yechim — uch holat
| Diskriminant | Ildizlar | Umumiy yechim |
|---|---|---|
| D > 0 | r_{1} ≠ r_{2} haqiqiy | y = C_{1}e^{r_{1}x} + C_{2}e^{r_{2}x} |
| D = 0 | r_{1} = r_{2} = r | y = (C_{1} + C_{2}x)e^{rx} |
| D < 0 | r = α ± βi | y = e^{αx}(C_{1}cos βx + C_{2}sin βx) |
:::

Kompleks holatda: α < 0 — **so'nuvchi tebranish** (muvozanatga qaytadi), α = 0 — doimiy tebranish, α > 0 — kuchayuvchi tebranish (beqaror).

::: grafik x: 0..10, y: -1.2..1.2 | y'' + 0,6y' + 4,09y = 0: y = e⁻⁰˒³ˣ·cos 2x — so'nuvchi tebranish
y = exp(-0.3x)cos(2x) | teal | y = e⁻⁰˒³ˣ·cos 2x
y = exp(-0.3x) | slate | ±e⁻⁰˒³ˣ (o'ram)
y = -exp(-0.3x) | slate |
:::

## Bir jinsli bo'lmagan tenglama: maxsus o'ng tomon

y'' + py' + qy = f(x). Umumiy yechim y = y_{BJ} + y^{*} (9-mavzu). f(x) maxsus ko'rinishda bo'lsa, y^{*} ni **noma'lum koeffitsiyentlar** bilan «taxmin» qilamiz:

::: formula Xususiy yechim shakli
| f(x) | y^{*} shakli |
|---|---|
| P_{n}(x) — n-darajali ko'phad | Q_{n}(x)·x^{s} |
| P_{n}(x)e^{ax} | Q_{n}(x)e^{ax}·x^{s} |
| e^{ax}(M cos bx + N sin bx) | e^{ax}(A cos bx + B sin bx)·x^{s} |

s — a (yoki a ± bi) soni xarakteristik tenglamaning **necha karrali ildizi** ekani (ildiz bo'lmasa s = 0). s > 0 holat — **rezonans**.
:::

Keyin y^{*} ni tenglamaga qo'yib, x ning bir xil darajalari oldidagi koeffitsiyentlarni tenglashtiramiz.

## Ishlangan misollar

::: misol Uch holat
a) y'' − 5y' + 6y = 0; b) y'' − 4y' + 4y = 0; c) y'' + 2y' + 5y = 0.
---
a) r^2 − 5r + 6 = 0 ⇒ r = 2; 3: **y = C_{1}e^{2x} + C_{2}e^{3x}**.

b) r^2 − 4r + 4 = 0 ⇒ r = 2 (karrali): **y = (C_{1} + C_{2}x)e^{2x}**.

c) r^2 + 2r + 5 = 0 ⇒ D = 4 − 20 = −16, r = −1 ± 2i: **y = e^{−x}(C_{1}cos 2x + C_{2}sin 2x)**.
:::

::: misol Koshi masalasi
y'' + 4y = 0, y(0) = 1, y'(0) = 2.
---
r^2 + 4 = 0 ⇒ r = ±2i: y = C_{1}cos 2x + C_{2}sin 2x.

y(0) = C_{1} = 1; y' = −2C_{1}sin 2x + 2C_{2}cos 2x, y'(0) = 2C_{2} = 2 ⇒ C_{2} = 1.

**y = cos 2x + sin 2x**.
:::

::: misol Ko'phad o'ng tomon
y'' − 5y' + 6y = 12x − 4.
---
0 — ildiz emas (ildizlar 2; 3), s = 0: y^{*} = Ax + B. y^{*'} = A, y^{*''} = 0.

−5A + 6Ax + 6B = 12x − 4 ⇒ 6A = 12, 6B − 5A = −4 ⇒ **A = 2, B = 1**.

**y = C_{1}e^{2x} + C_{2}e^{3x} + 2x + 1**.
:::

::: misol Eksponenta va rezonans
a) y'' − 3y' + 2y = e^{3x}; b) y'' − 3y' + 2y = e^{x}.
---
Ildizlar: r^2 − 3r + 2 = 0 ⇒ r = 1; 2.

a) 3 — ildiz emas: y^{*} = Ae^{3x} ⇒ (9 − 9 + 2)Ae^{3x} = e^{3x} ⇒ A = {1|2}. **y = C_{1}e^{x} + C_{2}e^{2x} + {1|2}e^{3x}**.

b) 1 — oddiy ildiz, s = 1 (rezonans): y^{*} = Axe^{x}. y^{*'} = A(x + 1)e^{x}, y^{*''} = A(x + 2)e^{x}.

A·e^{x}[(x + 2) − 3(x + 1) + 2x] = −Ae^{x} = e^{x} ⇒ A = −1. **y = C_{1}e^{x} + C_{2}e^{2x} − xe^{x}**.
:::

::: xato
- **Karrali ildizda C_{2}e^{rx} ni x ga ko'paytirishni unutish** — aks holda ikki yechim bir xil bo'lib qoladi.
- **Rezonansni tekshirmaslik.** y^{*} = Ae^{x} ni qo'ysangiz, 0 = e^{x} chiqadi — bu x^{s} ko'paytuvchi kerakligi belgisi.
- **cos ning o'zi bor bo'lsa, y^{*} da faqat A cos bx yozish.** Har doim A cos bx + B sin bx.
:::
