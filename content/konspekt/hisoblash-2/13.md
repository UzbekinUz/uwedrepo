## Asosiy tushunchalar

**Sonli qator:** a_{1} + a_{2} + … + a_{n} + … = Σa_{n}. **Qismiy yig'indi** S_{n} = a_{1} + … + a_{n}.

Agar lim S_{n} = S chekli bo'lsa, qator **yaqinlashuvchi**, S — uning yig'indisi; aks holda **uzoqlashuvchi**.

::: formula Geometrik qator
$$
a + aq + aq^2 + … = {a|1 − q}, ∣q∣ < 1
$$
∣q∣ ≥ 1 bo'lsa — uzoqlashadi.
:::

::: teorema Zaruriy shart
Qator yaqinlashsa, **a_{n} → 0**. Teskarisi noto'g'ri: garmonik qator Σ{1|n} da a_{n} → 0, lekin u **uzoqlashadi**. Amalda: a_{n} ↛ 0 bo'lsa — darhol uzoqlashadi.
:::

## Musbat hadli qatorlar alomatlari

::: formula Alomatlar
| Alomat | Qachon qulay | Xulosa |
|---|---|---|
| Taqqoslash | a_{n} ma'lum qatorga o'xshash | a_{n} ≤ b_{n}, Σb_{n} yaq. ⇒ Σa_{n} yaq. |
| Limit taqqoslash | kasr-ratsional a_{n} | lim a_{n}/b_{n} = c ∈ (0; ∞) ⇒ ikkalasi bir xil |
| Dalamber | n!, a^{n} | lim a_{n+1}/a_{n} = D: D < 1 yaq., D > 1 uzoq. |
| Koshi (radikal) | (…)^{n} | lim ⁿ√a_{n} = K: K < 1 yaq., K > 1 uzoq. |
| Integral | a_{n} = f(n), f kamayuvchi | Σa_{n} va ∫_{1}^{∞}f dx bir xil |
:::

D = 1 yoki K = 1 bo'lsa, alomat javob bermaydi.

::: teorema Umumlashgan garmonik qator
$$
Σ{1|n^{p}}: p > 1 — yaqinlashadi, p ≤ 1 — uzoqlashadi
$$
Integral alomatdan kelib chiqadi; taqqoslash uchun eng ko'p ishlatiladigan «etalon».
:::

## Ishorasi almashinuvchi qatorlar

::: teorema Leybnits alomati
a_{1} − a_{2} + a_{3} − … (a_{n} > 0) qatorda a_{n} **monoton kamayib nolga intilsa**, qator yaqinlashadi. Xato ∣S − S_{n}∣ ≤ a_{n+1}.
:::

Σ∣a_{n}∣ yaqinlashsa — **absolyut**, Σa_{n} yaqinlashib Σ∣a_{n}∣ uzoqlashsa — **shartli** yaqinlashuvchi.

## Ishlangan misollar

::: misol Teleskopik qator
Σ_{n=1}^{∞} {1|n(n + 1)} yig'indisi.
---
{1|n(n + 1)} = {1|n} − {1|n + 1}. S_{n} = (1 − {1|2}) + ({1|2} − {1|3}) + … = 1 − {1|n + 1}.

lim S_{n} = **1**.
:::

::: misol Multiplikator va perpetuitet
a) Iste'molga moyillik MPC = 0,8. 1 mlrd investitsiyaning jami samarasi? b) Yiliga 100 mln to'laydigan abadiy renta, stavka 10%. Bugungi qiymati?
---
a) 1 + 0,8 + 0,8^2 + … = {1|1 − 0,8} = **5 mlrd** (multiplikator 5).

b) PV = {100|1,1} + {100|1,1^2} + … = {100/1,1|1 − 1/1,1} = {100|0,1} = **1000 mln**.
:::

::: misol Alomatlar
a) Σ{n|2n + 1}; b) Σ{2^{n}|n!}; c) Σ{1|n^2 + 1}; d) Σ({n|3n + 1})^{n}.
---
a) a_{n} → {1|2} ≠ 0 — **uzoqlashadi** (zaruriy shart bajarilmadi).

b) Dalamber: {a_{n+1}|a_{n}} = {2|n + 1} → 0 < 1 — **yaqinlashadi**.

c) {1|n^2 + 1} < {1|n^2}, Σ{1|n^2} yaqinlashadi (p = 2) — **yaqinlashadi**.

d) Koshi: ⁿ√a_{n} = {n|3n + 1} → {1|3} < 1 — **yaqinlashadi**.
:::

::: misol Leybnits
1 − {1|2} + {1|3} − {1|4} + …
---
{1|n} kamayadi va → 0 — Leybnits bo'yicha **yaqinlashadi** (yig'indisi ln 2 ≈ 0,693). Modullar qatori — garmonik, uzoqlashadi. Demak yaqinlashish **shartli**.
:::

::: xato
- **a_{n} → 0 dan yaqinlashish xulosasini chiqarish** — garmonik qatorni eslang.
- **Dalamberda D = 1 chiqqanda «yaqinlashadi» deyish.** Bu holda alomat hech narsa demaydi (Σ1/n va Σ1/n^2 ikkalasida D = 1).
- **Geometrik qator yig'indisini birinchi hadsiz yozish.** Formula a/(1 − q), a — **birinchi** had.
:::

## Mustaqil mashqlar

::: mashq
Σ_{n=0}^{∞} {2^{n}|3^{n}} yig'indisi || 3
Σ{n^2|2^{n}} yaqinlashadimi? || Ha (Dalamber: 1/2)
