::: hayot Hayotda qayerda kerak?
Bir o'zgaruvchili integral egri chiziq ostidagi yuzani yoki vaqt davomida yig'ilgan miqdorni beradi. Endi miqdor **tekislik** bo'ylab taqsimlangan: shahar hududidagi aholi zichligi, ikki tasodifiy omilning birgalikdagi ehtimoli, ikki narx bo'yicha talab. Umumiy miqdorni topish uchun **ikki karrali integral** kerak.
:::

## Ta'rif va geometrik ma'no

D sohani kichik Δs_{i} bo'laklarga bo'lamiz, har birida nuqta olib, integral yig'indi tuzamiz: Σf(x_{i}, y_{i})Δs_{i}. Bo'laklar kichrayganda uning limiti — **ikki karrali integral**:

$$
∫∫_{D} f(x, y) dxdy = lim_{max d_{i}→0} Σ f(x_{i}, y_{i})Δs_{i}
$$

::: tushuncha Ma'nosi
- f ≥ 0 bo'lsa — D ustida turgan, yuqoridan z = f(x, y) sirt bilan chegaralangan **jism hajmi**.
- f = 1 bo'lsa — D sohaning **yuzasi**: S = ∫∫_{D} dxdy.
- f — zichlik bo'lsa — umumiy **massa** (aholi soni, umumiy ehtimol va h.k.).
:::

Xossalar bir karrali integralnikiga o'xshash: chiziqlilik, sohani bo'laklarga bo'lish mumkin, f ≤ g dan integrallar tengsizligi kelib chiqadi.

## Takroriy integralga keltirish

::: formula To'g'ri to'rtburchak D = [a; b] × [c; d]
$$
∫∫_{D} f dxdy = ∫_{a}^{b} (∫_{c}^{d} f(x, y) dy) dx
$$
Avval ichki integral (x — o'zgarmas), keyin tashqi. Tartibni almashtirish mumkin.
:::

::: formula Egri chiziqli soha
**I tur** — a ≤ x ≤ b, φ_{1}(x) ≤ y ≤ φ_{2}(x) («pastki va ustki chegara»):
$$
∫∫_{D} f dxdy = ∫_{a}^{b} dx ∫_{φ_{1}(x)}^{φ_{2}(x)} f(x, y) dy
$$
**II tur** — c ≤ y ≤ d, ψ_{1}(y) ≤ x ≤ ψ_{2}(y) («chap va o'ng chegara»): avval x bo'yicha.
:::

Qadamlar: **sohani chizing** → har bir chegarani tenglama bilan yozing → tashqi o'zgaruvchining o'zgarmas chegaralarini (kesishish nuqtalari) toping → ichki chegaralar — funksiyalar.

::: grafik x: -0.2..1.3, y: -0.2..1.3 | D: y = x² va y = x orasidagi soha, 0 ≤ x ≤ 1
y = x | teal | y = x (ustki)
y = x^2 | amber | y = x² (pastki)
soha x ; x^2 | 0..1 | teal | D
nuqta 1, 1 | (1; 1)
:::

## Integrallash tartibini almashtirish

Ba'zan ichki integral «olinmaydi» (masalan, ∫e^{y^2}dy), lekin tartib almashtirilsa, oson bo'ladi. Buning uchun chegaralardan sohani tiklab, uni boshqa tur sifatida qayta yozamiz.

## Qutb koordinatalari

Doira, halqa, sektor ko'rinishidagi sohalarda: x = r cos φ, y = r sin φ, **dxdy = r dr dφ** (r — «Yakobian», unutmang!):

$$
∫∫_{D} f(x, y) dxdy = ∫∫_{D'} f(r cos φ, r sin φ)·r dr dφ
$$

## Ishlangan misollar

::: misol To'g'ri to'rtburchak
∫∫_{D}(x + 2y)dxdy, D = [0; 2] × [0; 1].
---
Ichki integral (x o'zgarmas): ∫_{0}^{1}(x + 2y)dy = [xy + y^2]_{0}^{1} = x + 1.

Tashqi: ∫_{0}^{2}(x + 1)dx = [{x^2|2} + x]_{0}^{2} = 2 + 2 = **4**.
:::

::: misol Egri chiziqli soha
∫∫_{D} xy dxdy, D: y = x^2 va y = x orasida.
---
Kesishish: x^2 = x ⇒ x = 0; 1. Bu oraliqda x ≥ x^2, ya'ni pastki chegara y = x^2, ustki y = x.

∫_{0}^{1} dx ∫_{x^2}^{x} xy dy = ∫_{0}^{1} x·{x^2 − x^4|2} dx = {1|2}({1|4} − {1|6}) = {1|2}·{1|12} = **{1|24}**.
:::

::: misol Tartibni almashtirish
I = ∫_{0}^{1} dx ∫_{x}^{1} e^{y^2} dy.
---
∫e^{y^2}dy elementar funksiyalarda olinmaydi. Soha: 0 ≤ x ≤ 1, x ≤ y ≤ 1 — bu uchburchak, uchlari (0; 0), (0; 1), (1; 1). II tur sifatida: 0 ≤ y ≤ 1, 0 ≤ x ≤ y.

I = ∫_{0}^{1} dy ∫_{0}^{y} e^{y^2} dx = ∫_{0}^{1} ye^{y^2} dy = [{1|2}e^{y^2}]_{0}^{1} = **{e − 1|2} ≈ 0,859**.
:::

::: misol Qutb koordinatalari
∫∫_{D}(x^2 + y^2)dxdy, D: x^2 + y^2 ≤ 4.
---
x^2 + y^2 = r^2, D': 0 ≤ r ≤ 2, 0 ≤ φ ≤ 2π.

∫_{0}^{2π} dφ ∫_{0}^{2} r^2·r dr = 2π·[{r^4|4}]_{0}^{2} = 2π·4 = **8π ≈ 25,1**.
:::

::: xato
- **Tashqi integral chegarasida o'zgaruvchi qoldirish.** Tashqi chegaralar doim **sonlar** bo'lishi kerak.
- **Pastki va ustki chegarani adashtirish** — sohani chizmasdan yozish. Oraliqdan bitta nuqta olib tekshiring (x = 0,5: x = 0,5 > x^2 = 0,25).
- **Qutb koordinatalarida r ko'paytuvchisini unutish:** dxdy = r dr dφ, dr dφ emas.
:::
