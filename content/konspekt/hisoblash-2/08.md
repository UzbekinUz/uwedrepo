::: hayot Hayotda qayerda kerak?
Omonatga nafaqat foiz qo'shiladi, balki har oy qo'shimcha pul ham qo'yiladi: S' = rS + a. Ombordagi zaxira bir vaqtda kamayadi va to'ldiriladi. Bunday «o'sish + tashqi oqim» modellari aynan **chiziqli** differensial tenglamalardir — ular amaliyotda eng ko'p uchraydi.
:::

## Chiziqli tenglama

$$
y' + p(x)y = q(x)
$$

y va y' faqat birinchi darajada qatnashadi. q(x) = 0 bo'lsa — **bir jinsli**, aks holda **bir jinsli emas**.

::: formula 1-usul: integrallovchi ko'paytuvchi
μ(x) = e^{∫p(x)dx}. Tenglamani μ ga ko'paytirsak, chap tomon ko'paytma hosilasiga aylanadi:

$$
(μy)' = μq ⇒ y = {1|μ}(∫μq dx + C)
$$
:::

::: formula 2-usul: Bernulli (y = uv)
y = uv, y' = u'v + uv'. Qo'ysak: u'v + u(v' + pv) = q.
1. v ni shunday tanlaymiz: v' + pv = 0 (ajraladigan, C siz yechiladi).
2. Qolgani: u'v = q ⇒ u = ∫{q|v}dx + C.
3. y = uv.
:::

Ikkala usul bir xil javob beradi; birini puxta o'zlashtirish yetarli.

## Bernulli tenglamasi

$$
y' + p(x)y = q(x)y^{n} (n ≠ 0; 1)
$$

y^{n} ga bo'lib, **z = y^{1 − n}** almashtirish qilsak, z' = (1 − n)y^{−n}y' va tenglama **z ga nisbatan chiziqli** bo'ladi: z' + (1 − n)pz = (1 − n)q.

## To'liq differensialli tenglamalar

P(x, y)dx + Q(x, y)dy = 0 tenglamaning chap tomoni biror U(x, y) funksiyaning to'liq differensiali bo'lsa (dU = 0), yechim **U(x, y) = C**.

::: teorema Shart va topish
To'liq differensial bo'lishi uchun: **{∂P|∂y} = {∂Q|∂x}**.

U ni topish: U = ∫P dx + φ(y), so'ng U'_{y} = Q dan φ(y) aniqlanadi.
:::

## Ishlangan misollar

::: misol Integrallovchi ko'paytuvchi
y' + 2y = 4x.
---
μ = e^{∫2dx} = e^{2x}. (ye^{2x})' = 4xe^{2x}.

∫4xe^{2x}dx (bo'laklab) = 2xe^{2x} − e^{2x} + C.

**y = 2x − 1 + Ce^{−2x}**. Tekshiruv: y' = 2 − 2Ce^{−2x}; y' + 2y = 2 − 2Ce^{−2x} + 4x − 2 + 2Ce^{−2x} = 4x ✓.
:::

::: misol Koshi masalasi (Bernulli usuli)
y' − {y|x} = x^2, y(1) = 2.
---
y = uv: u'v + u(v' − {v|x}) = x^2.

v' = {v|x} ⇒ v = x. Keyin u'x = x^2 ⇒ u' = x ⇒ u = {x^2|2} + C.

y = x({x^2|2} + C) = {x^3|2} + Cx. y(1) = {1|2} + C = 2 ⇒ C = {3|2}.

**y = {x^3 + 3x|2}**.
:::

::: misol Muntazam to'ldiriladigan omonat
S' = 0,1S + 2 (mln so'm, yil), S(0) = 0. 5 yildan keyin?
---
S' − 0,1S = 2: μ = e^{−0,1t}, (Se^{−0,1t})' = 2e^{−0,1t} ⇒ Se^{−0,1t} = −20e^{−0,1t} + C.

S = −20 + Ce^{0,1t}, S(0) = 0 ⇒ C = 20: **S = 20(e^{0,1t} − 1)**.

S(5) = 20(e^{0,5} − 1) ≈ 20·0,6487 ≈ **13,0 mln** (10 mln qo'yilgan, 3 mln — foizlar).
:::

::: misol Bernulli tenglamasi
y' + y = y^2.
---
n = 2, z = y^{−1}: z' = −y^{−2}y'. Tenglamani y^2 ga bo'lamiz: y^{−2}y' + y^{−1} = 1 ⇒ −z' + z = 1 ⇒ z' − z = −1.

Chiziqli: z = 1 + Ce^{x}. **y = {1|1 + Ce^{x}}** (shuningdek y = 0).
:::

::: misol To'liq differensial
(2xy + 3)dx + (x^2 + 4y)dy = 0.
---
P'_{y} = 2x, Q'_{x} = 2x — teng ✓.

U = ∫(2xy + 3)dx = x^2y + 3x + φ(y). U'_{y} = x^2 + φ'(y) = x^2 + 4y ⇒ φ = 2y^2.

**x^2y + 3x + 2y^2 = C**.
:::

::: xato
- **Tenglamani standart ko'rinishga keltirmay p(x) ni olish.** xy' + y = … bo'lsa, avval x ga bo'ling: p = 1/x.
- **Bernulli usulida v ni topishda C qo'shish.** v uchun bitta xususiy yechim yetarli, C faqat u da.
- **To'liq differensial shartini tekshirmasdan U ni qidirish.**
:::

## O'zingizni tekshiring

::: test
? Qaysi tenglama chiziqli?
- y' + y^2 = x
+ y' + xy = sin x
- yy' = x
- y' = e^{y}
> y va y' faqat birinchi darajada.
? y' + 3y = 0 ning integrallovchi ko'paytuvchisi?
- e^{−3x}
+ e^{3x}
- 3x
- x^3
> μ = e^{∫3dx}.
? y' + y = y^{3} Bernulli tenglamasi uchun almashtirish?
- z = y^{3}
+ z = y^{−2}
- z = y^{2}
- z = y'
> z = y^{1−n}, n = 3.
? (3x^2 + y)dx + (x + 2y)dy = 0 ning umumiy integrali?
- x^3 + y^2 = C
+ x^3 + xy + y^2 = C
- 3x^2y + y^2 = C
- x^3 + 2xy = C
> P'_{y} = 1 = Q'_{x}; U = x^3 + xy + y^2.
:::

## Mustaqil mashqlar

::: mashq
y' − y = e^{x} || y = (x + C)e^{x}
y' + {y|x} = 3x, y(1) = 2 || y = x^2 + {1|x}
xy' + y = x^3 || y = {x^3|4} + {C|x}
y' − 2y = −y^2 (Bernulli) || y = {2|1 + Ce^{−2x}}
(y + 2x)dx + (x − 1)dy = 0 || xy − y + x^2 = C
:::
