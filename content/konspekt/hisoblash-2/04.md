::: hayot Hayotda qayerda kerak?
Iste'molchining puli cheklangan, firma esa ma'lum hajmni eng arzon yo'l bilan ishlab chiqarmoqchi. Bu «cheklov ostida eng yaxshisini tanlash» masalalari — iqtisodiyotning yuragi. Ularning matematik tili — shartli ekstremum va Lagranj ko'paytuvchisi. Ma'lumotlarga eng yaxshi chiziq o'tkazish (regressiya) ham aslida ikki o'zgaruvchili funksiya minimumi.

## Chekli kattaliklar va elastiklik

Q = f(x, y) uchun **xususiy elastiklik** — x 1% o'zgarganda Q necha foiz o'zgarishi:

$$
E_{x} = {∂Q|∂x}·{x|Q}
$$

::: tushuncha Muhim natijalar
- Kobb–Duglas Q = AK^{α}L^{β}: **E_{K} = α, E_{L} = β** — elastiklik o'zgarmas.
- Talab Q = a·p^{−e}·I^{d}: narx bo'yicha elastiklik −e, daromad bo'yicha d.
- Kesishgan elastiklik E_{p_{2}} > 0 — tovarlar **o'rinbosar**, < 0 — **to'ldiruvchi**.
:::

## MRTS va Eyler teoremasi

Izokvanta bo'ylab Q o'zgarmaydi: dQ = MP_{K}dK + MP_{L}dL = 0. Bundan **texnik almashtirishning chekli normasi**:

$$
MRTS = −{dK|dL} = {MP_{L}|MP_{K}}
$$

— bitta ishchini nechta kapital birligi bilan almashtirish mumkinligi. Foydalilikda xuddi shunday **MRS = {MU_{x}|MU_{y}}**.

::: teorema Eyler teoremasi
f — k-darajali bir jinsli funksiya bo'lsa, ya'ni f(tK, tL) = t^{k}f(K, L), u holda

$$
K·{∂f|∂K} + L·{∂f|∂L} = k·f
$$

k = 1 da (masshtabdan doimiy samara): har bir omilga chekli mahsuloti bo'yicha haq to'lansa, butun mahsulot **qoldiqsiz taqsimlanadi**.
:::

## Shartli ekstremum: Lagranj usuli

f(x, y) → extr, sharti g(x, y) = c. **Lagranj funksiyasi**:

$$
ℒ = f(x, y) + λ(c − g(x, y))
$$

::: formula Algoritm
1. ℒ'_{x} = 0, ℒ'_{y} = 0, ℒ'_{λ} = 0 sistemani yechamiz.
2. Birinchi ikkitasidan λ ni yo'qotsak: {f'_{x}|g'_{x}} = {f'_{y}|g'_{y}} — **sath chizig'i cheklovga urinadi**.
3. λ — **cheklovning soyaviy narxi**: c ni 1 birlikka oshirsak, optimal qiymat taxminan λ ga oshadi.
:::

::: grafik x: 0..42, y: 0..22 | U = xy → max, 2x + 4y = 80: befarqlik egri chizig'i U = 200 byudjet chizig'iga (20; 10) da urinadi
y = (80 - 2x)/4 | slate | byudjet 2x + 4y = 80 | 0..40
y = 200/x | teal | U = 200 | 9..40
y = 100/x | amber | U = 100 | 5..40
nuqta 20, 10 | optimum (20; 10)
:::

## Eng kichik kvadratlar usuli

(x_{i}; y_{i}) nuqtalarga y = ax + b to'g'ri chiziq o'tkazamiz. Og'ishlar kvadratlari yig'indisi S(a, b) = Σ(ax_{i} + b − y_{i})^2 **ikki o'zgaruvchili funksiya** — uning minimumi:

$$
[:aΣx_{i}^2 + bΣx_{i} = Σx_{i}y_{i}; aΣx_{i} + bn = Σy_{i}:]
$$

## Ishlangan misollar

::: misol Iste'molchi tanlovi
U = xy, narxlar p_{x} = 2, p_{y} = 4, daromad 80. Optimal to'plam va λ?
---
ℒ = xy + λ(80 − 2x − 4y). ℒ'_{x} = y − 2λ = 0, ℒ'_{y} = x − 4λ = 0 ⇒ **x = 2y**.

Byudjet: 4y + 4y = 80 ⇒ **y = 10, x = 20**, U = 200. λ = {y|2} = **5**.

Tekshiruv: daromad 81 bo'lsa, y = {81|8}, x = {81|4}, U = {6561|32} ≈ 205,03 — haqiqatan ≈ 5 ga oshdi. λ — **pulning chekli foydaliligi**.
:::

::: misol Xarajatni minimallashtirish
Q = K^{0,5}L^{0,5} = 10 hajmni eng arzon ishlab chiqarish: kapital narxi r = 4, ish haqi w = 1.
---
Optimum shartida MRTS = narxlar nisbati: {MP_{L}|MP_{K}} = {K|L} = {w|r} = {1|4} ⇒ **L = 4K**.

√(K·4K) = 2K = 10 ⇒ **K = 5, L = 20**. Xarajat C = 4·5 + 20 = **40**.
:::

::: misol Eyler teoremasi tekshiruvi
Q = 10K^{0,4}L^{0,6}, K = L = 1.
---
MP_{K} = 4K^{−0,6}L^{0,6} = 4, MP_{L} = 6K^{0,4}L^{−0,4} = 6.

K·MP_{K} + L·MP_{L} = 4 + 6 = 10 = Q ✓ (k = 1). Kapitalga 40%, mehnatga 60% ulush tegadi — Kobb–Duglas ko'rsatkichlari aynan daromad ulushlari.
:::

::: misol Eng kichik kvadratlar
(1; 2), (2; 3), (3; 5) nuqtalarga y = ax + b chiziq.
---
n = 3, Σx = 6, Σy = 10, Σx^2 = 14, Σxy = 2 + 6 + 15 = 23.

[:14a + 6b = 23; 6a + 3b = 10:] Ikkinchisini 2 ga ko'paytirib ayiramiz: 2a = 3 ⇒ **a = 1,5**, b = {10 − 9|3} = {1|3}.

**y = 1,5x + 0,33.**
:::

::: grafik x: 0..4, y: 0..6.5 | Eng kichik kvadratlar chizig'i y = 1,5x + 1/3
y = 1.5x + 1/3 | teal | y = 1,5x + 0,33
nuqta 1, 2 | (1; 2)
nuqta 2, 3 | (2; 3)
nuqta 3, 5 | (3; 5)
:::

::: xato
- **Elastiklikni chekli mahsulot bilan aralashtirish.** MP — birliklarda, elastiklik — foizlarda.
- **Lagranjda ℒ'_{λ} = 0 tenglamani unutish** — bu aynan cheklovning o'zi.
- **MRTS ni MP_{K}/MP_{L} deb yozish.** Surat — almashtiriladigan omil (L) ning chekli mahsuloti.
:::

- MRTS = MP_{L}/MP_{K}; optimumda = narxlar nisbati.
- Eyler: bir jinsli 1-darajada K·MP_{K} + L·MP_{L} = Q.
- Lagranj: ℒ = f + λ(c − g); λ — soyaviy narx.
