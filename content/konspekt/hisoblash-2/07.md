Ko'p iqtisodiy qonunlar «kattalikning o'zi»ni emas, uning **o'zgarish tezligini** tasvirlaydi: «omonat har yili 20% ga o'sadi», «narx talab va taklif farqiga mutanosib o'zgaradi». Bunday tasvir — **differensial tenglama**, uni yechish esa kelajakdagi qiymatni topish demak. 7–12-mavzular shu haqda.

## Asosiy tushunchalar

Noma'lum funksiya y(x), uning hosilalari va x ni bog'lovchi tenglama — **oddiy differensial tenglama (DT)**. Tenglamadagi eng yuqori hosila tartibi — DT ning **tartibi**.

Birinchi tartibli DT: F(x, y, y') = 0 yoki y' = f(x, y).

::: tushuncha Yechimlar
- **Umumiy yechim** y = φ(x, C) — ixtiyoriy C o'zgarmasni o'z ichiga oladi; geometrik jihatdan — **integral egri chiziqlar oilasi**.
- **Xususiy yechim** — C ning aniq qiymatida.
- **Koshi masalasi**: y' = f(x, y), y(x_{0}) = y_{0} — oiladan (x_{0}; y_{0}) nuqtadan o'tadigan egri chiziqni tanlash.
:::

Hosila — urinma qiyaligi. Shuning uchun y' = f(x, y) tenglama tekislikning har bir nuqtasida **yo'nalish** beradi (yo'nalishlar maydoni), yechim esa shu yo'nalishlarga urinib boradigan egri chiziq.

## O'zgaruvchilari ajraladigan tenglamalar

$$
{dy|dx} = f(x)·g(y)
$$

::: formula Yechish usuli
1. y' ni {dy|dx} deb yozamiz.
2. y li hamma narsani dy tomonga, x li hammasini dx tomonga o'tkazamiz: {dy|g(y)} = f(x)dx.
3. Ikkala tomonni integrallaymiz: ∫{dy|g(y)} = ∫f(x)dx + C.
4. g(y) = 0 ildizlari ham yechim bo'lishi mumkin — alohida tekshiring.
:::

Eng muhim misol — **tabiiy o'sish qonuni** y' = ky: {dy|y} = k dx ⇒ ln∣y∣ = kx + C ⇒ **y = y_{0}e^{kx}**. k > 0 — eksponensial o'sish (uzluksiz foiz), k < 0 — so'nish (amortizatsiya).

::: grafik x: -1.5..1.5, y: -4..8 | y' = 2xy ning integral egri chiziqlari y = C·eˣ²
y = exp(x^2) | teal | C = 1
y = 2exp(x^2) | amber | C = 2
y = 3exp(x^2) | rose | C = 3 (Koshi: y(0) = 3)
y = -exp(x^2) | violet | C = −1
nuqta 0, 3 | (0; 3)
:::

## Bir jinsli tenglamalar

Agar o'ng tomon faqat {y|x} nisbatga bog'liq bo'lsa — y' = f({y|x}) — tenglama **bir jinsli**. Tekshirish: x va y o'rniga tx, ty qo'yganda f o'zgarmaydi.

::: formula Almashtirish
y = ux (u — yangi noma'lum funksiya), y' = u + xu'. Natijada: u + xu' = f(u) ⇒ {du|f(u) − u} = {dx|x} — o'zgaruvchilar ajraladi.
:::

## Ishlangan misollar

::: misol Koshi masalasi
y' = 2xy, y(0) = 3.
---
{dy|y} = 2x dx ⇒ ln∣y∣ = x^2 + C_{1} ⇒ y = Ce^{x^2} (y = 0 ham shu oilada, C = 0).

y(0) = C = 3 ⇒ **y = 3e^{x^2}**.
:::

::: misol Omonat
Omonat uzluksiz 18% stavka bilan o'sadi: S' = 0,18S, S(0) = 10 mln so'm. 5 yildan keyin? Necha yilda ikki baravar?
---
S(t) = 10e^{0,18t}. S(5) = 10e^{0,9} ≈ 10·2,4596 = **24,6 mln so'm**.

2 = e^{0,18t} ⇒ t = {ln 2|0,18} ≈ **3,85 yil** («72 qoidasi»ga yaqin: 72/18 = 4).
:::

::: misol O'zgaruvchilar ajraladi
(1 + x^2)y' = 2xy.
---
{dy|y} = {2x|1 + x^2}dx ⇒ ln∣y∣ = ln(1 + x^2) + ln∣C∣ ⇒ **y = C(1 + x^2)**.

Tekshiruv: y' = 2Cx, (1 + x^2)·2Cx = 2x·C(1 + x^2) ✓.
:::

::: misol Bir jinsli tenglama
y' = {x^2 + y^2|xy}.
---
O'ng tomon = {x|y} + {y|x} — faqat y/x ga bog'liq. y = ux: u + xu' = {1|u} + u ⇒ xu' = {1|u}.

u du = {dx|x} ⇒ {u^2|2} = ln∣x∣ + C ⇒ u^2 = 2ln∣x∣ + 2C.

u = y/x qaytsak: **y^2 = x^2(2ln∣x∣ + C)**.
:::

::: xato
- **Integrallagandan keyin C ni unutish** — yoki uni ikki tomonga ham yozib, keyin birlashtirmaslik.
- **ln∣y∣ = x^2 + C dan y = e^{x^2} + C deb yozish.** To'g'risi: y = e^{x^2 + C} = C'e^{x^2} — o'zgarmas ko'paytuvchi bo'ladi.
- **g(y) ga bo'lganda yo'qolgan yechimlarni unutish** (masalan, y = 0).
:::

## Mustaqil mashqlar

::: mashq
y' = −2y, y(0) = 5 || y = 5e^{−2x}
y' = {x|y}, y(0) = 1 || y^2 = x^2 + 1 (y = √(x^2 + 1))
y' = e^{x − y} || e^{y} = e^{x} + C
xy' = y + x (bir jinsli) || y = x(ln∣x∣ + C)
