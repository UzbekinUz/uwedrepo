- Tartibi pasaytiriladigan yuqori tartibli tenglamalarni (uch asosiy tur)
- Chiziqli bir jinsli tenglama yechimlarining tuzilishini: fundamental sistema, Vronskiy determinanti
- Bir jinsli bo'lmagan tenglama umumiy yechimi = bir jinsli umumiy + xususiy
- O'zgarmaslarni variatsiyalash (Lagranj) usuli g'oyasini
:::

::: hayot Hayotda qayerda kerak?
Ikkinchi hosila — «tezlanish»: o'sish sur'atining o'zi qanday o'zgarmoqda. Iqtisodiy sikllar (bum va retsessiyaning almashinuvi), narxlarning muvozanat atrofida tebranishi, kutilmalarni hisobga olgan bozor modellari — bularning hammasi **ikkinchi tartibli** tenglamalarga olib keladi. Bu mavzu ularning umumiy nazariyasi, keyingisi — aniq yechish texnikasi.
:::

## Tartibi pasaytiriladigan tenglamalar

::: formula Uch tur
| Tur | Almashtirish | Natija |
|---|---|---|
| y^{(n)} = f(x) | — | n marta ketma-ket integrallash |
| F(x, y', y'') = 0 (y yo'q) | y' = p(x), y'' = p' | p ga nisbatan 1-tartibli |
| F(y, y', y'') = 0 (x yo'q) | y' = p(y), y'' = p{dp|dy} | p(y) ga nisbatan 1-tartibli |
:::

n-tartibli tenglamaning umumiy yechimida **n ta** ixtiyoriy o'zgarmas bo'ladi; Koshi masalasida n ta boshlang'ich shart beriladi: y(x_{0}), y'(x_{0}), …, y^{(n−1)}(x_{0}).

## Chiziqli tenglamalar

$$
y'' + p(x)y' + q(x)y = f(x)
$$

f = 0 — **bir jinsli** (BJ), f ≠ 0 — **bir jinsli emas** (BJE).

::: teorema BJ tenglama yechimlarining xossalari
1. y_{1}, y_{2} yechim bo'lsa, C_{1}y_{1} + C_{2}y_{2} ham yechim (**superpozitsiya**).
2. y_{1}, y_{2} **chiziqli erkli** bo'lsa (y_{2}/y_{1} ≠ const), ular **fundamental sistema** tashkil qiladi va umumiy yechim: **y = C_{1}y_{1} + C_{2}y_{2}**.
:::

Erklilikni tekshirish — **Vronskiy determinanti**:

$$
W(x) = [|y_{1} y_{2}; y'_{1} y'_{2}|] = y_{1}y'_{2} − y_{2}y'_{1}
$$

W ≠ 0 — erkli, W ≡ 0 — bog'liq.

::: teorema BJE tenglama umumiy yechimining tuzilishi
$$
y = y_{BJ} + y^{*}
$$
y_{BJ} = C_{1}y_{1} + C_{2}y_{2} — mos bir jinsli tenglamaning umumiy yechimi, y^{*} — BJE tenglamaning **istalgan bitta** xususiy yechimi.
:::

Bu xuddi chiziqli algebra sistemalaridagi qoida: «bir jinsli sistemaning umumiy yechimi + bitta xususiy yechim» (Miqdoriy usullar, 4-mavzu).

::: formula O'zgarmaslarni variatsiyalash (Lagranj)
y^{*} = C_{1}(x)y_{1} + C_{2}(x)y_{2} ko'rinishda qidiramiz, bu yerda

$$
[:C'_{1}y_{1} + C'_{2}y_{2} = 0; C'_{1}y'_{1} + C'_{2}y'_{2} = f(x):]
$$

Sistemaning determinanti aynan W ≠ 0, shuning uchun u doim yechiladi.
:::

## Ishlangan misollar

::: misol Ketma-ket integrallash
y'' = 6x, y(0) = 1, y'(0) = 2.
---
y' = 3x^2 + C_{1}, y = x^3 + C_{1}x + C_{2}.

y'(0) = C_{1} = 2, y(0) = C_{2} = 1 ⇒ **y = x^3 + 2x + 1**.
:::

::: misol y qatnashmagan tenglama
xy'' = y'.
---
y' = p: xp' = p ⇒ {dp|p} = {dx|x} ⇒ p = C_{1}x.

y' = C_{1}x ⇒ **y = C_{1}{x^2|2} + C_{2}** (yoki y = Ax^2 + B).
:::

::: misol x qatnashmagan tenglama
yy'' = (y')^2.
---
y' = p(y), y'' = p{dp|dy}: yp{dp|dy} = p^2 ⇒ {dp|p} = {dy|y} ⇒ p = C_{1}y.

y' = C_{1}y ⇒ **y = C_{2}e^{C_{1}x}**.
:::

::: misol Vronskiy va tuzilish
y'' − y = −x. y_{1} = e^{x}, y_{2} = e^{−x} — bir jinsli qismning yechimlari. Umumiy yechim?
---
W = e^{x}·(−e^{−x}) − e^{−x}·e^{x} = −2 ≠ 0 — erkli, fundamental sistema.

Xususiy yechimni ko'z bilan topamiz: y^{*} = x ⇒ y^{*''} − y^{*} = 0 − x = −x ✓.

**y = C_{1}e^{x} + C_{2}e^{−x} + x**.
:::

::: xato
- **n-tartibli tenglamada n tadan kam o'zgarmas qoldirish** — umumiy yechim to'liq emas.
- **BJE ning xususiy yechimini topib, y_{BJ} ni qo'shmaslik** — bu umumiy yechim emas.
- **Chiziqli bog'liq funksiyalarni fundamental sistema deb olish** (masalan, e^{x} va 3e^{x}).
:::
