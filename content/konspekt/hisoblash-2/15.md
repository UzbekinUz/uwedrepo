## Teylor qatori

f funksiya x_{0} nuqtada istalgan tartibli hosilalarga ega bo'lsa:

$$
f(x) = f(x_{0}) + f'(x_{0})(x − x_{0}) + {f''(x_{0})|2!}(x − x_{0})^2 + … + {f^{(n)}(x_{0})|n!}(x − x_{0})^{n} + R_{n}(x)
$$

x_{0} = 0 bo'lsa — **Makloren qatori**. Qoldiq had (Lagranj shaklida): R_{n} = {f^{(n+1)}(c)|(n + 1)!}(x − x_{0})^{n+1}, c — x_{0} va x orasidagi nuqta. R_{n} → 0 bo'lsa, funksiya o'z Teylor qatoriga teng.

::: formula Asosiy Makloren yoyilmalari
| Funksiya | Yoyilma | Soha |
|---|---|---|
| e^{x} | 1 + x + {x^2|2!} + {x^3|3!} + … | ℝ |
| sin x | x − {x^3|3!} + {x^5|5!} − … | ℝ |
| cos x | 1 − {x^2|2!} + {x^4|4!} − … | ℝ |
| ln(1 + x) | x − {x^2|2} + {x^3|3} − … | (−1; 1] |
| (1 + x)^{m} | 1 + mx + {m(m − 1)|2!}x^2 + … | (−1; 1) |
| {1|1 − x} | 1 + x + x^2 + … | (−1; 1) |
:::

::: grafik x: -4..4, y: -2.5..2.5 | sin x va uning Makloren ko'phadlari: hadlar ko'paygan sari yaqinlashish sohasi kengayadi
y = sin(x) | teal | sin x
y = x | slate | T₁ = x
y = x - x^3/6 | amber | T₃
y = x - x^3/6 + x^5/120 | rose | T₅
:::

## Qatorlarning tatbiqlari

::: tushuncha Uch asosiy foydalanish
1. **Taqribiy hisoblash:** bir necha had olinadi, xato — birinchi tashlangan had (ishora almashinuvchi qatorda) yoki R_{n} orqali baholanadi.
2. **Limitlar:** 0/0 noaniqlikda funksiyalar yoyilmasi bilan almashtiriladi — Lopitalning qulay o'rinbosari.
3. **Integrallar:** e^{−x^2}, {sin x|x} kabi funksiyalarning boshlang'ich funksiyasi elementar emas — qatorni hadma-had integrallaymiz.
:::

## Ishlangan misollar

::: misol e sonini hisoblash
e^{x} qatorining 6 ta hadi bilan e ni toping, xatoni baholang.
---
e ≈ 1 + 1 + {1|2} + {1|6} + {1|24} + {1|120} = 2,71667.

R_{5} = {e^{c}|6!} < {3|720} ≈ 0,0042. Haqiqiy xato: 2,71828 − 2,71667 ≈ **0,0016**.
:::

::: misol Ildizni taqribiy hisoblash
√1,1 ni 0,0001 aniqlikda.
---
(1 + x)^{1/2} = 1 + {1|2}x − {1|8}x^2 + {1|16}x^3 − …, x = 0,1:

1 + 0,05 − 0,00125 + 0,0000625 ≈ **1,04881** (aniq 1,0488088). Keyingi had ≈ 0,000004 — aniqlik yetarli.
:::

::: misol Limit
lim_{x→0} {e^{x} − 1 − x|x^2}.
---
e^{x} = 1 + x + {x^2|2} + {x^3|6} + … ⇒ surat = {x^2|2} + {x^3|6} + …

{x^2/2 + x^3/6 + …|x^2} = {1|2} + {x|6} + … → **{1|2}**.
:::

::: misol Olinmaydigan integral
∫_{0}^{1} e^{−x^2} dx ni 0,001 aniqlikda.
---
e^{−x^2} = 1 − x^2 + {x^4|2!} − {x^6|3!} + {x^8|4!} − … Hadma-had integrallaymiz:

∫_{0}^{1} = 1 − {1|3} + {1|10} − {1|42} + {1|216} − {1|1320} + …

Ishora almashinuvchi: birinchi tashlangan had {1|1320} ≈ 0,00076 < 0,001. 5 ta had yig'indisi ≈ **0,7475** (aniq qiymat 0,7468).
:::

::: misol Moliyaviy taxmin
Stavka 5%, 10 yil: (1,05)^{10} ni binomial yoyilma bilan.
---
(1 + r)^{n} ≈ 1 + nr + {n(n − 1)|2}r^2 + {n(n − 1)(n − 2)|6}r^3.

1 + 0,5 + 45·0,0025 + 120·0,000125 = 1 + 0,5 + 0,1125 + 0,015 = **1,6275** (aniq 1,6289). Ikki had (1,5) — «oddiy foiz», keyingilari — «foizga foiz» effekti.
:::

::: xato
- **n! ni unutish:** f^{(n)}(x_{0}) ning o'zi emas, f^{(n)}(x_{0})/n! koeffitsiyent.
- **ln(1 + x) yoyilmasini x > 1 da ishlatish** — u yerda qator uzoqlashadi. ln 3 uchun boshqa usul kerak (masalan, ln 3 = −ln(1 − 2/3)).
- **Taqribiy hisobda xatoni baholamaslik.**
:::
