::: maqsad
- Ikki o'zgaruvchili funksiya ekstremumining zaruriy shartini (statsionar nuqtalar)
- Yetarli shartni: Δ = AC − B^2 testi, egar nuqta
- Yopiq sohada eng katta va eng kichik qiymatni topishni
- Ikki mahsulot chiqaradigan firma foydasini maksimallashtirishni
:::

::: hayot Hayotda qayerda kerak?
Firma ikki xil mahsulot chiqaradi. Har birini qancha ishlab chiqarsa, foyda eng katta bo'ladi? Bir o'zgaruvchida «hosila = 0» qilib yechardik. Endi ikkita hosila — ikkalasini ham nolga tenglaymiz. Lekin yangi narsa ham bor: **egar nuqta** — bir yo'nalishda tepalik, boshqasida chuqurlik.
:::

## Lokal ekstremum va zaruriy shart

M_{0} nuqta atrofidagi barcha nuqtalarda f(M) ≤ f(M_{0}) bo'lsa — **lokal maksimum**, f(M) ≥ f(M_{0}) bo'lsa — **lokal minimum**.

::: teorema Zaruriy shart
Differensiallanuvchi funksiya M_{0} da ekstremumga ega bo'lsa:

$$
f'_{x}(M_{0}) = 0, f'_{y}(M_{0}) = 0
$$

ya'ni grad f = 0. Bunday nuqtalar **statsionar** (kritik) nuqtalar deyiladi. Har bir statsionar nuqta ham ekstremum emas!
:::

## Yetarli shart

Statsionar nuqtada ikkinchi hosilalarni hisoblaymiz: A = f''_{xx}, B = f''_{xy}, C = f''_{yy} va

$$
Δ = AC − B^2 = [|A B; B C|]
$$

::: formula Δ testi
| Shart | Xulosa |
|---|---|
| Δ > 0, A > 0 | lokal **minimum** |
| Δ > 0, A < 0 | lokal **maksimum** |
| Δ < 0 | ekstremum yo'q — **egar nuqta** |
| Δ = 0 | test javob bermaydi, qo'shimcha tekshiruv kerak |
:::

Egar nuqtani z = x^2 − y^2 yaxshi ko'rsatadi: Ox bo'ylab (y = 0) bu parabola z = x^2 (pastda minimum), Oy bo'ylab (x = 0) — z = −y^2 (tepada maksimum).

::: grafik x: -2..2, y: -4..4 | z = x² − y² ning ikki kesimi: (0; 0) — egar nuqta
y = x^2 | teal | y = 0 kesimi: z = x² (minimum)
y = -x^2 | rose | x = 0 kesimi: z = −y² (maksimum)
nuqta 0, 0 | egar nuqta
:::

## Yopiq sohada eng katta va eng kichik qiymat

Chegaralangan yopiq sohada uzluksiz funksiya eng katta va eng kichik qiymatga erishadi (Veyershtrass). Ularni topish algoritmi:

1. Soha **ichidagi** statsionar nuqtalarni topib, f ni hisoblash.
2. Har bir **chegara chizig'ida** funksiyani bitta o'zgaruvchiga keltirib, uning eng katta/kichik qiymatlarini topish.
3. **Burchak nuqtalari**ni ham hisoblash.
4. Barcha topilgan qiymatlardan eng kattasi va eng kichigini tanlash.

## Ishlangan misollar

::: misol Minimum
f = x^2 + xy + y^2 − 3x − 6y ning ekstremumi.
---
f'_{x} = 2x + y − 3 = 0, f'_{y} = x + 2y − 6 = 0 ⇒ x = 0, y = 3.

A = 2, B = 1, C = 2: Δ = 4 − 1 = 3 > 0, A > 0 ⇒ **minimum**, f(0; 3) = 9 − 18 = **−9**.
:::

::: misol Egar nuqta va minimum
f = x^3 + y^3 − 3xy.
---
f'_{x} = 3x^2 − 3y = 0 ⇒ y = x^2; f'_{y} = 3y^2 − 3x = 0 ⇒ x = y^2. Bundan x = x^4 ⇒ x = 0 yoki x = 1.

Statsionar nuqtalar: (0; 0) va (1; 1). A = 6x, B = −3, C = 6y.

- (0; 0): Δ = 0 − 9 = −9 < 0 — **egar nuqta**.
- (1; 1): Δ = 36 − 9 = 27 > 0, A = 6 > 0 — **minimum**, f = 1 + 1 − 3 = **−1**.
:::

::: misol Ikki mahsulotli firma
Foyda P = 30x + 36y − x^2 − xy − y^2 − 10 (x, y — mahsulotlar hajmi). Optimal reja?
---
P'_{x} = 30 − 2x − y = 0, P'_{y} = 36 − x − 2y = 0. Birinchisidan y = 30 − 2x, ikkinchisiga qo'yamiz: 36 − x − 60 + 4x = 0 ⇒ **x = 8, y = 14**.

A = −2, B = −1, C = −2: Δ = 3 > 0, A < 0 ⇒ maksimum.

P_{max} = 240 + 504 − 64 − 112 − 196 − 10 = **362**.
:::

::: misol Yopiq sohada
f = x^2 + y^2 − 2x − 2y, soha D: x ≥ 0, y ≥ 0, x + y ≤ 4 (uchburchak).
---
**Ichki nuqta:** 2x − 2 = 0, 2y − 2 = 0 ⇒ (1; 1) ∈ D, f = −2.

**x = 0:** f = y^2 − 2y, y ∈ [0; 4]: y = 1 da −1, uchlarda 0 va 8.

**y = 0:** simmetriya bo'yicha x = 1 da −1, uchlarda 0 va 8.

**x + y = 4:** y = 4 − x qo'ysak, f = 2x^2 − 8x + 8 = 2(x − 2)^2: x = 2 da 0, uchlarda 8.

**Javob:** eng kichik qiymat **−2** (1; 1) da; eng katta **8** — (4; 0) va (0; 4) burchaklarda.
:::

::: xato
- **Statsionar nuqtani darhol ekstremum deb e'lon qilish.** Δ < 0 bo'lsa — egar nuqta.
- **Δ ni A·C deb hisoblash** — B^2 ni ayirishni unutmang.
- **Yopiq sohada chegarani tekshirmaslik.** Eng katta qiymat ko'pincha chegarada, hatto burchakda bo'ladi.
:::
