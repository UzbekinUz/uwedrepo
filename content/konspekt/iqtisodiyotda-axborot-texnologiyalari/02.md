## MS Access va uning obyektlari

**MS Access** — Microsoft Office tarkibidagi relyatsion MBBT. Fayl kengaytmasi — **.accdb** (eski versiyalarda .mdb).

| Obyekt | Vazifasi |
|---|---|
| **Jadvallar (Tables)** | Ma'lumotlarni saqlash — MBning asosi |
| **So'rovlar (Queries)** | Ma'lumotlarni tanlash, hisoblash, o'zgartirish |
| **Formalar (Forms)** | Ma'lumot kiritish va ko'rish uchun qulay oyna |
| **Hisobotlar (Reports)** | Chop etish uchun natijalarni rasmiylashtirish |
| **Makroslar (Macros)** | Amallarni avtomatlashtirish |
| **Modullar (Modules)** | VBA tilidagi dasturlar |

## Jadval yaratish usullari

- **Jadval rejimi (Datasheet View)** — Excel'ga o'xshash, darhol ma'lumot kiritish.
- **Konstruktor rejimi (Design View)** — maydon nomi, turi va xususiyatlarini aniq belgilash. **Tavsiya etiladigan usul.**
- Tashqi manbadan import (Excel, CSV, boshqa MB).

## Maydon (ma'lumot) turlari

| Tur | Nima uchun | Misol |
|---|---|---|
| **Short Text (Qisqa matn)** | 255 belgigacha matn | Familiya, telefon |
| **Long Text (Uzun matn)** | Katta izohlar | Tavsif |
| **Number (Son)** | Hisob-kitob qilinadigan sonlar | Soni, yoshi |
| **Currency (Pul)** | Pul summalari | Narx, maosh |
| **Date/Time** | Sana va vaqt | Tug'ilgan sana |
| **AutoNumber (Hisoblagich)** | Avtomatik o'suvchi raqam | ID |
| **Yes/No (Mantiqiy)** | Ha/yo'q | Grant asosidami |
| **Lookup (Qiymatlar ro'yxati)** | Ro'yxatdan tanlash | Fakultet |
| **Attachment, OLE** | Fayl, rasm | Fotosurat |
| **Hyperlink** | Havola | Veb-sayt |

::: eslatma Telefon raqami — son emasmi?
Telefon, pasport seriyasi, pochta indeksi — **matn** turida saqlanadi: ular bilan hisob-kitob qilinmaydi, boshida 0 yoki + belgisi bo'lishi mumkin.
:::

## Maydon xususiyatlari

- **Field Size (o'lcham)** — matn uzunligi yoki son turi.
- **Format** — ko'rinish (masalan, sana formati).
- **Input Mask (kiritish niqobi)** — kiritish shabloni, masalan telefon uchun.
- **Default Value (standart qiymat)** — masalan, bugungi sana.
- **Validation Rule (tekshirish sharti)** — masalan, GPA 0 dan 5 gacha: Between 0 And 5.
- **Validation Text** — shart buzilganda chiqadigan xabar.
- **Required (majburiy)** — bo'sh qoldirib bo'lmaydi.
- **Indexed** — tez qidirish uchun indeks (takrorlanmaydigan yoki takrorlanadigan).

## Birlamchi kalit va bog'lanishlar

**Birlamchi kalit** konstruktor rejimida maydonni tanlab, «Key» (kalit) tugmasi bilan belgilanadi; odatda **AutoNumber** turidagi ID.

**Ma'lumotlar sxemasi (Database Tools → Relationships):**
1. Jadvallarni sxemaga qo'shish.
2. Birlamchi kalitni tashqi kalit ustiga sichqoncha bilan sudrash.
3. **«Ma'lumotlar yaxlitligini ta'minlash» (Enforce Referential Integrity)** belgisini qo'yish.
4. Zarur bo'lsa: **kaskadli yangilash** va **kaskadli o'chirish**.

::: tushuncha Ma'lumotlar yaxlitligi
**Referensial yaxlitlik** — tashqi kalitdagi har bir qiymat bog'langan jadvalning birlamchi kalitida mavjud bo'lishi sharti. Masalan, «Baholar» jadvaliga mavjud bo'lmagan talabaning bahosini kiritib bo'lmaydi.
:::

::: misol Vaziyat: maydon turlarini tanlang
«Xodimlar» jadvali: XodimID, F.I.Sh., Tug'ilgan sana, Telefon, Maosh, Bo'lim (5 ta bo'limdan biri), Shartnoma asosidami. Har biriga tur tanlang.
---
XodimID — **AutoNumber** (birlamchi kalit); F.I.Sh. — **Short Text**; Tug'ilgan sana — **Date/Time**; Telefon — **Short Text** (kiritish niqobi bilan); Maosh — **Currency** (tekshirish sharti: 0 dan katta); Bo'lim — **Lookup** yoki alohida «Bo'limlar» jadvaliga tashqi kalit; Shartnoma — **Yes/No**.
:::

::: xato
- **Bog'lanishda yaxlitlik belgisini qo'ymaslik.** Natijada «yetim» yozuvlar paydo bo'ladi — mavjud bo'lmagan mijozga tegishli buyurtmalar.
- **Bog'lanuvchi maydonlarning turlari mos kelmasligi.** AutoNumber kalit bilan bog'lanuvchi tashqi kalit **Number (Long Integer)** turida bo'lishi kerak.
:::
