## So'rov nima?

::: tushuncha Ta'rif
**So'rov (query)** — bir yoki bir nechta jadvaldan **shartga mos** ma'lumotlarni tanlash, hisoblash yoki o'zgartirish buyrug'i. So'rov natijasi vaqtinchalik jadval ko'rinishida chiqadi va har safar ochilganda yangilanadi.
:::

**Yaratish usullari:** So'rovlar ustasi (Query Wizard), **konstruktor (Query Design)** va **SQL rejimi**.

## So'rov turlari

| Tur | Vazifasi |
|---|---|
| **Tanlash (Select)** | Shartga mos yozuvlarni ko'rsatish |
| **Parametrli** | Shart qiymati har safar foydalanuvchidan so'raladi |
| **Yakuniy (guruhlash, Totals)** | Guruhlar bo'yicha yig'indi, o'rtacha, soni |
| **Kesishma (Crosstab)** | Ikki o'lchovli jamlama jadval |
| **Jadval yaratish (Make Table)** | Natijadan yangi jadval |
| **Qo'shish (Append)** | Yozuvlarni boshqa jadvalga qo'shish |
| **Yangilash (Update)** | Qiymatlarni ommaviy o'zgartirish |
| **O'chirish (Delete)** | Shartga mos yozuvlarni o'chirish |

Oxirgi to'rttasi — **o'zgartirish so'rovlari**: ular ma'lumotlarni o'zgartiradi, shuning uchun ishga tushirishdan oldin zaxira nusxa olish tavsiya etiladi.

## Shartlar (Criteria)

| Shart | Ma'nosi |
|---|---|
| > 1000000 | 1 mln dan katta |
| Between 3,5 And 5 | 3,5 dan 5 gacha |
| "Toshkent" | Aynan Toshkent |
| Like "A*" | A harfi bilan boshlanadi |
| Is Null | Bo'sh qiymat |
| >=#01.01.2026# | 2026-yil 1-yanvardan keyin |

Bir qatordagi shartlar — **VA (And)**, turli qatorlardagi shartlar — **YOKI (Or)** bilan birlashadi.

**Hisoblanuvchi maydon:** konstruktorda bo'sh ustunga yoziladi, masalan: Summa: [Narx]*[Soni].

**Parametrli so'rov:** shart katagiga kvadrat qavsda savol yoziladi: [Shahar nomini kiriting].

## SQL asoslari

**SQL (Structured Query Language)** — relyatsion MBlar bilan ishlash tili. Access'da har bir so'rov aslida SQL buyrug'idir (Ko'rinish → SQL rejimi).

```sql
-- Toshkentdagi mijozlar, familiya bo'yicha saralangan
SELECT Familiya, Ism, Telefon
FROM Mijozlar
WHERE Shahar = 'Toshkent'
ORDER BY Familiya;

-- Har bir shahar bo'yicha savdo summasi (guruhlash)
SELECT Mijozlar.Shahar, SUM(Sotuvlar.Narx * Sotuvlar.Soni) AS Jami
FROM Mijozlar INNER JOIN Sotuvlar ON Mijozlar.MijozID = Sotuvlar.MijozID
GROUP BY Mijozlar.Shahar
HAVING SUM(Sotuvlar.Narx * Sotuvlar.Soni) > 10000000;

-- Barcha tovar narxini 10 % ga oshirish (yangilash so'rovi)
UPDATE Tovarlar SET Narx = Narx * 1.1;
```

::: eslatma Asosiy SQL kalit so'zlari
- **SELECT** — qaysi maydonlar; **FROM** — qaysi jadvaldan; **WHERE** — yozuvlar uchun shart.
- **ORDER BY** — saralash (ASC o'suvchi, DESC kamayuvchi).
- **GROUP BY** — guruhlash; **HAVING** — guruhlar uchun shart.
- **JOIN** — jadvallarni bog'lash; **INNER JOIN** faqat ikkala jadvalda mos yozuvlarni oladi.
- Agregat funksiyalar: **SUM, AVG, COUNT, MIN, MAX**.
- **INSERT, UPDATE, DELETE** — qo'shish, yangilash, o'chirish.
:::

::: misol Vaziyat: so'rov yozing
«Talabalar» (TalabaID, Familiya, Guruh, GPA) jadvalidan GPA 4 dan yuqori bo'lgan talabalarni GPA bo'yicha kamayish tartibida chiqaring. Keyin har bir guruhning o'rtacha GPA sini hisoblang.
---
```sql
SELECT Familiya, Guruh, GPA
FROM Talabalar
WHERE GPA > 4
ORDER BY GPA DESC;

SELECT Guruh, AVG(GPA) AS OrtachaGPA, COUNT(*) AS Soni
FROM Talabalar
GROUP BY Guruh;
```
Access konstruktorida ikkinchi so'rov uchun «Totals» (Σ) tugmasi bosilib, Guruh — Group By, GPA — Avg qilib belgilanadi.
:::

::: xato
- **WHERE va HAVING ni aralashtirish.** WHERE — guruhlashdan oldin alohida yozuvlarga; HAVING — guruhlashdan keyin guruhlarga shart qo'yadi.
- **O'zgartirish so'rovini sinamasdan ishga tushirish.** Avval xuddi shu shart bilan tanlash so'rovini bajarib, qaysi yozuvlar o'zgarishini tekshiring.
:::

## O'zingizni tekshiring

::: test
? Guruhlar uchun shart qo'yuvchi SQL kalit so'zi?
- WHERE
- ORDER BY
- SELECT
+ HAVING
> HAVING GROUP BY dan keyin guruhlarga shart qo'yadi.
? Har safar ishga tushganda foydalanuvchidan qiymat so'raydigan so'rov?
- Kesishma so'rov
+ Parametrli so'rov
- O'chirish so'rovi
- Jadval yaratish so'rovi
> Parametr shart katagiga kvadrat qavsdagi savol sifatida yoziladi.
? Faqat ikkala jadvalda mos keladigan yozuvlarni qaytaruvchi bog'lash?
- LEFT JOIN
- UNION
+ INNER JOIN
- CROSS JOIN
> INNER JOIN — ichki bog'lash.
:::

## Mustaqil mashqlar

::: mashq
O'zgartirish so'rovlarining to'rt turini ayting. || Jadval yaratish, qo'shish, yangilash, o'chirish.

«Tovarlar» jadvalidan narxi 50 000 dan arzon tovarlarni chiqaruvchi SQL yozing. || SELECT Nomi, Narx FROM Tovarlar WHERE Narx < 50000;
:::

:::
