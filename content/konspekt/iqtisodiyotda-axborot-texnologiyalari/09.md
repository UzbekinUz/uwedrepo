## Faktorlar

::: tushuncha Ta'rif
**Faktor** — **kategorial** (toifali) ma'lumotlarni saqlovchi tuzilma: jins, viloyat, ta'lim darajasi, baho. Faktor qiymatlari **darajalar (levels)** deyiladi.
:::

```r
viloyat <- factor(c("Toshkent", "Samarqand", "Toshkent", "Buxoro", "Toshkent"))
levels(viloyat)    # "Buxoro" "Samarqand" "Toshkent"
table(viloyat)     # har bir daraja necha marta uchraydi
nlevels(viloyat)   # 3

# Tartibli faktor (darajalar orasida tartib bor)
reyting <- factor(c("past", "yuqori", "o'rta"),
                  levels = c("past", "o'rta", "yuqori"), ordered = TRUE)
reyting[1] < reyting[2]   # TRUE
```

Faktorlar statistik modellarda (regressiya) va grafiklarda guruhlar sifatida avtomatik ishlatiladi.

## Data frame

**Data frame** — R dagi asosiy **jadval** tuzilmasi: har bir ustun — vektor (o'z turida), barcha ustunlar uzunligi teng. Excel varag'i yoki MB jadvaliga o'xshaydi.

```r
mijozlar <- data.frame(
  ism     = c("Ali", "Laylo", "Bekzod", "Madina", "Sardor"),
  viloyat = c("Toshkent", "Samarqand", "Toshkent", "Buxoro", "Toshkent"),
  xarid   = c(1200, 800, 1500, 600, 950),
  doimiy  = c(TRUE, FALSE, TRUE, FALSE, TRUE)
)
head(mijozlar)       # birinchi 6 qator
str(mijozlar)        # tuzilma va turlar
summary(mijozlar)    # statistik qisqacha ma'lumot
nrow(mijozlar); ncol(mijozlar); names(mijozlar)
```

**Murojaat va filtrlash:**

```r
mijozlar$xarid                         # ustun (vektor)
mijozlar[2, ]                          # 2-qator
mijozlar[mijozlar$xarid > 900, ]       # shart bo'yicha qatorlar
subset(mijozlar, viloyat == "Toshkent", select = c(ism, xarid))
mijozlar[order(-mijozlar$xarid), ]     # xarid bo'yicha kamayish tartibida
mijozlar$bonus <- mijozlar$xarid * 0.05   # yangi ustun
```

**Guruhlash:**

```r
aggregate(xarid ~ viloyat, data = mijozlar, FUN = mean)
tapply(mijozlar$xarid, mijozlar$viloyat, sum)
```

```r
library(dplyr)
mijozlar %>%
  filter(xarid > 700) %>%
  group_by(viloyat) %>%
  summarise(ortacha = mean(xarid), soni = n()) %>%
  arrange(desc(ortacha))
```

**%>%** («pipe») — natijani keyingi funksiyaga uzatadi: kod chapdan o'ngga, qadam-baqadam o'qiladi.
