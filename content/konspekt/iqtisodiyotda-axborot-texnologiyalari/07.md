## Taqqoslash va mantiqiy operatorlar

| Operator | Ma'nosi | Misol | Natija |
|---|---|---|---|
| == | teng | 5 == 5 | TRUE |
| != | teng emas | 5 != 3 | TRUE |
| > , < | katta, kichik | 7 > 10 | FALSE |
| >= , <= | katta yoki teng, kichik yoki teng | 4 >= 4 | TRUE |

**Mantiqiy operatorlar:** **&** — VA, **vertikal chiziq** — YOKI, **!** — EMAS, **xor()** — faqat bittasi rost. Vektorlar uchun bittalik (& va bitta chiziq), if shartida bitta qiymat uchun ikkitalik (&& va ikki chiziq) shakl ishlatiladi:

```r
daromad <- 8000000
qarz <- 1000000
daromad > 5000000 & qarz < 2000000   # TRUE  (VA)
daromad > 10000000 | qarz == 0       # FALSE (YOKI)
!(qarz > 0)                          # FALSE (EMAS)
xor(TRUE, FALSE)                     # TRUE: faqat bittasi rost
if (daromad > 0 && qarz >= 0) print("To'g'ri ma'lumot")
if (qarz == 0 || daromad > 1e7) print("Imtiyozli mijoz")
```

## Shartli operatorlar

```r
ball <- 78
if (ball >= 86) {
  baho <- "A'lo"
} else if (ball >= 71) {
  baho <- "Yaxshi"
} else if (ball >= 55) {
  baho <- "Qoniqarli"
} else {
  baho <- "Qoniqarsiz"
}
print(baho)   # "Yaxshi"
```

**ifelse()** — vektor uchun shart, har bir element alohida tekshiriladi:

```r
ballar <- c(92, 64, 45, 80)
ifelse(ballar >= 55, "O'tdi", "Yiqildi")
# "O'tdi" "O'tdi" "Yiqildi" "O'tdi"
```

**switch()** — bir nechta variantdan tanlash: switch("b", a = 1, b = 2, c = 3) natijasi 2.

## Sikllar

::: eslatma Uch turdagi sikl
- **for** — oldindan ma'lum to'plam yoki son marta takrorlash.
- **while** — shart rost bo'lguncha takrorlash (shart oldindan tekshiriladi).
- **repeat** — cheksiz sikl, faqat **break** bilan to'xtaydi.
:::

```r
# for: 1 dan 5 gacha kvadratlar
for (i in 1:5) {
  cat(i, "ning kvadrati:", i^2, "\n")
}

# while: depozit qachon ikki baravar bo'ladi? (yillik 20 %)
summa <- 1000000
yil <- 0
while (summa < 2000000) {
  summa <- summa * 1.20
  yil <- yil + 1
}
cat("Kerakli yillar:", yil, "\n")   # 4

# repeat + break: tasodifiy son 6 tushguncha zar tashlash
set.seed(1)
urinish <- 0
repeat {
  zar <- sample(1:6, 1)
  urinish <- urinish + 1
  if (zar == 6) break
}
urinish
```

**break** — siklni butunlay to'xtatadi; **next** — joriy qadamni o'tkazib, keyingisiga o'tadi:

```r
for (i in 1:10) {
  if (i %% 2 == 0) next   # juft sonlarni o'tkazib yuborish
  print(i)                # 1 3 5 7 9
}
```

::: eslatma Vektorlashtirish
R da ko'p hisob-kitoblar siklsiz, butun vektor bilan bajariladi va bu tezroq: sum(1:100) yoki 1:5 vektorining kvadratlari (pastdagi kod).

```r
sum(1:100)   # 5050
(1:5)^2      # 1 4 9 16 25
```

Siklni faqat haqiqatan zarur bo'lganda ishlating.
:::

::: misol Vaziyat: kredit skoring
Mijozlar daromadi (mln so'm): 4, 9, 12, 6. Qoida: daromad 10 dan katta — «Tasdiqlandi», 5 dan 10 gacha — «Qo'shimcha tekshiruv», 5 dan kam — «Rad etildi». Sikl bilan va siklsiz yechim yozing.
---
```r
daromad <- c(4, 9, 12, 6)

# 1-usul: for sikli
for (d in daromad) {
  if (d > 10) {
    qaror <- "Tasdiqlandi"
  } else if (d >= 5) {
    qaror <- "Qo'shimcha tekshiruv"
  } else {
    qaror <- "Rad etildi"
  }
  cat(d, "mln:", qaror, "\n")
}

# 2-usul: ichma-ich ifelse (siklsiz)
ifelse(daromad > 10, "Tasdiqlandi",
       ifelse(daromad >= 5, "Qo'shimcha tekshiruv", "Rad etildi"))
```
Natija: 4 — Rad etildi; 9 — Qo'shimcha tekshiruv; 12 — Tasdiqlandi; 6 — Qo'shimcha tekshiruv.
:::

::: xato
- **Tenglikni tekshirishda bitta = yozish.** if (x = 5) xato; to'g'risi if (x == 5).
- **while siklida o'zgaruvchini yangilamaslik.** Shart hech qachon yolg'on bo'lmaydi va sikl cheksiz davom etadi.
:::
