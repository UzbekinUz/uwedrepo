## Vektorlar

::: tushuncha Ta'rif
**Vektor** — R ning asosiy tuzilmasi: **bir xil turdagi** elementlarning tartiblangan to'plami. Hatto bitta son ham uzunligi 1 bo'lgan vektor.
:::

```r
savdo <- c(120, 135, 150, 110)   # c() — birlashtirish
oylar <- 1:12                    # 1 dan 12 gacha
qadam <- seq(0, 100, by = 25)    # 0 25 50 75 100
takror <- rep("A", 3)            # "A" "A" "A"
length(savdo)                    # 4
```

**Indekslash** (R da indeks **1 dan** boshlanadi):

```r
savdo[2]            # 135
savdo[c(1, 3)]      # 120 150
savdo[-1]           # birinchisidan tashqari: 135 150 110
savdo[savdo > 120]  # shart bo'yicha: 135 150
names(savdo) <- c("Yan", "Fev", "Mar", "Apr")
savdo["Mar"]        # 150
```

**Vektor amallari** element bo'yicha bajariladi:

```r
narx <- c(10, 20, 30)
soni <- c(2, 5, 1)
narx * soni          # 20 100 30
sum(narx * soni)     # 150
mean(savdo); max(savdo); min(savdo); sort(savdo, decreasing = TRUE)
which.max(savdo)     # eng katta element indeksi
cumsum(savdo)        # yig'ma yig'indi
```

Turli turlar aralashsa, R ularni bitta turga keltiradi: c(1, "a", TRUE) — hammasi matnga aylanadi.

## Matritsalar

**Matritsa** — bir xil turdagi elementlarning **ikki o'lchovli** jadvali (qatorlar va ustunlar).

```r
m <- matrix(1:6, nrow = 2, ncol = 3)   # ustunlar bo'yicha to'ldiriladi
m
#      [,1] [,2] [,3]
# [1,]    1    3    5
# [2,]    2    4    6
m[2, 3]        # 6 — 2-qator, 3-ustun
m[1, ]         # 1-qator: 1 3 5
m[, 2]         # 2-ustun: 3 4
dim(m)         # 2 3
t(m)           # transponirlash
```

```r
A <- matrix(c(2, 1, 1, 3), nrow = 2)
B <- matrix(c(1, 0, 0, 1), nrow = 2)
A * B          # element bo'yicha ko'paytirish
A %*% B        # matritsa ko'paytmasi
det(A)         # determinant: 5
solve(A)       # teskari matritsa
rbind(m, 7:9)  # qator qo'shish
cbind(m, 0)    # ustun qo'shish
rowSums(m); colMeans(m)
```

**Qator va ustun nomlari:** rownames() va colnames(); **apply(m, 1, sum)** — har bir qatorga funksiya qo'llash (2 — ustunlarga).

## Ro'yxatlar (list)

**Ro'yxat** — **turli turdagi** va turli uzunlikdagi elementlarni (vektor, matritsa, boshqa ro'yxat) saqlovchi tuzilma.

```r
firma <- list(
  nomi = "Paxta Invest",
  xodimlar = c("Ali", "Vali", "Laylo"),
  savdo = matrix(c(100, 120, 90, 110), nrow = 2),
  davlat = TRUE
)
firma$nomi            # "Paxta Invest"
firma[["xodimlar"]]   # vektor
firma["xodimlar"]     # ro'yxat (bitta elementli)
firma$xodimlar[2]     # "Vali"
firma$yil <- 2026     # yangi element qo'shish
names(firma)          # elementlar nomlari
str(firma)            # tuzilmani ko'rish
```

Ro'yxatga funksiyani qo'llash: **lapply()** (natija — ro'yxat), **sapply()** (natija — imkon qadar vektor).

| Tuzilma | O'lchov | Element turlari |
|---|---|---|
| Vektor | 1 | Bir xil |
| Matritsa | 2 | Bir xil |
| Massiv (array) | 2 dan ko'p | Bir xil |
| Ro'yxat | 1 (ichma-ich) | Turli |
| Data frame (9-mavzu) | 2 | Har bir ustun o'z turida |

::: misol Vaziyat: filiallar savdosi
3 ta filialning 4 choraklik savdosi (mln so'm): Toshkent — 50, 55, 60, 70; Samarqand — 30, 32, 35, 40; Buxoro — 20, 25, 22, 28. Matritsa tuzing, har bir filialning yillik savdosini va har bir chorakdagi jami savdoni toping.
---
```r
savdo <- matrix(c(50, 55, 60, 70,
                  30, 32, 35, 40,
                  20, 25, 22, 28),
                nrow = 3, byrow = TRUE)
rownames(savdo) <- c("Toshkent", "Samarqand", "Buxoro")
colnames(savdo) <- c("Q1", "Q2", "Q3", "Q4")
rowSums(savdo)   # Toshkent 235, Samarqand 137, Buxoro 95
colSums(savdo)   # Q1 100, Q2 112, Q3 117, Q4 138
```
byrow = TRUE — matritsani qatorlar bo'yicha to'ldirish.
:::

::: xato
- **Indeksni 0 dan boshlash.** R da birinchi element x[1]; x[0] bo'sh vektor qaytaradi.
- **Element bo'yicha va matritsa ko'paytmasini aralashtirish.** A * B — element bo'yicha; A %*% B — chiziqli algebradagi matritsa ko'paytmasi.
:::
