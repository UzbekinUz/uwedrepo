- Formaning vazifasi va turlarini bilishni
- Formalarni usta va konstruktor yordamida yaratishni
- Boshqaruv elementlari va forma bo'limlaridan foydalanishni
- Bo'ysunuvchi (subforma) va bosh tugmali formalarni yaratishni
:::

::: hayot Hayotda qayerda kerak?
Do'kon kassiri yoki bank operatori jadval bilan ishlamaydi — u tugmalar, ro'yxatlar va maydonlari bo'lgan qulay oynada ishlaydi. Access'da bunday oyna — **forma**. To'g'ri yaratilgan forma noto'g'ri kiritishning oldini oladi va xodimning ishini tezlashtiradi.
:::

## Forma nima?

::: tushuncha Ta'rif
**Forma** — jadval yoki so'rov ma'lumotlarini **kiritish, ko'rish va tahrirlash** uchun mo'ljallangan foydalanuvchi interfeysi (oyna). Forma ma'lumotni o'zi saqlamaydi — u **manba** (jadval yoki so'rov) bilan bog'langan.
:::

## Forma yaratish usullari

| Usul | Xususiyati |
|---|---|
| **Forma (Form)** tugmasi | Tanlangan jadval asosida bir zumda avtomatik forma |
| **Formalar ustasi (Form Wizard)** | Maydonlar, ko'rinish va uslubni bosqichma-bosqich tanlash |
| **Konstruktor (Form Design)** | Barcha elementlarni qo'lda joylashtirish — to'liq nazorat |
| **Maket rejimi (Layout View)** | Ma'lumotlarni ko'rib turib, joylashuvni o'zgartirish |
| **Bo'sh forma (Blank Form)** | Noldan yaratish |

**Forma ko'rinishlari:** bitta yozuvli (ustunli), lentali (bir nechta yozuv), jadvalli, **ajratilgan forma (Split Form)** — yuqorida forma, pastda jadval.

## Forma bo'limlari

- **Forma sarlavhasi (Form Header)** — nom, logotip, tugmalar.
- **Ma'lumotlar sohasi (Detail)** — maydonlar.
- **Forma eslatmasi (Form Footer)** — jami summalar, izohlar.

## Boshqaruv elementlari

| Element | Vazifasi |
|---|---|
| **Yozuv (Label)** | Matnli izoh |
| **Maydon (Text Box)** | Ma'lumot kiritish yoki hisoblangan qiymat |
| **Ro'yxat (List Box)** va **Ochiluvchi ro'yxat (Combo Box)** | Qiymatni ro'yxatdan tanlash |
| **Bayroqcha (Check Box)** | Ha/yo'q |
| **Tugma (Button)** | Amalni bajarish: saqlash, keyingi yozuv, hisobotni ochish |
| **Rasm, logotip** | Bezak |
| **Subforma (Subform)** | Bog'langan jadval ma'lumotlarini ko'rsatish |

**Hisoblanuvchi maydon** formada: Text Box xususiyatlarida manba sifatida ifoda yoziladi, masalan =[Narx]*[Soni].

## Bo'ysunuvchi forma (subforma)

**Subforma** — asosiy forma ichidagi forma. U **birga-ko'p** bog'lanishni ko'rsatadi: asosiy formada bitta yozuv (masalan, mijoz), subformada esa unga tegishli ko'p yozuvlar (uning barcha buyurtmalari).

**Yaratish:** Formalar ustasida ikkita bog'langan jadval maydonlarini tanlash → «bo'ysunuvchi forma» variantini belgilash yoki konstruktorda Subform elementi bilan qo'shish. Ikki forma **bog'lovchi maydonlar** (masalan, MijozID) orqali sinxronlanadi.

## Bosh tugmali forma (navigatsiya)

**Bosh tugmali forma** (Main Switchboard yoki Navigation Form) — MB ochilganda chiqadigan «bosh menyu»: «Mijozlar», «Tovarlar», «Yangi buyurtma», «Oylik hisobot» tugmalari. Foydalanuvchi jadvallarni ko'rmasdan, faqat tugmalar orqali ishlaydi. Uni **ishga tushirish formasi** sifatida belgilash mumkin (File → Options → Current Database → Display Form).

::: misol Vaziyat: qaysi formani tanlaysiz?
Universitet ofis-registratori talaba kartochkasini ochganda, uning barcha fanlar bo'yicha baholarini ham bir oynada ko'rishi kerak. Qanday forma kerak?
---
**Asosiy forma + subforma.** Asosiy forma — «Talabalar» jadvali (bitta talaba ma'lumotlari, ustunli ko'rinish); subforma — «Baholar» jadvali (lentali yoki jadvalli ko'rinish), TalabaID orqali bog'langan. Talaba almashtirilsa, subformadagi baholar avtomatik yangilanadi. Forma eslatmasiga o'rtacha baho uchun hisoblanuvchi maydon qo'shish mumkin.
:::

::: xato
- **Formani ma'lumot saqlovchi obyekt deb o'ylash.** Ma'lumotlar jadvalda saqlanadi; forma faqat ular bilan ishlash oynasi.
- **Subformani bog'lovchi maydonsiz qo'shish.** Unda subforma barcha yozuvlarni ko'rsatadi, asosiy yozuv bilan sinxronlanmaydi.
:::

## Mustaqil mashqlar

::: mashq
Formaning uchta bo'limini ayting. || Forma sarlavhasi, ma'lumotlar sohasi, forma eslatmasi.
Formani yaratishning to'rtta usulini ayting. || Avtomatik forma, Formalar ustasi, Konstruktor, Maket rejimi, Bo'sh forma.
Bosh tugmali forma nima uchun kerak? || MB bilan faqat tugmalar orqali ishlash — qulay bosh menyu, jadvallarni foydalanuvchidan yashirish.
:::

::: xulosa
Forma — jadval yoki so'rov ma'lumotlari bilan ishlash uchun interfeys. U usta, konstruktor yoki maket rejimida yaratiladi va sarlavha, ma'lumotlar sohasi hamda eslatmadan iborat. Subforma birga-ko'p bog'lanishni bir oynada ko'rsatadi, bosh tugmali forma esa butun MB uchun qulay menyu vazifasini bajaradi.
:::
