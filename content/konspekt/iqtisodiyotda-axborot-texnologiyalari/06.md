## R tili haqida

**R** — statistik hisoblash va ma'lumotlarni vizuallashtirish uchun yaratilgan **bepul, ochiq kodli** dasturlash tili (Ross Ihaka va Robert Gentleman, Yangi Zelandiya, 1993). Uning kuchi — **CRAN** omboridagi 20 000 dan ortiq paket.

**RStudio** (Posit) — R uchun qulay muhit (IDE). To'rtta panel:
1. **Skript muharriri** — kodni yozish va saqlash (.R fayl).
2. **Konsol** — kodni bajarish va natija.
3. **Muhit (Environment)** — yaratilgan o'zgaruvchilar.
4. **Fayllar, grafiklar, paketlar, yordam.**

Kodni bajarish: qatorni tanlab **Ctrl + Enter**. Yordam: ?mean yoki help(mean). Izoh # belgisi bilan yoziladi.

## O'zgaruvchilar

O'zgaruvchiga qiymat **<-** operatori bilan beriladi (= ham ishlaydi, lekin R uslubida <- afzal).

```r
narx <- 15000        # son
soni <- 3
summa <- narx * soni # 45000
shahar <- "Toshkent" # matn
grant <- TRUE        # mantiqiy qiymat
summa                # natijani ko'rish
```

**Nomlash qoidalari:** harf bilan boshlanadi; harf, raqam, nuqta va pastki chiziq ishlatiladi; katta va kichik harflar farqlanadi (Narx va narx — ikki xil o'zgaruvchi); bo'shliq ishlatilmaydi.

**Konstantalar:** pi (3.14159...), LETTERS (lotin bosh harflari), month.name (oy nomlari); maxsus qiymatlar: **NA** — yo'q ma'lumot, **NULL** — bo'sh obyekt, **Inf** — cheksizlik, **NaN** — son emas (0/0).

## Ma'lumot turlari

| Tur | Misol | Tekshirish |
|---|---|---|
| **numeric** (haqiqiy son) | 3.14, 15000 | is.numeric() |
| **integer** (butun son) | 5L | is.integer() |
| **character** (matn) | "UWED" | is.character() |
| **logical** (mantiqiy) | TRUE, FALSE | is.logical() |
| **complex** | 2+3i | is.complex() |

Turni bilish: **class(x)**. Turni o'zgartirish: as.numeric("25"), as.character(100), as.integer(3.9) — natija 3.

## Chiqarish funksiyalari

```r
x <- 45000
print(x)                         # [1] 45000
cat("Jami summa:", x, "so'm\n")  # Jami summa: 45000 so'm
paste("Narx", x, sep = ": ")     # "Narx: 45000"
paste0("ID-", 101)               # "ID-101" (ajratuvchisiz)
sprintf("Foiz: %.1f%%", 12.345)  # "Foiz: 12.3%"
format(1234567, big.mark = " ")  # "1 234 567"
```

- **print()** — obyektni ko'rsatadi, [1] indeksi bilan.
- **cat()** — bir nechta qiymatni birlashtirib chiqaradi, qator ko'chirish uchun \n kerak.
- **paste()** — matnlarni birlashtiradi (sep — ajratuvchi), **paste0()** — ajratuvchisiz.
- **sprintf()** — formatlangan chiqarish.

::: misol Vaziyat: kredit to'lovi
Mijoz 12 oyga 6 000 000 so'm kredit oldi, yillik foiz — 24 %. Oddiy foizda umumiy to'lov va oylik to'lovni R da hisoblang va chiroyli chiqaring.
---
```r
kredit <- 6000000
foiz <- 0.24
oy <- 12
jami <- kredit * (1 + foiz * oy / 12)  # 7440000
oylik <- jami / oy                     # 620000
cat("Umumiy to'lov:", format(jami, big.mark = " "), "so'm\n")
cat("Oylik to'lov:", format(oylik, big.mark = " "), "so'm\n")
```
Natija: umumiy to'lov 7 440 000 so'm, oylik to'lov 620 000 so'm.
:::

## Mustaqil mashqlar

::: mashq
R ning beshta asosiy ma'lumot turini ayting. || numeric, integer, character, logical, complex.
