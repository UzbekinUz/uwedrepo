## Bazaviy grafiklar

| Funksiya | Grafik | Qachon ishlatiladi |
|---|---|---|
| **plot()** | Nuqtali yoki chiziqli | Ikki o'zgaruvchi bog'liqligi, vaqt qatori |
| **barplot()** | Ustunli | Toifalarni taqqoslash |
| **hist()** | Gistogramma | Taqsimotni ko'rish |
| **pie()** | Doiraviy | Ulushlar (kam toifa bo'lsa) |
| **boxplot()** | Quti diagrammasi | Mediana, tarqoqlik, chetlanishlar |
| **lines(), points(), abline()** | Mavjud grafikka qo'shimcha | Trend chizig'i, qo'shimcha nuqtalar |

```r
oylar <- 1:12
savdo <- c(120, 125, 140, 138, 150, 165, 170, 168, 180, 190, 205, 220)

plot(oylar, savdo, type = "l", col = "blue", lwd = 2,
     main = "2026-yil savdo dinamikasi",
     xlab = "Oy", ylab = "Savdo, mln so'm")
points(oylar, savdo, pch = 19, col = "darkblue")
abline(lm(savdo ~ oylar), col = "red", lty = 2)   # chiziqli trend
```

**type** parametri: "p" — nuqtalar, "l" — chiziq, "b" — ikkalasi.

```r
filial <- c(Toshkent = 235, Samarqand = 137, Buxoro = 95)
barplot(filial, col = c("steelblue", "orange", "gray"),
        main = "Filiallar bo'yicha yillik savdo", ylab = "mln so'm")

set.seed(10)
daromad <- rnorm(500, mean = 6, sd = 1.5)   # 500 ta oila daromadi (taqlid)
hist(daromad, breaks = 20, col = "lightgreen",
     main = "Oilalar daromadi taqsimoti", xlab = "mln so'm")

pie(c(45, 30, 25), labels = c("Oziq-ovqat", "Kiyim", "Xizmatlar"))
boxplot(xarid ~ viloyat, data = mijozlar)    # 9-mavzudagi jadval
```

## Grafik parametrlari

- **main, xlab, ylab** — sarlavha va o'q nomlari.
- **col** — rang; **lwd** — chiziq qalinligi; **lty** — chiziq turi; **pch** — nuqta shakli; **cex** — o'lcham.
- **xlim, ylim** — o'qlar chegaralari.
- **legend()** — izoh: legend("topleft", legend = c("2025", "2026"), col = c("gray", "blue"), lty = 1).
- **par(mfrow = c(1, 2))** — bitta oynada ikkita grafik.

## ggplot2: «grafiklar grammatikasi»

**ggplot2** grafikni qatlamlardan quradi: **ma'lumot** + **estetika** (aes — o'qlar, rang) + **geometriya** (geom — nuqta, chiziq, ustun) + sozlamalar.

```r
library(ggplot2)
df <- data.frame(oy = oylar, savdo = savdo)
ggplot(df, aes(x = oy, y = savdo)) +
  geom_line(color = "steelblue", linewidth = 1) +
  geom_point() +
  geom_smooth(method = "lm", se = FALSE, linetype = "dashed") +
  labs(title = "Savdo dinamikasi", x = "Oy", y = "mln so'm") +
  theme_minimal()

ggplot(mijozlar, aes(x = viloyat, y = xarid, fill = viloyat)) +
  geom_col() +
  labs(title = "Viloyatlar bo'yicha xarid")
```

## 3D grafiklar

```r
x <- seq(-3, 3, length.out = 30)
y <- seq(-3, 3, length.out = 30)
z <- outer(x, y, function(a, b) exp(-(a^2 + b^2) / 2))   # «qo'ng'iroq» sirti
persp(x, y, z, theta = 30, phi = 25, col = "lightblue",
      main = "3D sirt")
contour(x, y, z)   # sath chiziqlari
```

Interaktiv 3D uchun **plotly** yoki **rgl** paketlari ishlatiladi.

## Grafikni saqlash

```r
png("savdo.png", width = 800, height = 500)
plot(oylar, savdo, type = "l")
dev.off()   # faylni yopish va saqlash
ggsave("savdo_gg.png", width = 8, height = 5)   # ggplot2 uchun
```
