::: hayot Hayotda qayerda kerak?
Firma ikki mahsulot chiqaradi va ular bir-biriga ta'sir qiladi (bir xil xomashyo, raqobatlashadigan bozor). Foyda funksiyasida x^2, y^2 va xy hadlar paydo bo'ladi. Qaysi hajmlarda foyda maksimal va bu haqiqatan maksimummi, «egar» emasmi? Javobni kvadratik forma va Silvestr mezoni beradi.
:::

## Kvadratik forma

::: formula Ta'rif va matritsa ko'rinishi
n o'zgaruvchining ikkinchi darajali bir jinsli ko'phadi:

$$
Q(x) = Σ_{i}Σ_{j} a_{ij}x_{i}x_{j} = x^{T}Ax
$$

A — **simmetrik** matritsa: diagonalda x_{i}^2 koeffitsiyentlari, a_{ij} = a_{ji} — x_{i}x_{j} koeffitsiyentining **yarmi**.

Masalan, Q = 2x^2 + 2xy + 3y^2 ⇒ A = (2 1; 1 3).
:::

## Aniqlanganlik

::: tushuncha Turlari
Q (va A) — x ≠ 0 uchun:
- **musbat aniqlangan**: Q(x) > 0 (masalan, x^2 + y^2);
- **manfiy aniqlangan**: Q(x) < 0 (−x^2 − y^2);
- **noaniq**: ham musbat, ham manfiy qiymat oladi (x^2 − y^2);
- yarim aniqlangan: Q ≥ 0 yoki Q ≤ 0, lekin nolga ham teng bo'ladi.
:::

Xos sonlar orqali: hammasi > 0 — musbat aniqlangan; hammasi < 0 — manfiy aniqlangan; har xil ishorali — noaniq (5-mavzu).

## Silvestr mezoni

Bosh burchak minorlari: Δ_{1} = a_{11}, Δ_{2} = det(a_{11} a_{12}; a_{21} a_{22}), …, Δ_{n} = det A.

::: teorema Silvestr mezoni
- Q **musbat aniqlangan** ⇔ Δ_{1} > 0, Δ_{2} > 0, …, Δ_{n} > 0.
- Q **manfiy aniqlangan** ⇔ ishoralar almashinadi: Δ_{1} < 0, Δ_{2} > 0, Δ_{3} < 0, …
:::

## Shartsiz ekstremum

::: formula Zaruriy va yetarli shartlar
1. **Zaruriy**: barcha xususiy hosilalar nolga teng — **statsionar nuqta**: ∂f/∂x_{i} = 0.
2. **Yetarli**: statsionar nuqtada ikkinchi hosilalar (Gesse) matritsasi H:
   - H musbat aniqlangan ⇒ **minimum**;
   - H manfiy aniqlangan ⇒ **maksimum**;
   - H noaniq ⇒ ekstremum yo'q (**egar nuqta**).
:::

::: eslatma Ikki o'zgaruvchi uchun tezkor qoida
A = f_{xx}, B = f_{xy}, C = f_{yy}, D = AC − B^2:
- D > 0, A > 0 — minimum; D > 0, A < 0 — maksimum; D < 0 — egar; D = 0 — qo'shimcha tekshiruv kerak.
:::

## Ishlangan misollar

::: misol Aniqlanganlikni tekshirish
a) Q = 2x^2 + 2xy + 3y^2; b) Q = x^2 − 4xy + y^2.
---
a) A = (2 1; 1 3): Δ_{1} = 2 > 0, Δ_{2} = 6 − 1 = 5 > 0 — **musbat aniqlangan**.

b) A = (1 −2; −2 1): Δ_{1} = 1 > 0, Δ_{2} = 1 − 4 = −3 < 0 — **noaniq**. Tekshiruv: x = y = 1 da Q = −2 < 0, x = 1, y = 0 da Q = 1 > 0.
:::

::: misol Shartsiz minimum
f = x^2 + xy + y^2 − 6x − 9y ning ekstremumi.
---
f_{x} = 2x + y − 6 = 0, f_{y} = x + 2y − 9 = 0 ⇒ **x = 1, y = 4**.

Gesse matritsasi H = (2 1; 1 2): Δ_{1} = 2 > 0, Δ_{2} = 3 > 0 — musbat aniqlangan ⇒ **minimum**.

f(1; 4) = 1 + 4 + 16 − 6 − 36 = **−21**.
:::

::: misol Ikki mahsulotli firma foydasi
π = 60x + 90y − 2x^2 − 2xy − 3y^2 (x, y — mahsulot hajmlari). Optimal hajmlar?
---
π_{x} = 60 − 4x − 2y = 0, π_{y} = 90 − 2x − 6y = 0. Birinchisidan y = 30 − 2x; ikkinchisiga qo'yamiz: 90 − 2x − 180 + 12x = 0 ⇒ **x = 9, y = 12**.

H = (−4 −2; −2 −6): Δ_{1} = −4 < 0, Δ_{2} = 24 − 4 = 20 > 0 — manfiy aniqlangan ⇒ **maksimum**.

π_{max} = 540 + 1 080 − 162 − 216 − 432 = **810**.
:::

::: xato
- **xy koeffitsiyentini to'liq a_{12} ga yozish.** Simmetrik matritsada a_{12} = a_{21} = koeffitsiyentning **yarmi**.
- **Manfiy aniqlanganlik uchun «hamma minorlar manfiy» deyish.** To'g'risi — ishoralar almashinadi: −, +, −, …
- **Statsionar nuqtani tekshirmasdan ekstremum deyish** — egar nuqta bo'lishi mumkin.
:::

:::

## Mustaqil mashqlar
