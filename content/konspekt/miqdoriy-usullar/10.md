«2,6 ta yuk mashinasi sotib olamiz» yoki «1,5 ta filial ochamiz» degan reja ma'nosiz. Ko'p iqtisodiy qarorlar bo'linmas: odamlar, mashinalar, loyihalar, «ha/yo'q» tanlovlari. BSD — o'zgaruvchilarning hammasi yoki bir qismi faqat butun qiymat oladigan ChD.

## BSD masalasining qo'yilishi

::: formula Umumiy ko'rinish
Z = c^{T}x → max (min); Ax ≤ b; x ≥ 0; **x_{j} — butun son** (j ∈ J).

- **To'liq butun sonli**: hamma o'zgaruvchilar butun.
- **Aralash**: faqat bir qismi butun.
- **Bul (0–1)**: x_{j} ∈ {0; 1} — «tanlash / tanlamaslik».
:::

**Relaksatsiya** — butunlik shartini olib tashlangan oddiy ChD. Uning optimumi BSD optimumining chegarasi: max masalada Z_{BSD} ≤ Z_{rel}.

## Grafik usul va yaxlitlash

::: oddiy
Butun yechimlar joiz sohadagi «panjara nuqtalari». Optimal butun nuqta relaksatsiya optimumiga eng yaqin nuqta bo'lishi **shart emas** — hatto yaxlitlangan nuqta joiz sohadan chiqib ketishi ham mumkin.
:::

## Gomori kesish usuli

1. Relaksatsiyani simpleks usulda yechamiz.
2. Agar biror butun bo'lishi kerak bo'lgan o'zgaruvchi kasr chiqsa, shu qatordan **kesuvchi cheklov** (Gomori kesimi) tuzamiz: u joriy kasr yechimni kesib tashlaydi, lekin birorta ham butun nuqtani olib tashlamaydi.
3. Kesimni jadvalga qo'shib, qayta yechamiz. Butun yechim chiqquncha takrorlaymiz.

## Shoxlar va chegaralar usuli

::: formula Algoritm
1. Relaksatsiyani yeching. Yechim butun bo'lsa — tamom.
2. Kasr o'zgaruvchi x_{j} = d ni tanlab, ikki shoxga bo'ling: **x_{j} ≤ [d]** va **x_{j} ≥ [d] + 1**.
3. Har bir shoxni relaksatsiya sifatida yeching.
4. Topilgan eng yaxshi butun yechim — **rekord**. Relaksatsiya qiymati rekorddan yaxshi bo'lmagan shoxlar **kesib tashlanadi**.
:::

## Ishlangan misollar

::: misol Yaxlitlash nega ishlamaydi
Z = 5x_{1} + 4x_{2} → max; 6x_{1} + 4x_{2} ≤ 24; x_{1} + 2x_{2} ≤ 6; x_{1}, x_{2} ≥ 0 va butun.
---
Relaksatsiya optimumi: **(3; 1,5), Z = 21**.

Yaxlitlash: (3; 2) — joiz emas (6·3 + 4·2 = 26 > 24). Pastga yaxlitlash: (3; 1), Z = 19.

Lekin butun optimum boshqa joyda: **(4; 0), Z = 20** (6·4 = 24 ≤ 24, 4 ≤ 6). Yaxlitlangan (3; 1) dan yaxshiroq!
:::

::: misol Shoxlar va chegaralar
Yuqoridagi masalani shoxlar va chegaralar usulida yeching.
---
**0-tugun**: (3; 1,5), Z = 21. x_{2} kasr → shoxlaymiz.

**1-tugun (x_{2} ≤ 1)**: (3,33; 1), Z = 20,67. x_{1} kasr → yana shoxlaymiz.
- **1a (x_{1} ≤ 3)**: (3; 1), Z = 19 — butun, rekord = 19.
- **1b (x_{1} ≥ 4)**: (4; 0), Z = 20 — butun, **yangi rekord = 20**.

**2-tugun (x_{2} ≥ 2)**: (2; 2), Z = 18 — butun, lekin 18 < 20 → kesiladi.

Hamma shoxlar tekshirildi: **optimum (4; 0), Z = 20**.
:::

::: misol Loyihalarni tanlash (0–1 model)
Byudjet 10 mln. To'rt loyiha: A (narxi 4, sof foyda 6), B (3; 4), C (5; 7), D (2; 3). Qaysilarini tanlash kerak?
---
x_{j} = 1 — loyiha tanlanadi, 0 — yo'q.

**Z = 6x_{A} + 4x_{B} + 7x_{C} + 3x_{D} → max**; 4x_{A} + 3x_{B} + 5x_{C} + 2x_{D} ≤ 10; x_{j} ∈ {0; 1}.

Kombinatsiyalarni solishtirish: A + C: narx 9, foyda 13; A + B + D: 9 va 13; **B + C + D: 10 va 14**; A + C + D: 11 — byudjetdan oshadi.

Javob: **B, C, D — foyda 14 mln**. Eng «samarali» A loyihasi (6/4 = 1,5) tanlanmadi — butun sonli masalada «eng yaxshi nisbat» qoidasi har doim ham ishlamaydi.
:::

::: tushuncha Boshqa diskret modellar
- **Joylashtirish**: qaysi shaharlarda ombor ochish (y_{i} ∈ {0; 1}) + tashish xarajatlari.
- **Belgilangan xarajat**: mahsulot ishlab chiqarilsa (x > 0), qo'shimcha F xarajat: x ≤ My, y ∈ {0; 1}.
- **«Yoki – yoki» shartlari**: ikki cheklovdan kamida bittasi bajarilsin.
:::

::: xato
- **Relaksatsiya yechimini yaxlitlab, optimal deb e'lon qilish.** 1-misol buning noto'g'riligini ko'rsatdi.
- **Shoxlashda x_{j} ≤ [d] va x_{j} ≥ [d] oraliqlarini qoplab yuborish.** Ikkinchi shox [d] + 1 dan boshlanadi.
- **Rekorddan yomon shoxlarni davom ettirish** — vaqt isrofi.
:::

## O'zingizni tekshiring

::: test
? Max BSD masalasida relaksatsiya qiymati 50. Butun optimum haqida nima deyish mumkin?
+ Z_{BSD} ≤ 50
- Z_{BSD} = 50
- Z_{BSD} ≥ 50
- Z_{BSD} = 49
> Butunlik sharti qo'shilsa, joiz soha torayadi — natija yaxshilanmaydi.
? x_{2} = 3,7 bo'yicha shoxlash. Qaysi ikki shox?
- x_{2} ≤ 3,7 va x_{2} ≥ 3,7
+ x_{2} ≤ 3 va x_{2} ≥ 4
- x_{2} = 3 va x_{2} = 4
- x_{2} ≤ 4 va x_{2} ≥ 3
> [3,7] = 3: x_{2} ≤ 3 yoki x_{2} ≥ 4 — kasr qiymatlar chiqarib tashlanadi.
? Loyiha tanlash modelida o'zgaruvchilar qanday?
- Ixtiyoriy haqiqiy
- Faqat musbat
+ 0 yoki 1
- Butun, 0 dan 10 gacha
> Bul o'zgaruvchi: tanlanadi (1) yoki yo'q (0).
:::
