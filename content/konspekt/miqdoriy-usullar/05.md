## Ta'rif va geometrik ma'no

::: tushuncha Xos son va xos vektor
A — kvadrat matritsa. Agar noldan farqli X vektor va λ son uchun

$$
AX = λX
$$

bajarilsa, λ — A ning **xos soni**, X — unga mos **xos vektori**.
:::

::: oddiy
Matritsa vektorni odatda buradi va cho'zadi. Xos vektor — burilmaydigan «maxsus yo'nalish»: A uni faqat λ marta cho'zadi (λ < 0 bo'lsa teskari tomonga ag'daradi).
:::

## Xarakteristik tenglama

AX = λX ⇔ (A − λE)X = 0. Bu bir jinsli sistema notrivial yechimga ega bo'lishi uchun (4-mavzu):

$$
det(A − λE) = 0
$$

Bu — **xarakteristik tenglama**. 2 × 2 uchun: λ^2 − (a_{11} + a_{22})λ + det A = 0.

::: formula Foydali xossalar
- Xos sonlar yig'indisi = **iz** (diagonal elementlar yig'indisi): λ_{1} + … + λ_{n} = tr A.
- Xos sonlar ko'paytmasi = **det A**.
- Uchburchak matritsaning xos sonlari — diagonal elementlari.
- Simmetrik matritsaning xos sonlari doim **haqiqiy**.
:::

| Karrali | [[2 1; 0 2]] | λ = 2 (ikki karrali), faqat bitta erkli xos vektor |
| Kompleks | [[0 −1; 1 0]] | λ = ±i — haqiqiy xos vektor yo'q (90° burish) |

## Diagonallashtirish

Agar n × n matritsaning n ta chiziqli erkli xos vektori bo'lsa, ularni ustun qilib P tuzamiz:

$$
A = PDP^{−1}, D = diag(λ_{1}, …, λ_{n})
$$

Foydasi: **A^{k} = PD^{k}P^{−1}**, D^{k} esa shunchaki diagonal elementlarni darajaga ko'tarish. Har xil xos sonli matritsa doim diagonallashadi.

## Ishlangan misollar

::: misol Xos son va xos vektorlar
A = [[4 1; 2 3]].
---
Xarakteristik tenglama: λ^2 − 7λ + (12 − 2) = 0 → λ^2 − 7λ + 10 = 0 → **λ_{1} = 5, λ_{2} = 2**.

λ = 5: (A − 5E)X = 0 → −x_{1} + x_{2} = 0 → **X_{1} = [[1; 1]]**. Tekshiruv: A[[1; 1]] = [[5; 5]] = 5·[[1; 1]] ✓.

λ = 2: 2x_{1} + x_{2} = 0 → **X_{2} = [[1; −2]]**. A[[1; −2]] = [[2; −4]] = 2·[[1; −2]] ✓.

Xossa: 5 + 2 = 7 = tr A, 5·2 = 10 = det A ✓.
:::

::: misol Diagonallashtirish va A^{3}
Yuqoridagi A uchun A^{3} ni toping.
---
P = [[1 1; 1 −2]], D = diag(5; 2). A^{3} = P·diag(125; 8)·P^{−1}.

P^{−1} = {1|−3}·[[−2 −1; −1 1]]. Hisoblash natijasi: **A^{3} = [[86 39; 78 47]]** — to'g'ridan-to'g'ri A·A·A ga teng (tekshirib ko'ring).
:::

::: misol Bozor ulushlari (Markov zanjiri)
O'tish matritsasi (qator — «qayerdan»): P = [[0,9 0,1; 0,2 0,8]]. Uzoq muddatda ulushlar?
---
Barqaror taqsimot π = [[π_{A} π_{B}]] uchun πP = π, ya'ni π — P^{T} ning **λ = 1** ga mos xos vektori:

0,9π_{A} + 0,2π_{B} = π_{A} → 0,1π_{A} = 0,2π_{B} → π_{A} = 2π_{B}.

π_{A} + π_{B} = 1 dan: **π_{A} = {2|3} ≈ 67%, π_{B} = {1|3} ≈ 33%** — boshlang'ich ulushlardan qat'i nazar.
:::

::: xato
- **X = 0 ni xos vektor deb olish.** Ta'rif bo'yicha xos vektor noldan farqli.
- **det(A − λE) da λ ni faqat bitta elementdan ayirish.** λ bosh diagonaldagi **har bir** elementdan ayiriladi.
- **Xos vektorni yagona deb hisoblash.** [[1; 1]] ham, [[3; 3]] ham — bitta yo'nalish; odatda eng sodda ko'rinish yoziladi.
:::
