- Vektorlarning chiziqli bog'liq va erkli bo'lishini tekshirishni
- Bazis tushunchasini
- Matritsa rangini minorlar va elementar almashtirishlar bilan topishni
- Bir jinsli sistemaning fundamental yechimlar sistemasini (FYS) tuzishni
:::

::: hayot Hayotda qayerda kerak?
Firmada uchta mahsulot bor, lekin uchinchisining xomashyo sarfi birinchi va ikkinchisinikining yig'indisiga teng. Demak u «yangi» ma'lumot bermaydi — resurslar bo'yicha u qolgan ikkitasining kombinatsiyasi. Chiziqli bog'liqlik shuni aniqlaydi: modeldagi qaysi ko'rsatkichlar haqiqatan mustaqil, qaysilari ortiqcha.
:::

## Chiziqli bog'liqlik va erklilik

a_{1}, a_{2}, …, a_{k} vektorlar **chiziqli bog'liq**, agar hammasi nol bo'lmagan λ_{1}, …, λ_{k} sonlar uchun

$$
λ_{1}a_{1} + λ_{2}a_{2} + … + λ_{k}a_{k} = 0
$$

bajarilsa. Aks holda (faqat hamma λ = 0 bo'lgandagina) ular **chiziqli erkli**.

::: oddiy
Bog'liq — vektorlardan birini qolganlari orqali ifodalash mumkin. Erkli — hech biri boshqalarining «aralashmasi» emas.
:::

::: tushuncha Bazis
Fazodagi chiziqli erkli vektorlarning **maksimal** to'plami — bazis. R^{n} da bazis har doim n ta vektordan iborat; har qanday vektor bazis orqali **yagona** tarzda ifodalanadi.
:::

## Matritsaning rangi

::: tushuncha k-tartibli minor
Matritsadan ixtiyoriy k ta qator va k ta ustun tanlab tuzilgan determinant. **Rang** r(A) — noldan farqli minorlarning eng katta tartibi.
:::

::: teorema Rang haqida teorema
Matritsaning rangi uning chiziqli erkli qatorlari (yoki ustunlari) maksimal soniga teng.
:::

Rangni topish usullari:

1. **Minorlarni o'rab olish**: noldan farqli k-tartibli minorni topib, uni o'rab turgan (k + 1)-tartibli minorlarni tekshiramiz. Hammasi nol bo'lsa, r = k.
2. **Elementar almashtirishlar**: pog'onali ko'rinishga keltirib, noldan farqli qatorlarni sanaymiz — amalda eng tez usul.

## Bir jinsli sistema

AX = 0 — ozod hadlari nol bo'lgan sistema. U **doim birgalikda**: X = 0 (trivial yechim) har doim bor.

::: teorema Notrivial yechim sharti
AX = 0 noldan farqli yechimga ega ⇔ **r(A) < n**. Kvadrat matritsa uchun bu **det A = 0** demak.
:::

::: formula Fundamental yechimlar sistemasi (FYS)
r(A) = r < n bo'lsa, n − r ta chiziqli erkli yechimlar to'plami — FYS mavjud. Umumiy yechim:

$$
X = c_{1}X_{1} + c_{2}X_{2} + … + c_{n−r}X_{n−r}
$$

c_{i} — ixtiyoriy sonlar. FYS ni olish uchun erkin noma'lumlarga navbat bilan (1, 0, …), (0, 1, …) qiymatlar beriladi.
:::

## Ishlangan misollar

::: misol Chiziqli bog'liqlikni tekshirish
a_{1} = (1; 2; 3), a_{2} = (2; 1; 0), a_{3} = (3; 3; 3). Bog'liqmi?
---
Matritsa (1 2 3; 2 1 0; 3 3 3) ning rangi: 2-q − 2·(1-q) = (0 −3 −6), 3-q − 3·(1-q) = (0 −3 −6). Ular teng — rang **2 < 3**, demak vektorlar **bog'liq**.

Haqiqatan, **a_{3} = a_{1} + a_{2}**: (1 + 2; 2 + 1; 3 + 0) = (3; 3; 3).
:::

::: misol Minorlar orqali rang
A = (1 2 3; 2 4 6; 1 0 1) ning rangi?
---
2-qator 1-qatorning ikki baravari, shuning uchun det A = 0 va r < 3.

2-tartibli minor: 1-va 3-qator, 1- va 2-ustun: det(1 2; 1 0) = −2 ≠ 0. Demak **r(A) = 2**.
:::

::: misol FYS ni topish
x_{1} + 2x_{2} − x_{3} = 0; 2x_{1} + 4x_{2} − 2x_{3} = 0; x_{1} + x_{2} + x_{3} = 0.
---
2-tenglama 1-sining ikki baravari — tashlab yuboramiz. Qolganlarini ayirsak: x_{2} − 2x_{3} = 0 → x_{2} = 2x_{3}; so'ng x_{1} = −x_{2} − x_{3} = −3x_{3}.

r(A) = 2, n = 3, FYS bitta vektordan iborat. x_{3} = 1 desak: **X_{1} = (−3; 2; 1)**.

Umumiy yechim: X = c·(−3; 2; 1). Tekshiruv: −3 + 4 − 1 = 0 ✓, −3 + 2 + 1 = 0 ✓.
:::

::: xato
- **«Vektorlar 3 ta, demak erkli».** Soni emas, rang hal qiladi.
- **Bir jinsli sistemani «yechimi yo'q» deyish.** X = 0 doim yechim; savol — boshqa yechim bormi.
- **FYS da erkin noma'lumlarga bir xil qiymat berish.** (1, 0) va (0, 1) kabi chiziqli erkli qiymatlar kerak.
:::

## O'zingizni tekshiring

::: test
? R^{3} da 4 ta vektor berilgan. Ular haqida nima deyish mumkin?
- Har doim erkli
+ Har doim bog'liq
- Bazis tashkil etadi
- Hech narsa deb bo'lmaydi
> R^{3} da erkli vektorlar 3 tadan oshmaydi, 4 tasi albatta bog'liq.
? 4 noma'lumli bir jinsli sistemada r(A) = 2. FYS da nechta vektor?
- 4
+ 2
- 6
- 1
> n − r = 4 − 2 = 2.
? Kvadrat bir jinsli sistema faqat trivial yechimga ega. Bu nimani bildiradi?
+ det A ≠ 0
- det A = 0
- r(A) < n
- Sistema birgalikda emas
> Notrivial yechim faqat det A = 0 da bo'ladi; aks holda yagona yechim — X = 0.
:::

## Mustaqil mashqlar

::: mashq
(1; 1) va (2; 3) erklimi? || Ha: det(1 2; 1 3) = 1 ≠ 0
(1 −1 2; 2 −2 4; 3 −3 6) rangi? || 1 (hamma qatorlar proporsional)
x_{1} − x_{2} + x_{3} = 0, 2x_{1} + x_{2} − x_{3} = 0 uchun FYS || X = c·(0; 1; 1)
(1; 0; 2), (0; 1; 1), (1; 1; 3) bog'liqmi? || Ha: uchinchisi birinchi ikkitasining yig'indisi
:::

::: eslatma Moodle bilan bog'liqlik
«4-mavzu. Bir jinsli tenglamalar sistemasi va uning fundamental yechimi» ma'ruzasi rejasi: chiziqli erklilik va bazis, matritsa rangi, n-tartibli minor, rangni hisoblash usullari, bir jinsli tenglamalar sistemasi, bazis (fundamental) yechimlar sistemasi. Shu bo'limda Joriy nazoratning namunaviy varianti ham bor — ushbu misollar uning asosiy turlarini qamrab oladi.
:::

- AX = 0: notrivial yechim ⇔ r < n; FYS n − r ta vektordan iborat.
