## Sistema va uning matritsa shakli

m ta tenglama, n ta noma'lum:

$$
a_{11}x_{1} + a_{12}x_{2} + … + a_{1n}x_{n} = b_{1}, …, a_{m1}x_{1} + … + a_{mn}x_{n} = b_{m}
$$

Qisqacha: **AX = B**. A — koeffitsiyentlar matritsasi, X — noma'lumlar ustuni, B — ozod hadlar ustuni. A ga B ustunini qo'shsak — **kengaytirilgan matritsa** (A ∣ B) hosil bo'ladi.

::: tushuncha Sistema turlari
- **Birgalikda** — kamida bitta yechimi bor; **birgalikda emas** — yechimi yo'q.
- Birgalikdagi sistema **aniq** (yagona yechim) yoki **aniqmas** (cheksiz ko'p yechim) bo'ladi.
:::

## Kroneker–Kapelli teoremasi

::: teorema Kroneker–Kapelli
Sistema birgalikda ⇔ **r(A) = r(A ∣ B)**.

- r(A) = r(A ∣ B) = n (noma'lumlar soni) — **yagona** yechim;
- r(A) = r(A ∣ B) < n — **cheksiz ko'p** yechim, n − r ta erkin noma'lum;
- r(A) < r(A ∣ B) — yechim **yo'q**.
:::

## Gauss usuli

Kengaytirilgan matritsani elementar qator almashtirishlari bilan **pog'onali** ko'rinishga keltiramiz (to'g'ri yo'l), so'ng oxirgi tenglamadan boshlab noma'lumlarni topamiz (teskari yo'l).

::: oddiy
Gauss usuli — maktabdagi «qo'shish usuli»ning tartibli ko'rinishi: avval x_{1} ni 2- va 3-tenglamadan yo'qotamiz, keyin x_{2} ni 3-tenglamadan. Oxirgi tenglamada bitta noma'lum qoladi.
:::

## Gauss–Jordan usuli

Bunda matritsa **keltirilgan eshelon** ko'rinishgacha olib boriladi: chap qism birlik matritsaga aylanadi va oxirgi ustunda tayyor javob turadi — teskari yo'l kerak emas.

## Ishlangan misollar

::: misol Gauss usuli
Yeching: [:x + y + z = 6; 2x − y + z = 3; x + 2y − z = 2:]
---
| | x | y | z | b |
|---|---|---|---|---|
| 1-q | 1 | 1 | 1 | 6 |
| 2-q | 2 | −1 | 1 | 3 |
| 3-q | 1 | 2 | −1 | 2 |

2-q − 2·(1-q): [[0 −3 −1 ∣ −9]]; 3-q − (1-q): [[0 1 −2 ∣ −4]].

Ikkinchi va uchinchini almashtirib, yangi 3-q = [[0 −3 −1 ∣ −9]] + 3·[[0 1 −2 ∣ −4]] = [[0 0 −7 ∣ −21]].

Teskari yo'l: −7z = −21 → **z = 3**; y − 2·3 = −4 → **y = 2**; x + 2 + 3 = 6 → **x = 1**.

Tekshiruv: 2·1 − 2 + 3 = 3 ✓, 1 + 4 − 3 = 2 ✓.
:::

::: misol Yechimi yo'q sistema
[:x + y = 2; 2x + 2y = 5:]
---
2-q − 2·(1-q): 0 = 1. Kengaytirilgan matritsa [[1 1 ∣ 2; 0 0 ∣ 1]]: r(A) = 1, r(A ∣ B) = 2. Rangi teng emas — **yechim yo'q** (ikki parallel to'g'ri chiziq).
:::

::: misol Cheksiz ko'p yechim
[:x + y + z = 3; 2x + 2y + 2z = 6:]
---
Ikkinchi tenglama birinchisining ikki baravari: r(A) = r(A ∣ B) = 1 < 3. Erkin noma'lumlar 3 − 1 = 2 ta: y = s, z = t, **x = 3 − s − t** (s, t — ixtiyoriy).
:::

::: misol Ishlab chiqarish rejasi (Gauss–Jordan)
Uch mahsulotning birligiga sarf: 1-xomashyo 1, 2, 1; 2-xomashyo 2, 1, 3; 3-xomashyo 1, 1, 2 birlik. Zaxira: 65, 85, 60. Xomashyo to'liq ishlatilishi uchun reja?
---
Sistema: [:x_{1} + 2x_{2} + x_{3} = 65; 2x_{1} + x_{2} + 3x_{3} = 85; x_{1} + x_{2} + 2x_{3} = 60:]

Gauss–Jordan almashtirishlaridan so'ng kengaytirilgan matritsa [[1 0 0 ∣ 10; 0 1 0 ∣ 20; 0 0 1 ∣ 15]] ko'rinishga keladi.

Reja: **x_{1} = 10, x_{2} = 20, x_{3} = 15**. Tekshiruv: 10 + 40 + 15 = 65 ✓, 20 + 20 + 45 = 85 ✓, 10 + 20 + 30 = 60 ✓.
:::

::: xato
- **Faqat A ning rangini tekshirish.** Kroneker–Kapelli uchun r(A) va r(A ∣ B) **ikkalasi** kerak.
- **Qatorni almashtirishda ozod hadni unutish.** Amal butun qatorga, b ustuni bilan birga qo'llanadi.
- **«0 = 0» qatorni ziddiyat deb o'ylash.** 0 = 0 — ortiqcha tenglama; ziddiyat — **0 = son ≠ 0**.
:::

## O'zingizni tekshiring

::: test
? 3 noma'lumli sistemada r(A) = r(A ∣ B) = 2. Yechimlar soni?
- Yagona
+ Cheksiz ko'p
- Yechim yo'q
- Aniq 2 ta
> Rang noma'lumlar sonidan kichik: n − r = 1 ta erkin noma'lum, demak cheksiz ko'p yechim.
? Pog'onali matritsada [[0 0 0 ∣ 4]] qatori chiqdi. Bu nima degani?
- x_{3} = 4
- Sistema aniqmas
+ Sistema birgalikda emas
- Xato qilingan
> 0 = 4 — ziddiyat: r(A ∣ B) > r(A), yechim yo'q.
? Gauss–Jordan usulida A qism nimaga aylantiriladi?
- Nol matritsaga
+ Birlik matritsaga
- Simmetrik matritsaga
- Transponirlangan matritsaga
> Chap qism E bo'lsa, o'ng ustunda tayyor yechim turadi.
:::
