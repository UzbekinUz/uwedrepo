## Masalaning qo'yilishi

::: formula Tenglik shartli masala
f(x_{1}, …, x_{n}) → max (min); g_{i}(x_{1}, …, x_{n}) = b_{i}, i = 1, …, m (m < n).
:::

## Noma'lumni yo'qotish usuli

Shart tenglamasidan bitta o'zgaruvchini qolganlari orqali ifodalab, f ga qo'yamiz — masala **shartsiz** ekstremumga aylanadi (14-mavzu). Sodda shartlarda tez, murakkab shartlarda esa ifodalab bo'lmasligi mumkin.

## Lagranj usuli

::: formula Lagranj funksiyasi
L(x, λ) = f(x) + λ_{1}(b_{1} − g_{1}(x)) + … + λ_{m}(b_{m} − g_{m}(x))

Zaruriy shartlar: **∂L/∂x_{j} = 0** (j = 1, …, n) va **∂L/∂λ_{i} = 0** (bu — shartlarning o'zi).
:::

::: tushuncha λ ning iqtisodiy ma'nosi
λ_{i} — b_{i} ni 1 birlikka oshirsak, optimal qiymat f* **qanchaga o'zgarishi**: λ ≈ Δf*/Δb. Byudjet masalasida — pulning **chekli foydaliligi**, xarajat masalasida — mahsulotning **chekli xarajati**. Bu ChDdagi soya narxining nochiziqli «qarindoshi» (9-mavzu).
:::

## Tengsizlik shartlari

g(x) ≤ b ko'rinishidagi shartda ikki holat bor:

1. **Cheklov faol emas**: shartsiz (yoki boshqa shartlar bilan) topilgan optimum g ≤ b ni qanoatlantiradi — cheklov hech narsani o'zgartirmaydi (λ = 0).
2. **Cheklov faol**: optimum chegarada yotadi — g(x) = b deb tenglik shartli masala sifatida yechamiz (λ ≥ 0).

Umumiy holda bu **Kun–Takker shartlari** deyiladi; ikki o'zgaruvchida grafik usul bilan ko'rinadi.

## Ishlangan misollar

::: misol Yo'qotish usuli
U = xy → max; 2x + 4y = 40 (x — ovqat, y — kitob, narxlari 2 va 4 ming so'm).
---
Shartdan x = 20 − 2y. U = (20 − 2y)y = 20y − 2y^2.

U' = 20 − 4y = 0 ⇒ **y = 5, x = 10**, U'' = −4 < 0 — maksimum. **U_{max} = 50.**
:::

::: misol Lagranj usuli va λ
Xuddi shu masala Lagranj usulida.
---
L = xy + λ(40 − 2x − 4y).

L_{x} = y − 2λ = 0, L_{y} = x − 4λ = 0, L_{λ} = 40 − 2x − 4y = 0.

y = 2λ, x = 4λ ⇒ 8λ + 8λ = 40 ⇒ **λ = 2,5**, x = 10, y = 5, U = 50.

Ma'nosi: byudjet 1 ming so'mga oshsa, foydalilik taxminan **2,5** ga oshadi (aniq hisob: byudjet 41 da U ≈ 52,53).

E'tibor bering: optimumda {MU_{x}|p_{x}} = {y|2} = 2,5 = {MU_{y}|p_{y}} = {x|4} — har bir so'mning foydaliligi teng («ekvimarjinal» qoida).
:::

::: misol Xarajatni minimallashtirish
C = x^2 + 2y^2 → min; x + y = 6 (jami 6 birlik ikki sexda ishlab chiqariladi).
---
L = x^2 + 2y^2 + λ(6 − x − y). L_{x} = 2x − λ = 0, L_{y} = 4y − λ = 0 ⇒ x = 2y.

x + y = 6 ⇒ **y = 2, x = 4, C_{min} = 16 + 8 = 24**, λ = 8.

λ = 8 — **chekli xarajat**: 7-birlikni ishlab chiqarish taxminan 8 ga tushadi.
:::

::: misol Tengsizlik shart (grafik usul)
U = xy → max; 2x + 4y ≤ 40; x ≤ 8; x, y ≥ 0.
---
Byudjetning o'zi bo'yicha optimum (10; 5) edi, lekin x ≤ 8 bajarilmaydi — demak x ≤ 8 cheklovi **faol**: x = 8.

Byudjet ham to'liq sarflanadi: 16 + 4y = 40 ⇒ **y = 6**, **U = 48** < 50 (qo'shimcha cheklov foydalilikni kamaytirdi).

::: grafik x: 0..21, y: 0..12 | Joiz soha, byudjet chizig'i va befarqlik egri chiziqlari
y = 10 - 0.5x | slate | byudjet 2x + 4y = 40
soha 10 - 0.5x | 0..8 | teal | joiz soha
y = 50/x | sky | U = 50 | 3..20
y = 48/x | amber | U = 48 | 3..20
vertikal 8 | x = 8
nuqta 10, 5 | (10; 5) — joiz emas
nuqta 8, 6 | optimum (8; 6)
:::
:::

::: xato
- **Lagranj shartlaridan ∂L/∂λ = 0 ni (cheklovni) unutish** — λ ni topib bo'lmaydi.
- **λ ni «shunchaki yordamchi son» deb tashlab ketish** — u eng muhim iqtisodiy natijalardan biri.
- **Tengsizlik shartida shartsiz optimumni tekshirmasdan cheklovni faol deb olish.** Avval ichki yechim joizligini tekshiring.
:::

## O'zingizni tekshiring

::: test
? f = x + y → max, x^2 + y^2 = 2 bo'lsa, optimum?
- (0; √2)
+ (1; 1)
- (2; 0)
- (√2; √2)
> L: 1 = 2λx, 1 = 2λy ⇒ x = y; 2x^2 = 2 ⇒ x = y = 1, f = 2.
? Byudjet masalasida λ = 3. Byudjet 2 birlikka oshsa, maksimal foydalilik taxminan qanchaga o'zgaradi?
- 1,5 ga
- 3 ga
+ 6 ga
- O'zgarmaydi
> Δf* ≈ λ·Δb = 3·2 = 6.
? Tengsizlik shartli masalada shartsiz optimum cheklovni qanoatlantiradi. Bu cheklov uchun λ = ?
+ 0
- 1
- Manfiy
- Cheksiz
> Faol bo'lmagan cheklovning bahosi nol (to'ldiruvchi bo'shliq g'oyasi).
:::

- Yo'qotish usuli: shartdan bitta o'zgaruvchini ifodalab, shartsiz ekstremumga keltiramiz.
- Lagranj: L = f + λ(b − g); ∂L/∂x = 0, ∂L/∂λ = 0.
- λ = Δf*/Δb — chekli foydalilik / chekli xarajat / soya narxi.
- Tengsizlik: avval ichki yechim; joiz bo'lmasa, cheklov faol (tenglik) deb yechamiz.
